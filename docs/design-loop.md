## 최종 검증 — 2026-09-13

- **테마**: default / sci-fi, 각각 dark / light. 색 대비 미달 0, 커스터마이징 다이얼 27개.
- **호환성**: Godot 4.6 stable 및 4.7.2에서 네 화면(390×844, 844×390, 768×1024, 1280×800) 각각 **384/384 통과**.
- **렌더 확인**: 4.6에서 프리셋 네 종류 × 36장 = 144장 생성, 대표 폰·데스크톱 화면 확인. 렌더 로그 오류 0.
- **사이트**: 요청한 `docs/www`에 영문 3페이지와 한국어 3페이지. 용어 사전 영문 155개, 한국어 159개.
  루트는 영어로 연결한다. 용어 팝업은 마우스·터치·키보드, Escape 닫기, 참조 링크 접근을 지원한다.

  모바일 코드 줄바꿈(I-78), 다크 모드(I-79), 표 그룹명(I-80), CSS 중괄호 오류를 해결했다.
- **검증 신뢰성**: CSS·잘못된 절 링크·낡은 용어 사전·이미 수정된 테마·화면 크기별 검사 실패를
  임시 사본에서 의도적으로 넣어 실패 검출 확인. 검사 중 원본 변경 없음.
- **설치본**: 배포 ZIP을 새 프로젝트에 설치해 **384/384 통과**. 스킨 다이얼 검사 자료는 설치본 밖에서 제공한다.
- **배포 준비**: `main / (root)` 설정 유지, 루트 `index.html` 및 `.nojekyll` 추가.
  이전 Pages 실패 원인이던 순환 데모 링크를 Git에서 제외하고 `run.sh --setup`으로 생성한다.
  실제 배포 주소와 관리 방법은 [README.md](README.md)에 있다.

`godot --headless --path "$SP/verify" --editor --quit`

🛑 **사이트 표·풍선은 눈으로 본다** — `bash tools/site_shots.sh "$SP/site_shots"` 가 6 페이지를 데스크톱(1100)·

HTML 을 읽어서는 안 보인다. 도구 안에서 `--headless=new` 크롬을 `&` 로 띄우고 파일이 생기면 죽인다 —
크롬은 스크린샷을 저장한 뒤에도 **끝나지 않고**, macOS 에는 `timeout` 이 없다. chrome-devtools MCP 는
사용자의 브라우저 프로필과 충돌해 못 쓴다. 🛑 크롬은 **창 폭을 500 CSS px 아래로 안 줄인다** — 폰 폭은
iframe 래퍼로 찍는다(도구가 한다). 창 폭만 줄여 찍은 그림은 500 배치를 잘라 낸 것이라 **가짜 결함**을 보인다.
레이아웃 폭이 의심되면 페이지에 `innerWidth` 를 화면에 찍는 프로브를 넣어 잰다(반복 33).

## 지켜야 할 규약

- 🛑🛑 **검사를 추가하면 일부러 깨뜨려 본다.** 반복 6 에서 넣은 `skin contrast` 는 **일곱 반복 동안
  아무것도 검증하지 않았다** — GDScript 람다가 바깥 지역 변수를 **값으로 캡처**해서, 람다 안의
  `worst = value` 가 바깥에 반영되지 않았다. 무엇을 재든 늘 초록불이었다. 통과하는 검사는
  **통과하도록 만들어졌을 뿐일 수 있다.** 새 검사는 반드시 대상 코드를 되돌려 **FAIL 을 눈으로 본 뒤**
  원복한다. (배열·사전은 참조로 캡처되므로 누적에는 그것을 쓴다.)
- 🛑🛑 **눈으로 의심이 들면 기록하기 전에 먼저 잰다.** 축소한 스크린샷(720px 로 줄인 것)으로
  여백·발광·잘림을 판단해 **두 번 헛짚었다**(I-20 발광 잘림, I-25 글자 붙음 — 둘 다 실측하니 멀쩡했다).
  의심이 들면 ① 해당 영역을 크롭해 원본 배율로 보거나 ② 프로브를 띄워 좌표를 찍어 본 **뒤에** 이슈로 적는다.
- 🛑🛑 **검사 출력을 `grep` 으로만 보지 않는다.** `grep -E "FAIL|passed"` 로 훑다가 **스크립트 오류로
  섹션이 통째로 중단된 것**을 놓쳤다 — 없는 함수를 불렀는데 앞 섹션들의 `passed` 만 보고 초록불로
  읽었다(2026-09-13, `GoSurface.close()`). 검사를 고친 뒤에는 **마지막 몇 줄을 그대로** 본다:
  `... | tail -5` 에는 총계와 `✅/🛑` 가 함께 나온다. 검사 **개수가 늘지 않았다면** 새 검사가
  돌지 않은 것이다 — 그것이 가장 빠른 신호다.
- 🛑🛑 **검사의 전제가 화면 크기에 기대지 않게 쓴다.** 두 반복 연속으로 같은 실수를 했다 —
  ① "기본이면 겹친다" 는 넓은 화면에서 폼이 가운데로 몰려 성립하지 않았고, ② 알림 폭을 300dp 로
  박으니 844dp 화면에서는 애초에 닿지 않았다. 숫자는 **화면에서 끌어온다**(`area.size.x * 0.9`).
  그리고 방향·자리를 이름으로 박지 않는다: "가로면 옆으로" 는 1280×800(1.6:1)에서 틀렸다 —
  **규칙 자체**(면적이 가장 적게 드는 쪽)를 잰다. 🔑 검사가 빨간불이면 코드부터 의심하게 되는데,
  이 셋은 모두 검사 쪽이 좁았던 것이다.
- 🛑 **기능을 더한 반복에서 부작용을 한 번은 찍어 본다.** `avoid_hud` 는 알림이 뜨는 순간 본문을
  통째로 출렁이게 했는데, 그것은 **다음 반복의 스크린샷**에서야 드러났다. 새 기능이 켜진 채
  다른 일(알림·시트·키보드)이 일어나는 화면을 하나는 남긴다.
- 🛑 **파일이 없어졌으면 지워진 것인지 옮겨진 것인지부터 본다.** 사이트가 `docs/www/` 에서 `docs/` 로
  재배치된 것을 "삭제" 로 읽고 복구부터 하려 했다(2026-09-13). `ls -la` 로 옆 폴더의 시각과 내용을
  먼저 보고, **`--delete` 동기화는 원본 실태를 확인하기 전에는 절대 돌리지 않는다** — 사본까지 지운다.
  당시 사이트 구조는 `docs/`였다. 최종 구조는 사용자 요청에 맞춘 `docs/www/`(영문), `docs/www/ko/`(한국어), `docs/www/site/`(사전)다.
- 🛑 **테마를 고쳤으면 `python3 tools/check_contrast.py` 가 「미달 합계 0」이어야 한다.** 색을 예쁘게
  고르다 보면 반드시 어딘가의 대비가 무너진다 — 눈으로는 안 보이고 햇빛 아래 폰에서만 보인다.
- 🛑 `SHAPE_DEFAULT`(**형태**)를 고쳐서 새 모양을 만들지 않는다 — **새 dict 를 더한다.**
  형태를 건드리면 네 테마의 배치가 한꺼번에 흔들려 회귀 범위를 좁힐 수 없다. 팔레트는 고쳐도 된다.
- 🛑 **두 엔진에서 검사한다.** 4.7 만으로는 4.6 호환을 보장하지 못한다:
  `GOHUD_PROJECT=$SP/verify46 GODOT_BIN=$SP/godot46/Godot.app/Contents/MacOS/Godot bash tools/run_tests.sh`
- 🛑 `GoStyle.box()`·`floating()`·`disc()` 는 `StyleBoxFlat` 반환 약속을 깨지 않는다. 커스텀 모양은 `GoStyle.surface()`.
- 🛑 내가 만들지 않은 파일(`go_sheet.gd`·`go_surface.gd`·`examples/demo/*`·`sim*.gd`·`i18n/*`)은 건드리지 않는다.

## 검증 환경 재구성

```bash
SP=<scratchpad>
mkdir -p "$SP/verify/addons"
cat > "$SP/verify/project.godot" <<'EOF'
config_version=5
[application]
config/name="gohud verify"
run/main_scene="res://addons/gohud/examples/gallery/gallery.tscn"
config/features=PackedStringArray("4.7", "GL Compatibility")
[display]
window/size/viewport_width=390
window/size/viewport_height=844
[rendering]
renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
EOF
# sync.sh — examples/.gdignore 를 빼고 복사한다(그게 있으면 갤러리를 못 연다)
rsync -a --delete --exclude '.git' --exclude '.godot' --exclude 'builds' --exclude '.env' \
  --exclude 'examples/demo' --exclude 'examples/.gdignore' --exclude '.review' \
  <애드온>/ "$SP/verify/addons/gohud/"
godot --headless --path "$SP/verify" --editor --quit     # 클래스 캐시·임포트
```

스크린샷 대조:
```bash
godot --path "$SP/verify" -s res://addons/gohud/tests/gallery_shots.gd -- \
  --out="$SP/shots" --preset=scifi_dark --still
```
`--still` 이 없으면 코치마크 맥동·페이드 때문에 **실행마다 그림이 달라져** 픽셀 대조를 못 한다.
