게임 UI 를 리소스 한 장으로 굴린다

gohud 는 Godot 4.7 이상에서 쓰는 HUD·UI 키트다. 떠 있는 창, 바텀 시트, 확인창, 폼, 스낵바, 코치마크, HUD 막대, 퀵슬롯, 가상 조이스틱을 테마 한 장과 아이콘 세트 한 장으로 굴리고, 안전영역·가상 키보드·RTL·터치 타깃을 스스로 챙긴다. 프리셋 열넷 — 기본·sci-fi·중세·Material 3·어린이·코믹·아케이드, 각각 다크·라이트 두 가지 — 이 한 줄로 색과 모양을 함께 바꾼다.

새로 추가: 아케이드, 코믹, Material 3, 어린이용 생김새

기본·sci-fi·중세에 새 계열 넷이 더해졌다 — 이제 기본 제공 생김새가 열넷이고, 각각 다크와 라이트가 있다. 모든 위젯·팝업·HUD 부품이 코드를 한 줄도 고치지 않고 그대로 받는다: 프리셋을 바꾸면 화면 전체가 따라온다.

Material 3 — 앱 화면용

Material 3 Expressive 를 공식 M3 토큰과 대조해 맞췄다: 48dp 터치 타깃 안에 40dp 판을 둔 알약 버튼, 28dp 대화상자와 시트, 채운 카드, 외곽선 입력란, Expressive 슬라이더. 앱 컴포넌트 — 내비게이션 바, 앱 바, FAB, 검색 바, 칩, 진행 표시, 날짜 선택기 — 는 M3 컴포넌트 토큰을 따르고, 제목은 함께 들어 있는 Roboto 로 쓴다. 상점, 설정, 받은 편지함 등 앱다운 느낌이 필요한 모든 화면에 쓴다.

어린이 — 장난감 상자

어린이를 위해 만들었다: 모든 키·줄·패널이 굵은 테두리에 단단한 턱이 달린 젤리 사탕이고, 누르면 그 턱이 쏙 들어간다. 컨트롤마다 자기 크레파스 색을 입는다. 퀵슬롯은 사탕 블록, 배지는 스티커, 조이스틱은 무지개다. 창에는 햇살처럼 노란 제목 리본과 둥근 사탕 닫기 버튼이 붙고, 누르면 말랑하게 찌그러진다. 치수와 프로젝트 글꼴은 조금도 바뀌지 않는다.

코믹 — 굵은 잉크

모든 면이 만화책의 칸이다: 굵은 잉크 테두리 안에 표면 색을 채우고, 뒤에 딱딱한 그림자를 깔며, 면을 누르면 그 그림자가 사라진다. 설정 하나로 모든 그림자를 켜고 끄고, 두 개로 테두리 굵기와 그림자 크기를 정하며, 호출 하나로 위젯 하나에만 같은 일을 한다. 창에는 노란 제목 캡션이 붙는다.

아케이드 — 칠한 키

모든 키를 칠한다 — 그라데이션, 흰 광택, 누르면 쏙 들어가는 턱을 남색 잉크 테두리 안에 담고 — 라벨은 잉크 테두리를 두른 흰 글자다: 시작은 초록, 나머지는 파랑, 삭제는 빨강. 판은 두껍다. 옅은 안쪽 면을 색 테가 둘러싸고, 창에는 금색 제목 배너와 둥근 빨간 닫기 키가 붙는다.

GoUi.use_preset(GoThemePresets.MATERIAL_LIGHT)   # 또는 MATERIAL_DARK
GoUi.use_preset(&"kids_light")                   # 또는 &"kids_dark"
GoUi.use_preset(&"comic_light")                  # 또는 &"comic_dark"
GoUi.use_preset(&"arcade_light")                 # 또는 &"arcade_dark"

아케이드: 칠한 키와 두꺼운 판

가장 새로운 생김새는 모든 화면을 오락실 게임기처럼 꾸민다. 모든 키를 칠한다 — 위는 밝고 아래로 갈수록 짙어지는 그라데이션, 캔디 광택(위쪽 절반의 윤기와 양쪽 위 모서리의 반짝임), 누르면 쏙 들어가는 턱을 모두 남색 잉크 테두리 안에 담은 알약 모양이고 — 라벨은 잉크 테두리를 두른 흰 글자다. 탭은 서로 떨어져 서고, 게이지는 잉크 눈금으로 여러 칸으로 나뉘며, 키 힌트는 키캡이고, 창 제목은 제비꼬리 금색 리본 위에 앉는다. 모든 판은 두껍다: 옅은 안쪽 면을 자기 광택을 지닌 색 테가 둘러싼다. arcade_light 는 하늘색 페이지에 흰 판을, arcade_dark 는 밤 페이지에 남색 판을 놓는다. 아래 그림은 모두 실제 gohud 화면이다 — 같은 코드에 프리셋 한 줄만 다르다. 

GoUi.use_preset(&"arcade_light")   # 또는 &"arcade_dark"

모든 키를 칠한다

밤에는: arcade_dark

어두운 페이지에서는 잉크가 훨씬 짙어져 페이지 자체가 되고, 칠한 색은 그대로 선명하다.

아케이드 생김새가 동작하는 방식

면

모든 키와 판은 GoStyleBoxArcade 다: 잉크 테두리, 그라데이션 몸통, 턱, 광택을 컨트롤 자신의 사각형 안에 그린다 — 키는 상태가 바뀌어도 크기가 그대로이고, 누르면 쏙 들어갈 뿐이다.

잘 읽히는 라벨

잉크 테두리를 두른 흰 라벨은 그 테두리가 떼어 놓는 어떤 색 위에서도 읽힌다 — WCAG 는 테두리를 글자의 일부로 친다. 모든 칠한 색은 그라데이션의 어느 높이에서든 라벨이 4.6:1 을 넘을 때까지 옮겨진다.

창

창 제목은 잉크 테두리를 두른 흰 글자로 금색 배너 위에 놓이고, 옆에 둥근 빨간 닫기 키가 붙는다. 대화상자, 시트, 서랍, 팝오버는 테를 두른 두꺼운 판이다.

키 하나는 자기 색을 따로 입을 수 있다 — 일시 정지 메뉴의 주황색 상점 키처럼:

menu.add_child(GoStyle.arcade_paint(GoStyle.button("Shop", _shop), Color("#FF8A1E")))

코믹: 굵은 잉크와 딱딱한 그림자

코믹 생김새는 모든 면을 만화책의 칸처럼 그린다 — 굵은 잉크 테두리 안에 표면 색을 채우고, 오른쪽 아래로 딱딱하고 꽉 찬 그림자를 드리운다. comic_light 는 종이 크림색 페이지 위에 검은 잉크로 그리고 주 색은 코발트색이다. comic_dark 는 밤 페이지 위에 크림색 잉크로 그리고 주 색은 노란색이다. 아래 그림은 모두 실제 gohud 화면이다 — 같은 코드에 프리셋 한 줄만 다르다. 

GoUi.use_preset(&"comic_light")   # 또는 &"comic_dark"

모든 위젯이 잉크를 입는다

버튼, 토글, 탭, 슬라이더, 카드, 폼, 표, 선택기, 칩이 모두 잉크를 입는다 — 하나하나 스타일을 줄 필요가 없다. 키를 누르면 그림자가 사라지고 면이 도장처럼 제자리로 쏙 들어간다. 비활성 면은 그림자를 잃고 흐려지므로, 누를 수 있는 것과 없는 것이 한눈에 구별된다.

밤에는: comic_dark

어두운 페이지에서는 검은 테두리가 보이지 않으므로, comic_dark 는 테두리를 크림색으로 그리고 같은 잉크 색을 띤 옅은 그림자를 드리운다. HUD 부품 — 퀵슬롯, 막대, 조이스틱, 보상 달력 — 도 같은 규칙을 따른다.

코믹 생김새가 동작하는 방식

모든 면에 StyleBox 하나

모든 면은 GoStyleBoxComic 이다: 채움, 테두리, 그림자를 컨트롤 자신의 사각형 안에 그린다. 그릴 때마다 GoConfig 에서 테두리와 그림자 크기를 읽으므로, 설정 하나로 화면 전체가 한꺼번에 바뀐다.

누르면 납작해진다

누른 키는 그림자를 내려놓고 그 자리로 옮겨 간다. 호버 때는 그림자가 남고, 포커스는 테두리를 절대 덮지 않는 안쪽 잉크 고리를 더하며, 비활성 면은 그림자를 잃고 흐려진다.

나머지는 스킨이 칠한다

GoSkinComic 은 코드가 그리는 것에 잉크를 입힌다: 퀵슬롯, 칩, 배지, 아바타, 알림, 내비게이션 바, FAB, 날짜 칸, 그리고 손잡이가 그림자를 드리우는 조이스틱.

창에는 캡션이 붙는다

창 제목은 만화의 내레이션 상자 같은 노란 캡션 위에 놓이고, 옆에 잉크를 입힌 둥근 닫기 버튼이 붙는다. 대화상자, 시트, 서랍, 팝오버는 불투명한 잉크 패널이다.

낮에도 밤에도 잘 읽힌다

두 팔레트 모두 다른 모든 프리셋과 똑같은 WCAG 대비 검사를 통과한다. 눌린 키와 비활성 키도 포함이다. 캡션 색이 페이지와 너무 가까워지면 그 테두리는 페이지 색으로 물러난다.

배치는 바뀌지 않는다

테두리와 그림자는 각 컨트롤 안에 들어가고 안쪽 여백은 테마가 준 그대로이므로, 다른 생김새로 배치한 화면은 그 배치를 그대로 지킨다 — 프로젝트 글꼴도 마찬가지다.

설정 셋과 호출 하나

GoConfig 설정 셋이 모든 코믹 면을 한꺼번에 바꾼다. 다시 만드는 것은 없다 — 값을 넣는 대로 화면이 다시 그려진다.

GoUi.config.comic_border_width = 2.0   # 테두리(dp) — 기본값 3
GoUi.config.comic_shadow_size = 6.0    # 그림자(dp) — 기본값 4
GoUi.config.comic_shadow = false       # 어디에도 그림자 없음

위젯 하나는 설정과 상관없이 따로 갈 수 있다. 마지막 인수로 true 를 넘기면 그 안의 모든 것까지 포함한다.

GoStyle.comic_shadow(skip_button, false)     # 이 버튼은 납작하게
GoStyle.comic_shadow(card, true, true)       # 이 카드와 그 안의 모든 것은 그림자 유지
GoStyle.comic_border(title, 5.0)             # 이것만 테두리를 더 굵게
나만의 코믹 만들기. tools/new_theme.py inked --from comic_light 가 팔레트를 복사한다. 종이·잉크·주 색을 바꾸고 tools/make_theme.py inked 를 실행하면 된다. 잉크, 그림자, 스킨이 함께 따라온다.

중세·sci-fi 프리셋 — 캐릭터 정보·인벤토리·퀘스트, 폼·격자·안내 카드, 각진 패널과 터치 조작. 프리셋을 바꾸는 것은 코드 한 줄이다.

프리셋 열넷과 바꾸는 법 →

무엇을 대신해 주는가

게임 UI 에서 시간을 가장 많이 잡아먹는 것은 버튼 모양이 아니라, 기기마다 다르게 어긋나는 것들이다. gohud 는 그 어긋남을 한곳에서 처리한다.

모든 치수가 토큰이다

여백·모서리·글자 크기를 숫자로 쓰지 않고 이름으로 부른다. 테마를 갈아 끼우면 화면 전체가 함께 움직인다.

보이는 크기와 누르는 크기가 다르다

닫기 버튼은 36dp 로 보이지만 터치 타깃은 48dp 다. 슬롯이 촘촘히 깔려도 겹친 자리는 중심이 가까운 쪽이 가져간다.

노치와 키보드를 피한다

안전영역 안에 HUD 를 붙이고, 가상 키보드가 올라오면 입력 칸이 그 위로 올라온다.

뒤로 가기가 하나씩 닫힌다

Escape 와 Android 뒤로 가기가 가장 위 창 하나만 닫는다. 겹쳐 띄운 창이 한꺼번에 사라지지 않는다.

알림은 입력을 훔치지 않는다

스낵바 위를 눌러도 그 아래 버튼이 눌린다. 포커스도 가져가지 않는다.

아이콘은 이름으로 부른다

위젯은 GoIconSet.CLOSE 처럼 이름만 안다. 세트를 갈아 끼우면 코드를 한 줄도 안 고치고 그림이 바뀐다. 아이콘 →

생김새 열넷, 코드 한 줄

GoUi.use_preset() 이 테마·스킨·아이콘을 함께 바꾼다 — 둥근 패널, 모서리를 자른 sci-fi, 단조 프레임의 중세, Material 3 앱 컴포넌트, 어린이의 젤리 사탕, 코믹 잉크, 아케이드 칠.

읽히는지는 잰다

모든 테마를 WCAG 로 잰다. 버튼 상태별 패널, 순백·순흑 위에 얹힌 반투명 HUD 패널까지.

플러그인을 켜지 않아도 전부 동작한다. 켜면 GoRuntime 오토로드가 붙어 창 크기·dp 배율·가상 키보드 높이를 추적하고, 설정 리소스와 프리셋을 고르는 프로젝트 설정이 생긴다 — 편의일 뿐 필수가 아니다.

gohud 설치

길은 둘이다. AI 에게 시키거나, 폴더를 프로젝트에 넣거나 — 그 밖에 설정할 것은 없다.

설치

빠른 시작

다섯 줄이면 테마가 입혀진 화면이 뜬다. 처음부터 끝까지는 설치 페이지에 있다.

빠른 시작

생김새 바꾸기 — 색뿐 아니라 모양까지

Theme 는 엔진이 그려 주는 것의 모양만 바꾼다. StyleBoxFlat 의 모서리는 둥근 것뿐이고, 조이스틱·퀵슬롯·코치마크는 코드가 직접 그리므로 테마를 아무리 갈아 끼워도 모양이 안 바뀐다. 그래서 gohud 는 테마·스킨·아이콘을 한 단위로 고르는 프리셋을 쓴다. 

GoUi.use_preset(GoThemePresets.MEDIEVAL_DARK)   # 테마·스킨·아이콘이 한꺼번에
프리셋생김새

스킨 — 테마가 닿지 못하는 자리

GoSkin 은 조이스틱, 퀵슬롯 패널, 코치마크 링, 칩, 스켈레톤, 알림 상자, 분절 선택, 구분선의 모양을 맡는다. 상속해서 바꾸고 싶은 것만 덮어쓰면 나머지는 기본 모양 그대로다. 

class_name MySkin extends GoSkin

func slot_box(accent: Color, lit: bool) -> StyleBox:
    var box := GoStyleBoxCut.new()
    box.bg_color = accent
    box.cut = 6.0
    box.edge_color = accent          # 위쪽 강조선
    return box

func draw_joystick(canvas: CanvasItem, center: Vector2, knob: Vector2,
        radius: float, knob_radius: float, ink: Color, base: Color, active: bool) -> void:
    canvas.draw_circle(center, radius, Color(base, 0.4))
    canvas.draw_circle(knob, knob_radius, ink)
클래스낼 수 있는 모양
GoStyleBoxCut모서리를 사선으로 자른 패널(챔퍼), 한 변만 굵은 강조선, 바깥으로 번지는 발광
GoStyleBoxBracket테두리를 두르지 않고 네 모서리만 짧게 긋는 조준 표식
GoStyleBoxMedieval리벳·모서리 각인·베벨 반사·재질 질감이 있는 단조 프레임
GoStyleBoxJelly젤리 사탕 — 굵은 테두리, 누르면 쏙 들어가는 단단한 턱, 위쪽이 더 밝은 몸통과 흰 광택
GoStyleBoxComic만화책의 칸 — 굵은 잉크 테두리와 딱딱한 드롭 섀도, 둘 다 게임이 도는 중에 GoConfig 로 크기를 정한다
GoStyleBoxArcade오락실 게임기의 키나 판 — 그라데이션 몸통, 흰 광택, 누르면 쏙 들어가는 턱, 잉크 테두리. 판은 옅은 안쪽 면을 두꺼운 색 테로 두른다

여섯 모두 여느 StyleBox 처럼 Theme 리소스 안에 그대로 저장된다 — 즉 테마가 모양을 바꿀 수 있다. GoSkinSciFi·GoSkinMedieval·GoSkinMaterial·GoSkinKids·GoSkinComic·GoSkinArcade 가 함께 들어 있는 상속 예다.

GoStyle.box() 는 언제나 StyleBoxFlat 을 돌려준다. 돌려받아 bg_color 나 corner_radius 를 고치는 옛 호출부와의 약속이기 때문이다. 커스텀 모양을 지켜야 하면 GoStyle.surface() 를 쓴다.

읽히는지는 눈대중이 아니라 잰다

"예쁘다" 는 취향이지만 "읽힌다" 는 잴 수 있다. 흐린 회색 글씨는 좋은 모니터에서 멀쩡해 보이고 한낮의 폰에서는 사라진다 — 눈으로 고르면 언젠가 반드시 그렇게 된다. 

python3 addons/gohud/tools/check_contrast.py

색 짝 전부와 버튼 상태마다의 글자와 그 글자가 얹힌 패널을 열네 테마 모두에서 WCAG 로 잰다. 반투명 색은 실제 배경에 합성한 뒤에 잰다 — 그대로 재면 화면에 보이는 것보다 좋은 비율이 나온다.

그래서 글자 색은 고르는 것이 아니라 끌어낸다 — 빌더가 팔레트 값을 출발점으로 삼아, 그 글자가 놓일 수 있는 모든 표면에서 기준을 넘길 때까지 밝기를 민다. 팔레트를 바꾸면 대비가 따라온다. 규칙과 그 뒤의 함정 →

진입점 하나가 검사 전부를 돌린다. 검사마다 볼 수 있는 범위가 다르다.

bash addons/gohud/tools/check_all.sh
검사잡는 것
run_tests.sh 네 화면 크기위젯 동작·배치, RTL 위치, 키보드 포커스, 스킨이 실행 중에 만드는 색의 대비, 프리셋 전부
new_project_check.sh호스트 프로젝트에 몰래 기대는 것. --zip 이면 배포본 그대로, --export 면 Web 빌드까지

check_generated.py · check_scaffold.sh생성된 테마가 팔레트와 맞는가, 임시 테마가 만들어지고 대비를 통과하는가

배포 버전

cat addons/gohud/package.json       # { "version": "1.1.0" }
bash addons/gohud/tools/release.sh  # 검사 전부 → ZIP → 빈 프로젝트에서 검증
bash addons/gohud/tools/package.sh  # 1.1.0 → builds/1.1.0/gohud-1.1.0.zip

버전은 package.json 에 적힌 값이다 — 패키징이 올리지 않는다. 새 버전을 내려면 먼저 그 숫자를 바꾼다. 성공하면 plugin.cfg·GoUi.VERSION 을 그 값으로 맞추고, 그 버전을 처음 패키징할 때만 CHANGELOG.md 의 Unreleased 항목을 날짜 붙은 버전으로 옮긴다. 같은 버전을 다시 패키징하면 ZIP 을 새로 만들어 이전 것과 바꾼다. 실패하면 아무것도 바뀌지 않는다. ZIP 에는 이 사이트·검사·도구와 package.json 이 들어가지 않는다.
