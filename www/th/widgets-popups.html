ป๊อปอัปและกล่องโต้ตอบ

ป๊อปอัปทุกแบบของ gohud — เลือกแบบไหน เปิดและปิดอย่างไร จัดการปุ่มย้อนกลับและการป้อนข้อมูลอย่างไร ในทุกรูปลักษณ์ ← วิดเจ็ต

วิดเจ็ต วิดเจ็ตทั้งหมด ป๊อปอัปและกล่องโต้ตอบ หน้าต่างลอย การบอกอะไรบางอย่างกับผู้เล่น HUD การรอ การบอก การนับ ฟอร์มและรายการ รูปทรงที่เกมใช้จริง ทับอยู่บนหน้าจอ GoStyle — ที่เดียวที่ทุกอย่างถูกสร้างขึ้น

เลือกป๊อปอัปให้ถูกแบบ

ป๊อปอัปคือการขัดจังหวะ ก่อนเลือกสักแบบ ให้ตอบคำถามข้อเดียว: ผู้เล่นต้องตอบก่อนที่เกมจะ ไปต่อหรือไม่? ถ้าใช่ ให้บล็อก ถ้าไม่ใช่ อย่าบล็อกเด็ดขาด — การ์ดที่หยุดเกมเพื่อแจ้งข่าวที่ผู้เล่นไม่ได้ขอ คือวิธีที่เร็วที่สุดที่จะทำให้เขาปิดเกมของคุณ

  1. คำถามที่มีคำตอบ — ซื้อ ลบ ออกจากเกม เขียนทับ → GoDialogs.confirm() สิ่งที่ต้องรับทราบ → alert() เลือกหนึ่งจากไม่กี่ตัวเลือก → choose()
  2. หน้าจอของมันเอง — การตั้งค่า แผ่นข้อมูลตัวละคร ไอเทมในร้านค้า → GoSurface กลางหน้าจอ
  3. รายการยาวหรือหน้าจัดการ — กระเป๋า จดหมาย เพื่อน → GoSheet จากด้านล่างบนมือถือ หรือ GoDrawer จากด้านข้างบนจอกว้าง
  4. เรื่องของสิ่งที่เพิ่งถูกกด — ค่าสถานะของไอเทม สิ่งที่ทำกับมันได้ → GoPopover หรือ GoContextMenu ข้าง ๆ มัน
  5. ข่าวที่เกมเล่นต่อไปได้ — บันทึกแล้ว ทิ้งของแล้ว ได้รับคำเชิญ → GoSnackbar, GoNotice หรือ GoPromptCard สิ่งเหล่านี้ไม่ยึดหน้าจอเลย
  6. สอนวิธีควบคุม → GoCoachMark สูตรโกงระหว่างพัฒนา → GoConsole

ป๊อปอัปทั้งหมดในแวบเดียว

ป๊อปอัปหยุดเกมย้อนกลับ / Escapeแตะข้างนอกใช้กับ
GoDialogs confirm · alertใช่ปิด — confirm ตอบ false ส่วน alert คืนกลับมาปิดเฉพาะเมื่อมี dismiss_on_scrimคำถามที่ต้องการคำตอบ
GoDialogs.chooseใช่ปิด — ตอบ -1ปิดเฉพาะเมื่อมี dismiss_on_scrimเลือกหนึ่งจากไม่กี่ตัวเลือก
GoSurfaceใช่ขอให้ปิดอันบนสุดขอให้ปิดเมื่อมี dismiss_on_scrimหน้าต่างของคุณเอง
GoSheetใช่ปิดทั้งชีตปิดกระเป๋า รายการในร้านค้า จดหมาย
GoDrawerใช่เฉพาะปุ่มย้อนกลับของ Androidปิดรายการด้านข้างบนจอกว้าง
GoPopoverจนกว่าจะปิดปิดปิด — และไม่ส่งต่อไปไหนอีกรายละเอียดไอเทมและสกิล

GoContextMenu · ดรอปดาวน์ · ซีเล็กต์ตามเมนูของเอนจินตามเมนูของเอนจินปิดการกระทำ รายการสั้น ๆ
GoSnackbarไม่—ส่งถึงเกมบันทึกแล้ว · เลิกทำ · ลองใหม่
GoPromptCardไม่—ส่งถึงเกมคำเชิญ คำขอแลกเปลี่ยน
GoNoticeไม่เลย—ส่งถึงเกมบรรทัดประจำที่บน HUD
GoBannerไม่ — มันอยู่ในหน้า——"คุณออฟไลน์อยู่ ลองใหม่"
GoCoachMarkเฉพาะการ์ดของมันจบทัวร์ส่งถึงเกมทัวร์ตอนเปิดเกมครั้งแรก
GoConsoleเฉพาะพาเนลของมันปุ่ม Escape ปิดมันส่งถึงเกมคำสั่งดีบัก

แต่ละอันเปิดบนเลเยอร์ไหน และทำไมจึงเรียงลำดับแบบนั้น ดูได้ที่ เลเยอร์ ปุ่มย้อนกลับ และอินพุต

ทุกภาพในหน้านี้คือเกมเล็ก ๆ เกมเดียวกัน — พลังชีวิตและมานาที่มุมซ้ายบน เหรียญที่มุมขวาบน จอยสติ๊กและ ควิกสล็อตสามช่องที่ด้านล่าง — ในพรีเซ็ต default_dark โดยมีป๊อปอัปหนึ่งอันเปิดทับอยู่ ป๊อปอัป เดียวกันในทั้งสิบสองลุค →

กายวิภาคของป๊อปอัป

ป๊อปอัปแบบบล็อกเกือบทุกตัวใน gohud — ไดอะล็อก ชีต ป๊อปโอเวอร์ รายการของคอมโบบ็อกซ์ และหน้าต่าง ของคุณเอง — คือโหนดเดียวกัน คือ GoSurface เรียนรู้ส่วนประกอบของมันครั้งเดียว แล้วคุณจะรู้จักทุกตัว

ส่วนประกอบคืออะไรเข้าถึงอย่างไร
เลเยอร์CanvasLayer ที่ป๊อปอัปอาศัยอยู่ หมายเลขของมันเป็นตัวตัดสินว่ามันบังอะไรบ้างคุณกำหนดเองสำหรับ GoSurface ส่วนตัวอื่นกำหนดไว้ในตัว (ตาราง)
ม่านม่านที่คลุมทุกอย่างข้างหลัง คอยรับการแตะที่พลาดตัวการ์ดscrim_transparent, dismiss_on_scrim, สี scrim ของธีม
การ์ดตัวหน้าต่างเอง — หน้าพาเนลของธีม จะมน ตัดมุม ตีขึ้นรูป หรือเป็นเยลลี่ ก็แล้วแต่ลุคcard, alpha
ส่วนหัวปุ่มย้อนกลับ (ถ้าต้องการ) ชื่อเรื่อง (ไม่เกินสองบรรทัด เกินนั้นเป็น "…") และปุ่มปิดset_title() · set_title_key() · set_back() · close_enabled · show_header
แถบเครื่องมือแถวที่ตรึงไว้ใต้ส่วนหัว — ช่องค้นหา ชิปตัวกรอง ซ่อนอยู่จนกว่าคุณจะใช้toolbar
เนื้อหาส่วนที่เลื่อนได้ ใส่เนื้อหาไว้ที่นี่body · scroll_body · clear()
บรรทัดสถานะบรรทัดที่ตรึงไว้ระหว่างเนื้อหากับส่วนท้าย — "ตรวจชื่อไม่ผ่าน" "กำลังบันทึก…"set_status_text() · set_status_key() · clear_status()
ส่วนท้ายปุ่มที่ตรึงไว้ด้านล่าง ซ่อนอยู่จนกว่าคุณจะใช้footer
ของที่ต้องอยู่กับที่ ให้ใส่ในแถวที่ตรึงไว้ ช่องค้นหา ข้อความผิดพลาด หรือปุ่มบันทึกที่ใส่ไว้ในเนื้อหา จะเลื่อนหายไปพร้อมรายการยาว ๆ — ผู้เล่นพิมพ์ชื่อผิด ข้อความผิดพลาดอยู่ใต้ขอบจอ แล้วดูเหมือนไม่มีอะไรเกิดขึ้นเลย ใช้ toolbar บรรทัดสถานะ และ footer เพราะมันอยู่กับที่ขณะที่เนื้อหาเลื่อน

ไดอะล็อกที่ await ได้

GoDialogs ถามแล้วรอ โหนดเดียว สามคำถาม — และคำตอบกลับมาที่บรรทัดเดิม โค้ดจึงอ่านเรียงตามลำดับเดียวกับที่ผู้เล่นได้สัมผัส

var dialogs := GoDialogs.new()
add_child(dialogs)

if await dialogs.confirm("Buy the starter pack?", "300 gems for a sword, a shield and 10 potions.",
        "Buy", "Not now"):
    buy_starter_pack()

สามคำถาม

confirm(title, body, ok_text := "", cancel_text := "", extra := "",
        args := {}, destructive := false) -> bool
alert(title, body, ok_text := "", extra := "", args := {})      # ใช้ await เพื่อรอ
choose(title, options: Array, cancel_text := "", translate := false) -> int
confirm_key(…) · alert_key(…)                                 # รับคีย์คำแปล
การเรียกคืนค่าใช้กับ
confirm()true หรือ falseใช่หรือไม่ — ซื้อ ลบ ออกจากเกม เขียนทับ
alert()ไม่คืนค่า — await มันเพื่อรอสิ่งที่ผู้เล่นต้องเห็น: รางวัล การเชื่อมต่อที่หลุด
choose()ดัชนีของตัวเลือก หรือ -1หนึ่งจากไม่กี่ตัวเลือก ตัวเลือกหนึ่งตัวคือ String หรือ {text, icon, danger, subtitle}
confirm_key() · alert_key()เหมือนข้างบนแบบเดียวกันแต่ใช้คีย์คำแปล — ข้อความเปลี่ยนตามเมื่อเปลี่ยนภาษาขณะที่ไดอะล็อกเปิดอยู่

ป้ายปุ่มที่ปล่อยว่างจะย้อนกลับไปใช้คำของชุดเอง (confirm, cancel ใน GoConfig.text_keys) extra จะถูกต่อท้ายเนื้อความในบรรทัดใหม่ args เติม {placeholders} ทั้งในชื่อเรื่อง และเนื้อความ: confirm("Buy {item}?", "It costs {price} gold.", "Buy", "", "", {"item": name, "price": 300})

ทุกทางออกมีคำตอบ

ผู้เล่น…confirmalertchoose
กด OK / กดตัวเลือกtrueคืนกลับมาดัชนีของตัวเลือก
กดยกเลิกfalse—-1
กด × Escape หรือปุ่มย้อนกลับของ Androidfalseคืนกลับมา-1
แตะม่าน (เฉพาะเมื่อมี dismiss_on_scrim)falseคืนกลับมา-1
โหนด GoDialogs ออกจากทรีfalseคืนกลับมา-1

โค้ดหลัง await จึงได้ทำงานเสมอ — ไม่มีคำถามไหนถูกปล่อยค้างไว้ แม้ฉากจะเปลี่ยนไปใต้ไดอะล็อกก็ตาม

การกระทำที่ย้อนกลับไม่ได้

ส่ง destructive = true สำหรับสิ่งที่ย้อนกลับไม่ได้ ปุ่ม OK จะกลายเป็นปุ่มทึบ Tone.DANGER_SOLID — ตัวอักษรขาวบนพื้นแดงในทุกลุค ในขณะที่ป้ายข้อความสีอันตรายแบบย้อมสี ต้องเข้มลงจนเกือบดำบนธีมสว่างจึงจะยังอ่านออก โทนสีถูกรีเซ็ตทุกครั้งที่เรียก เพราะหน้าต่างถูกใช้ซ้ำ

if await dialogs.confirm("Delete this save?", "Slot 2 — Aria, level 12. This cannot be undone.",
        "Delete", "Keep it", "", {}, true):
    delete_save(2)
OK ได้โฟกัสคีย์บอร์ด กล่องยืนยันทุกอันเปิดขึ้นมาโดยปุ่ม OK มีโฟกัส การกด Enter หรือ Space จึงเป็นการยืนยัน — รวมถึงแบบย้อนกลับไม่ได้ด้วย ตั้งชื่อปุ่มให้ทางเลือกที่ปลอดภัยเห็นได้ชัด ("เก็บไว้") และเก็บการกระทำที่ย้อนกลับไม่ได้ ไว้หลังขั้นตอนที่สอง เมื่อการพลาดเพียงครั้งเดียวทำให้ผู้เล่นเสียความคืบหน้าจริง ๆ

การจัดวางปุ่ม

action_layoutทำอะไร
VERTICAL (ค่าเริ่มต้น)ปุ่มซ้อนกันลงมา เต็มความกว้าง ปลอดภัยกับทุกภาษา — ป้ายภาษาเยอรมันหรือรัสเซียยาว ๆ ไม่มีวันถูกบีบ
HORIZONTALแถวเดียว ปุ่มละครึ่งความกว้าง
AUTOแถวเดียวก็ต่อเมื่อป้ายทั้งสองพอดีกับครึ่งการ์ดในบรรทัดเดียว ไม่อย่างนั้นก็ซ้อนกัน ตัดสินใหม่ทุกครั้งที่เปลี่ยนภาษาหรือปรับขนาด

action_gap คือช่องไฟระหว่างปุ่ม ส่วน body_gap คือช่องไฟเหนือปุ่ม — ตั้งให้กว้างกว่า ช่องไฟระหว่างปุ่ม เพื่อให้คำถามกับตัวเลือกอ่านออกมาเป็นสองส่วน ถ้าจะเปลี่ยนเฉพาะไดอะล็อกเดียว ให้เรียก set_next_action_layout() ก่อนเปิดมัน ปุ่มเดียวของ alert ใช้ความกว้างเต็มเสมอ

ทีละอัน

การเรียก confirm() ครั้งที่สองขณะที่ยังมีอันหนึ่งเปิดอยู่ จะคืนค่า false ทันที — ไดอะล็อก ไม่มีทางซ้อนบนไดอะล็อกโดยไม่ตั้งใจ เปิด queue_when_busy แล้วมันจะรอคิวแทน ส่วน alert() รอคิวเสมอ queue_limit (8) จำกัดความยาวคิว และเมื่อคิวล้น คำขอที่เก่าที่สุดจะได้คำตอบ false pending() นับคำขอที่รออยู่ และ clear_pending() ตอบ false ให้ทั้งหมด choose() ไม่เข้าคิวเลย: มันคืนค่า -1 เมื่อมีไดอะล็อกเปิดอยู่แล้ว

มือถือและเดสก์ท็อป

choose() เปิดเป็นชีตจากด้านล่างบน Android และ iOS — ตรงที่นิ้วโป้งอยู่ — และเป็นการ์ดกลางจอ บนเดสก์ท็อป กล่องยืนยันกว้างไม่เกิน max_width (420dp) และจัดกึ่งกลาง ตั้ง layer_index, max_width และค่า export อื่น ๆ ก่อน add_child เพราะค่าเหล่านี้ถูกนำไปใช้ตอนที่โหนดเข้าสู่ทรี

var picked := await dialogs.choose("Sort the bag by", [
    {"text": "Newest first", "icon": GoIconSet.CLOCK},
    {"text": "Rarity", "icon": GoIconSet.STAR},
    {"text": "Drop everything", "icon": GoIconSet.TRASH, "danger": true}])
if picked >= 0:
    sort_bag(picked)

GoSurface — หน้าต่างของคุณเอง

เมื่อป๊อปอัปเป็นมากกว่าคำถาม — การตั้งค่า แผ่นข้อมูลตัวละคร ไอเทมที่จะซื้อ — ให้สร้างบน GoSurface เซฟแอเรีย คีย์บอร์ด แถวที่ตรึงไว้ การเลื่อน ปุ่มย้อนกลับ โฟกัส และการปรับขนาด จัดการไว้ให้หมดแล้ว

var layer := CanvasLayer.new()
layer.layer = 50
add_child(layer)

var window := GoSurface.new()
window.set_title("Settings")
window.close_requested.connect(layer.queue_free)
window.body.add_child(GoStyle.toggle("Music", false))
window.body.add_child(GoStyle.slider(0.0, 1.0, 0.05))
var row := GoStyle.row()
row.add_child(GoStyle.button("Cancel", window.request_close))
row.add_child(GoStyle.button("Save", save_and_close, GoStyle.Tone.PRIMARY))
window.footer.add_child(row)
window.footer.visible = true
layer.add_child(window)
มันไม่ปิดตัวเอง × , Escape ปุ่มย้อนกลับ และการแตะม่าน ทำแค่ส่ง close_requested ออกมา การซ่อนหรือ คืนหน่วยความจำของหน้าต่างเป็นหน้าที่ของหน้าจอที่เป็นเจ้าของ — มีแต่มันที่รู้ว่า "ปิด" หมายถึงบันทึก ทิ้ง หรือถามก่อน

สามตำแหน่งการวาง

ANCHOR ต้องมี anchor_control การ์ดจะไปอยู่ทางขวาของมันถ้า anchor_min_width พอดี ไม่อย่างนั้นไปด้านที่กว้างกว่า ไม่อย่างนั้นก็อยู่ภายในหน้าจอ และจะเปิดขึ้นด้านบนเมื่อด้านบนมีที่มากกว่า มันตาม จุดตรึงที่เคลื่อนที่ทุกเฟรม anchor_width (320) และ anchor_max_height (520) กำหนดขนาดของมัน

GoSheet — หน้าที่มาจากด้านล่าง

var sheet := GoSheet.new()
add_child(sheet)

func show_bag(items: Array) -> void:
    sheet.open("Bag")
    var search := GoStyle.line_edit("Search the bag…")
    search.text_changed.connect(filter_bag)
    sheet.toolbar().add_child(search)
    sheet.toolbar().visible = true
    for item in items:
        sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, show_item.bind(item),
            Color.TRANSPARENT, item.description, false, GoIconSet.CHEVRON_RIGHT))
    sheet.add_footer(GoStyle.button("Close", sheet.close, GoStyle.Tone.PRIMARY))
  • มันคือ CanvasLayer (เลเยอร์ 10) ที่ถือ GoSurface แบบ BOTTOM ที่ปรับขนาดได้ — มันจึง อยู่เหนือ HUD และผู้เล่นลากให้สูงขึ้นได้
  • open(title) เริ่มหน้าใหม่: ล้างเนื้อหา แถบเครื่องมือ และปุ่มย้อนกลับ และคืนหน่วยความจำของสิ่งที่ add_footer() เพิ่มไว้ เรียกอีกครั้งเพื่อแสดงหน้าอื่นในชีตเดิม set_back() แสดงปุ่มย้อนกลับ ไว้เป็นทางกลับ ส่วน open_key() รับคีย์คำแปล
  • close() ซ่อนมัน — ไม่ได้คืนหน่วยความจำ open() ครั้งถัดไปจึงเปิดได้ทันที closed และ page_changed บอกคุณว่าเกิดขึ้นเมื่อไร
  • height_ratio (0.6) คือความสูงตอนเปิด max_height_ratio ยกเพดานขึ้น ส่วน dismissable (true) ปิดมันเมื่อแตะม่าน
Escape และปุ่มย้อนกลับปิดทั้งชีต แม้อยู่ในหน้าย่อยที่มี set_back() — มีแต่ปุ่มย้อนกลับบนหน้าจอ ที่ถอยกลับทีละหน้า ถ้าอยากให้ปุ่มย้อนกลับถอยทีละหน้า ให้จัดการ close_requested บน sheet.surface เอง

drawer.side = GoDrawer.Side.LEFT

  • open(title) เก็บเนื้อหาไว้ — เติมครั้งเดียวพอ set_title("") ซ่อนส่วนหัว motion_seconds (0.2) คือเวลาที่มันเลื่อนเข้ามา ส่วน reduce_motion ทำให้มันเปิดทันที

GoPopover — การ์ดบนสิ่งที่ถูกกด

slot.pressed.connect(func() -> void:
    var card := GoStyle.item_card({"icon": GoIconSet.POTION, "title": "Health potion",
        "subtitle": "Heals 50 HP · 12 left"}, false)
    GoPopover.open(slot, card, {"width": 280}))

surface แบบ ANCHOR ที่ต่อสายเลเยอร์ จุดตรึง และการเก็บกวาดไว้ให้แล้ว — สิบบรรทัดที่ทุกเกมต้องเขียน ซ้ำแล้วซ้ำอีก ทีละอัน: การเปิดอันที่สองจะปิดอันแรก เพราะการ์ดที่ซ้อนกันจะกลบหน้าจอจนไม่มีใครบอกได้ว่า การ์ดไหนเป็นของสล็อตไหน ม่านของมันโปร่งใส — การ์ดที่เปิดขึ้นมาเพื่อเทียบอุปกรณ์ต้องไม่ทำให้อุปกรณ์นั้นมืดลง — แต่ยังคงรับการแตะข้างนอกครั้งแรก ซึ่งจะปิดการ์ดและไม่ส่งต่อไปไหนอีก

GoPopover.close() และ GoPopover.is_open() เป็นแบบ static ส่วน open() คืนค่า surface — หรือ null เมื่อจุดตรึงไม่อยู่ในทรี จึงควรตรวจก่อนจะ await shown.close_requested

มันไม่ใช่ทูลทิปแบบเมาส์ชี้ การสัมผัสไม่มีสถานะ hover อะไรก็ตามที่มีแต่เมาส์เปิดให้เห็นได้ จะมองไม่เห็นเลยสำหรับ ผู้เล่นครึ่งหนึ่งของคุณ และเมื่อ dismissable = false และไม่มีชื่อเรื่อง ก็ไม่มีอะไรบนหน้าจอปิดมันได้ — มีแค่ Escape ปุ่มย้อนกลับ หรือการเรียกของคุณเอง

ใครเป็นเจ้าของปุ่มย้อนกลับ

  • มีแค่หน้าต่างบนสุดที่ตอบ ในบรรดาหน้าต่างที่เปิดอยู่ อันที่อยู่บนเลเยอร์สูงสุด (ถ้าเท่ากันก็อันล่าสุดในทรี) จะรับ Escape ปุ่มยกเลิกของเกมแพด (ui_cancel) ปุ่มย้อนกลับของ Android และการแตะม่าน หน้าต่างที่ซ้อนกัน ปิดทีละอัน ไม่ปิดพร้อมกัน
  • ปุ่มย้อนกลับของ Android ถูกจัดการช้าไปหนึ่งเฟรม การกดครั้งเดียวจึงไม่มีทางปิดสองหน้าต่าง
  • ขณะที่มีสิ่งที่เป็นเจ้าของปุ่มย้อนกลับเปิดอยู่ ปุ่มย้อนกลับของ Android จะไม่ปิดแอป (GoBackPolicy นับ เจ้าของ และคืนค่า quit_on_go_back หลังจากอันสุดท้ายปิด) ป๊อปอัปของคุณเองที่รับปุ่มย้อนกลับควรเรียก GoBackPolicy.acquire() และ release() — ใน _exit_tree ด้วย
  • ดรอว์เออร์ ทัวร์โค้ชมาร์ก และฟอร์ม จะหลีกทางขณะที่มีหน้าต่างเปิดอยู่ — ปุ่มย้อนกลับไปถึงหน้าต่างก่อน
  • GoConfig.close_on_back (เปิดอยู่) คือสวิตช์สำหรับหน้าต่าง

ใครรับการแตะ

  • หน้าต่างคลุมทั้งหน้าจอและหยุดอินพุต — แม้ม่านจะโปร่งใสก็ตาม ไม่มีอะไรบนเลเยอร์ที่ต่ำกว่าถูกกดได้ ขณะที่มันเปิดอยู่ ส่วนเลเยอร์ที่อยู่เหนือมัน (สแน็กบาร์) ยังกดได้
  • ล้อเมาส์และการบีบนิ้วก็หยุดที่หน้าต่างเช่นกัน: การเลื่อนเลยท้ายรายการไม่มีทางไปเลื่อนเกม
  • อินพุตของเกมเพลย์ที่ไม่ผ่านคอนโทรล — _unhandled_input สำหรับการเคลื่อนที่ การลากกล้อง — ควรหยุดไว้ก่อน: if GoSurface.is_any_open(): return ซึ่งครอบคลุมไดอะล็อก ชีต ป๊อปโอเวอร์ และคอมโบบ็อกซ์ ส่วนดรอว์เออร์ ต้องถาม is_open() แยกต่างหาก
  • สแน็กบาร์ ข้อความแจ้งเตือน พรอมต์การ์ด และโค้ชมาร์ก รับอินพุตเฉพาะบนการ์ดของตัวเอง ที่อื่นทั้งหมดเกมเป็นผู้รับ

โฟกัส

หน้าต่างที่เปิดด้วยพอยน์เตอร์จะไม่โฟกัสอะไรเลย — ไม่มีวงแหวนกะพริบเมื่อแตะ ถ้าเปิดจากคีย์บอร์ดหรือเกมแพด ปุ่มปิด (หรือ initial_focus) จะรับโฟกัส โฟกัสอยู่ภายในหน้าต่างตลอดที่เปิดอยู่ และกลับไปยังคอนโทรลที่ถือ โฟกัสไว้เมื่อหน้าต่างปิด ไดอะล็อกโฟกัสที่ OK ทุกครั้ง

การหยุดเกมชั่วคราว

การหยุดทรีชั่วคราวก็หยุดป๊อปอัปด้วย — มีแต่คอนโซลที่ยังทำงาน สำหรับเมนูหยุดชั่วคราว ให้ตั้ง process_mode = PROCESS_MODE_ALWAYS ให้เลเยอร์ของมัน แล้วหน้าต่าง ปุ่มในนั้น และปุ่มย้อนกลับจะยังทำงานขณะที่เกมหยุดอยู่

func open_settings() -> void:
    var layer := CanvasLayer.new()
    layer.layer = 50
    add_child(layer)
    var window := GoSurface.new()
    window.set_title("Settings")
    window.dismiss_on_scrim = true
    window.close_requested.connect(layer.queue_free)
    window.body.add_child(GoStyle.section("Sound", false))
    window.body.add_child(GoStyle.toggle("Music", false))
    window.body.add_child(GoStyle.slider(0.0, 1.0, 0.05))
    var row := GoStyle.row()
    row.add_child(GoStyle.button("Cancel", window.request_close))
    row.add_child(GoStyle.button("Save", func() -> void:
        save_settings()
        layer.queue_free(), GoStyle.Tone.PRIMARY))
    window.footer.add_child(row)
    window.footer.visible = true
    layer.add_child(window)

func pause() -> void:
    get_tree().paused = true
    var layer := CanvasLayer.new()
    layer.layer = 50
    layer.process_mode = Node.PROCESS_MODE_ALWAYS      # ยังทำงานต่อขณะที่เกมหยุดชั่วคราว
    add_child(layer)
    var menu := GoSurface.new()
    menu.set_title("Paused")
    menu.close_requested.connect(func() -> void:
        get_tree().paused = false
        layer.queue_free())
    menu.body.add_child(GoStyle.button("Resume", menu.request_close, GoStyle.Tone.PRIMARY))

หลุมพราง

  • GoSurface ไม่คืนหน่วยความจำตัวเองเลย ต่อ close_requested ไว้ ไม่อย่างนั้น × จะไม่ทำอะไร
  • ตัวเลือกที่ตั้งหลัง add_child — scrim_transparent, show_header, resizable, scroll_body และ layer_index กับ max_width ของ GoDialogs — จะไม่ถูกนำไปใช้
  • confirm() ครั้งที่สองคืนค่า false ทันที เปิด queue_when_busy ถ้าสองคำถามอาจมาชนกัน
  • Enter คือการยืนยัน OK มีโฟกัส บนไดอะล็อกแบบย้อนกลับไม่ได้ด้วย
  • ปุ่มย้อนกลับบนชีตปิดทั้งชีต ไม่ใช่แค่หน้าย่อย
  • Escape ไม่ปิดดรอว์เออร์ และ is_any_open() ก็มองไม่เห็นมัน
  • ป๊อปโอเวอร์หรือรายการของคอมโบบ็อกซ์บล็อกเกม จนกว่าจะปิด แม้ม่านจะโปร่งใส — และป๊อปโอเวอร์ที่มี dismissable = false และไม่มีชื่อเรื่อง จะไม่มีอะไรบนหน้าจอที่ปิดมันได้
  • พรอมต์การ์ดเริ่มต้นแบบซ่อนอยู่ และไม่มีการหมดเวลา
  • สแน็กบาร์ที่มี seconds: 0 และไม่มีปุ่มจะไม่มีวันหายไป และโดยค่าเริ่มต้นมันรับการแตะบนการ์ดของตัวเอง
  • การกดค้างที่ไม่มีใครรู้ คือฟีเจอร์ที่ไม่มีใครใช้ แสดงปุ่ม ⋯ ด้วย
  • ทรีที่หยุดชั่วคราวจะหยุดป๊อปอัปของคุณด้วย ใช้ PROCESS_MODE_ALWAYS บนเลเยอร์ของมัน
  • ข้อความแจ้งเตือนที่ไม่กำหนดความกว้าง จะหดจนแคบที่สุด — ใช้ preferred_width()
  • อย่าถามในสแน็กบาร์ อย่าแจ้งข่าวในไดอะล็อก คำถามจะหายไปเมื่อถูกเพิกเฉย ส่วนข่าวไม่ควรหยุดเกม
