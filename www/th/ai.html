Go HUD Skill

gohud มี AI skill มาให้ — API ทั้งหมด เทมเพลตที่รันได้ทันที และตัวเปิดพรีวิว วางบล็อกเดียวด้านล่างให้เอเจนต์เขียนโค้ดของคุณ แล้วมันจะติดตั้ง gohud และรู้วิธีใช้

คัดลอกพรอมต์ติดตั้ง ติดตั้ง

วางข้อความนี้ลงในเอเจนต์เขียนโค้ดของคุณ

เปิดโปรเจกต์ Godot ในเอเจนต์ วางบล็อกด้านล่างแล้วส่ง มันจะติดตั้ง skill และแอดออน จากนั้นจะบอกคุณว่า gohud ทำอะไรได้บ้าง

  1. เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ Godot แล้วเริ่มเอเจนต์เขียนโค้ดที่นั่น — เช่น claude
  2. กด คัดลอก ที่บล็อกด้านล่าง วางลงในเอเจนต์แล้วส่ง
  3. เมื่อเสร็จแล้ว ถ้าเอเจนต์ขอให้รีสตาร์ตก็รีสตาร์ต จากนั้นถามว่า: gohud ทำอะไรได้บ้าง?
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
บล็อกนี้เขียนเป็นภาษาอังกฤษโดยตั้งใจ — เป็นภาษาที่เอเจนต์ทุกตัวอ่านได้แม่นที่สุด คุณถามด้วยภาษาใดก็ได้ skill จะตอบด้วยภาษาที่คุณเขียน

หรือพิมพ์สองคำสั่ง — Claude Code

วิธีนี้ติดตั้ง skill เป็นปลั๊กอินของ Claude Code ในเทอร์มินัล:

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

อยู่ใน Claude Code อยู่แล้วหรือ? พิมพ์คำสั่งเหล่านี้แทน:

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

จากนั้นรีสตาร์ต Claude Code แล้วพิมพ์ /gohud:features — ถ้าขึ้นรายการฟีเจอร์ของ gohud แปลว่าติดตั้ง skill แล้ว ส่วนตัวแอดออนเองยังต้องอยู่ใน addons/gohud: ติดตั้ง →

เอเจนต์แต่ละตัวเก็บ skill ไว้ที่ไหน

อยากติดตั้งเองหรือ? วางโฟลเดอร์ skills/gohud ไว้ที่เอเจนต์ของคุณอ่าน อันที่มีอยู่ก่อนจะถูกใช้

เอเจนต์วางโฟลเดอร์ไว้ที่ไหนรูปแบบคำสั่ง
Claude Code — ปลั๊กอินclaude plugin install gohud@gohud/gohud:preview · /gohud:features
Claude Code — เฉพาะ skill~/.claude/skills/gohud/gohud preview · /gohud features
Claude Code — เฉพาะโปรเจกต์นี้.claude/skills/gohud/gohud preview
Codex · Cursor · Gemini CLI — อื่น ๆ.agents/skills/gohud—

คำสั่งที่คุณจะได้

/gohud:preview — แกลเลอรีวิดเจ็ต

เปิดแกลเลอรี: วิดเจ็ตทุกตัว ตัวเลือกพรีเซ็ตทั้ง 6 แบบ และชุดไอคอนทั้งชุด ถ้าพิมพ์คำสั่งนี้ในโปรเจกต์ Godot ของคุณ มันจะใช้ ตัวที่อยู่ในโปรเจกต์ของคุณเอง ที่ addons/gohud ถ้าไม่มี ก็จะใช้สำเนาที่มากับปลั๊กอิน หรือโคลนมาใหม่ มันรันในโปรเจกต์แซนด์บ็อกซ์ที่ใช้แล้วทิ้ง autoload และแคชการอิมพอร์ตของคุณจึงไม่ถูกแตะต้อง และหน้าต่าง จะเปิดค้างไว้จนกว่าคุณจะปิดเอง

/gohud:preview demo — ทัวร์แนะนำ 15 บท

เปิดเดโมที่หน้าเริ่มต้น เริ่มเดโม เล่นทัวร์ด้วยอินพุตจริง ส่วน สำรวจวิดเจ็ต ให้คุณลองเล่นทีละตัวด้วยมือ ปุ่มที่ระบุไว้ในหัวข้อ ตัวอย่าง ใช้ได้ที่นี่เช่นกัน

คำสั่งอื่น ๆ อีกมาก

คำสั่งทำอะไร
/gohud:preview medievalแผ่นข้อมูลตัวละคร ย่าม และสมุดบันทึกเควสต์ ในพรีเซ็ตยุคกลาง
/gohud:preview demo --explore hudเปิดเดโมเข้าไปที่บทใดบทหนึ่งโดยตรง — hud buttons inputs selection lists data states surfaces prompt touch coach scrolling forms anchors theming
/gohud:preview gallery --preset scifi_darkแกลเลอรีในพรีเซ็ตเดียว เติม --phone เพื่อได้หน้าต่างขนาดมือถือ 390×844 หรือ --size 1920x1080 สำหรับขนาดใดก็ได้
/gohud:preview res://ui/main_menu.tscnซีนของโปรเจกต์คุณเอง รันอยู่ในโปรเจกต์นั้น
/gohud:preview listเป้าหมายทุกอัน id ของพรีเซ็ต และคีย์ของบทเดโมทั้งหมด
/gohud:preview gallery --checkสโมกเทสต์แบบไม่มีหน้าต่าง — ล้มเหลวเมื่อสคริปต์มีข้อผิดพลาด
/gohud:featuresทุกฟีเจอร์ จัดกลุ่มไว้ พร้อมโค้ดบรรทัดเดียวต่อหนึ่งฟีเจอร์
/gohud:features hudเจาะลึกทีละด้าน — surfaces hud style theming icons i18n accessibility config

คำสั่งพรีวิวต้องมี Godot 4.6 ขึ้นไปอยู่ใน PATH

หรือจะขอตรง ๆ ก็ได้

หรือจะถามเอาเฉย ๆ ก็ได้ สกิลนี้สอน API ทั้งหมดของ gohud ให้เอเจนต์ การสั่งด้วยภาษาธรรมดาจึงใช้ได้ — "สร้างเมนูหยุดเกมด้วย gohud" ถ้าติดตั้งเป็นสกิลธรรมดาไว้ที่ ~/.claude/skills/gohud คำสั่งจะคั่นด้วยช่องว่างแทน: /gohud preview demo, /gohud features การพรีวิวต้องมี Godot 4.6 ขึ้นไปอยู่ใน PATH ของคุณ หรือส่ง --godot /path/to/godot เข้าไป
