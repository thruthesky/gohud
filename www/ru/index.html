Игровой интерфейс, которым управляет один ресурс

gohud — набор HUD и UI для Godot 4.6 и новее. Плавающие окна, нижние листы, диалоги, формы, снекбары, обучающие подсказки, полосы HUD, быстрые слоты и виртуальный стик работают от одной темы и одного сменного набора иконок, а безопасную область, виртуальную клавиатуру, RTL и области нажатия берут на себя. Шесть пресетов — обычный, sci-fi и средневековый, каждый в тёмном и светлом варианте, — меняют цвета и формы одной строкой.

Как это выглядит в игре

Средневековый и sci-fi пресеты — лист персонажа, инвентарь и задания; формы, сетки и карточки вопросов; угловатые панели и сенсорное управление. Пресет переключается одной строкой кода.

Что он берёт на себя

Больше всего времени в игровом интерфейсе съедает не форма кнопки, а всё то, что расходится между устройствами. gohud держит это расхождение в одном месте.

Каждый размер — это токен

Отступы, углы и размеры текста вызываются по имени, а не пишутся числами. Смените тему — и весь экран поедет вместе с ней.

Видимый размер ≠ размер нажатия

Кнопка закрытия выглядит на 36dp, но её область нажатия — 48dp. Там, где тесно стоящие слоты перекрываются, нажатие получает тот, чей центр ближе.

Вырезы и клавиатуры

Элементы HUD остаются внутри безопасной области, а поле ввода поднимается над виртуальной клавиатурой, когда та появляется.

«Назад» закрывает одно

Escape и кнопка «Назад» на Android закрывают только самую верхнюю поверхность. Стопка окон не исчезает целиком.

Уведомления не перехватывают ввод

Нажмите сквозь снекбар — и кнопка под ним его получит. Фокус тоже не отбирается.

Иконки запрашиваются по имени

Виджеты знают только GoIconSet.CLOSE. Смените набор — и все рисунки поменяются, не тронув ни строки кода.

Шесть образов, одна строка

GoUi.use_preset() меняет тему, скин и иконки разом — скруглённые, срезанные sci-fi или кованые средневековые рамки.

Читаемость — по измерению

Каждая тема проверена по WCAG, включая состояния кнопок и полупрозрачные панели HUD поверх чисто белого и чисто чёрного.

Всё работает и без включения плагина. Включение добавляет автозагрузку GoRuntime, которая следит за размером окна, масштабом dp и высотой клавиатуры, плюс настройки проекта для ресурса конфигурации и пресета — это удобства, а не требования.

Установка

Положите папку аддона в проект. Больше настраивать нечего.

Из Asset Store или ZIP-архива релиза

Распакуйте в корень проекта так, чтобы получилось res://addons/gohud/. Это всё. По желанию включите Project → Project Settings → Plugins → gohud.

Как git-подмодуль

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # по желанию: закрепить тег или коммит

Корень репозитория и есть папка аддона, поэтому он ложится ровно туда, где его ждёт Godot. Правьте на месте, коммитьте и пушьте внутри addons/gohud, а затем коммитьте указатель подмодуля в своей игре.

Нужен Godot 4.6 или новее. gohud использует API, появившиеся в 4.5 (DPITexture, FoldableContainer, свойства доступности), поэтому на всём, что старше, он падает ещё при разборе. 4.6 — поддерживаемый минимум, записанный в GoUi.MIN_ENGINE.

Быстрый старт

Любой виджет — это .new() и add_child(): ни файлов сцен, ни автозагрузки.

Выберите образ до сборки интерфейса (по желанию)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # если пропустить, используется default_dark

Подтверждение, которое можно await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Удалить сохранение", "Это действие необратимо."):
    delete_save()

Передайте destructive = true (последний аргумент) — и кнопка подтверждения нарисуется как залитая кнопка опасного действия.

Нижний лист с закреплённым полем поиска и подвалом

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Инвентарь")
sheet.toolbar().add_child(GoStyle.line_edit("Поиск…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Закрыть", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Почему закреплённые ряды отделены от прокручиваемого тела. Положите подтверждение и отмену в body — и длинный список вытолкнет их за экран. footer() виден всегда.

Угол HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Содержимое, которое держится в стороне от HUD

form.avoid_hud = true                  # обходить каждый видимый GoHudAnchor
joystick_anchor.reserve_space = false  # …кроме тех, что появляются только под пальцем
notice_anchor.avoid_peers = true       # уведомление садится под закреплённый HUD, а не накрывает его

Каждый прямоугольник обходится в том направлении, где потеря площади меньше: вниз на телефоне в книжной ориентации, вбок — в альбомной. Как HUD обходит сам себя →

Смена внешнего вида — цвета и форма

Theme может перерисовать только то, что рисует движок. Скруглённые углы — единственные, какие есть у StyleBoxFlat, а стик, быстрые слоты и обучающая подсказка рисуются кодом, поэтому одна лишь тема никогда не изменит их форму. Поэтому в gohud есть пресеты: тема, скин и набор иконок, выбранные как одно целое. 

GoUi.use_preset(GoThemePresets.MEDIEVAL_DARK)   # тема, скин и иконки разом
ПресетВид
default_darkИсходный gohud — скруглённые углы, мягкий синий акцент
default_lightТе же формы на светлой палитре
scifi_darkСрезанные углы, неоновые голубые грани и свечение, шестиугольный стик, прицельные скобки
scifi_lightТе же угловатые формы в яркой «чертёжной» палитре
medieval_darkТёмное железо и кожа, рамки под старое золото, заклёпки, гравированные иконки, заголовки шрифтом Cinzel
medieval_lightПергамент, чернила и бронза с теми же коваными рамками

Все четыре — это один и тот же экран галереи. Не отличается ни строки кода, только имя пресета. Углы кнопок, формы переключателей, строки списка и рамки полей ввода едут вместе.

Средневековая коллекция

medieval_dark соединяет железо и кожу со старым золотом; medieval_light берёт пергамент и чернила. На рамках меню есть заклёпка и небольшой угловой орнамент, а всегда видимый HUD остаётся сдержанным; 16 гравированных иконок перерисовывают названия предметов, и только заголовки и подзаголовки используют встроенный шрифт Cinzel.

Оба снимка — это examples/medieval/medieval.tscn, собранный из стандартных виджетов. Руководство по средневековью и как сделать своё королевство →

Один и тот же экран на телефоне и на настольном компьютере

Снимки галереи сделаны на телефоне в книжной ориентации. Ниже — тот же код при 1280×800: содержимое останавливается на читаемой ширине (480dp) и центрируется, а HUD остаётся по углам. Форма обходит плавающие элементы HUD, но не двигается, если и так их не задевает: сдвиг ради сдвига увёл бы содержимое с центра широкого экрана.

Тот же лист, другой вид

Выберите пресет в Project Settings → gohud → Theme → Preset или задайте GoConfig.preset. Явно заполненные theme, skin или icons берут верх над пресетом, так что можно взять пресет и переопределить лишь одно из трёх.

Новая тема — это один файл JSON. new_theme.py kingdom --from medieval_dark пишет палитру, в которой расписано каждое унаследованное значение; make_theme.py kingdom собирает тему, графику элементов управления и регуляторы скина, после чего пресет появляется в списке выбора. Все настройки и регуляторы →

Скины — там, куда Theme не дотягивается

Скину принадлежат стик, лицевые панели быстрых слотов, кольцо обучающей подсказки, чипы, скелетоны, оповещения, разделители и заголовки секций. Наследуйте его и переопределяйте только то, что хотите изменить. 

class_name MySkin extends GoSkin

func slot_box(accent: Color, lit: bool) -> StyleBox:
    var box := GoStyleBoxCut.new()
    box.bg_color = accent
    box.cut = 6.0
    box.edge_color = accent
    return box
КлассКакие формы умеет
GoStyleBoxCutДиагонально срезанные углы (фаска), одна утолщённая акцентная грань, внешнее свечение
GoStyleBoxBracketТолько угловые метки, без замыкания содержимого в рамку
GoStyleBoxMedievalКованая рамка с заклёпками, угловой гравировкой, фасочным бликом и фактурой материала

Все три сериализуются в ресурс Theme — именно это и позволяет теме менять форму, а не только цвет. GoSkinSciFi и GoSkinMedieval — подклассы, идущие в комплекте.

GoStyle.box() всегда возвращает StyleBoxFlat, потому что вызывающий код получает его и правит bg_color или corner_radius. Если нестандартная форма должна уцелеть, используйте GoStyle.surface().

Примеры, которые можно запустить

Три способа посмотреть gohud, не написав ни строки, — и ни одному не нужны ни сервер, ни автозагрузка.

ПримерКак открытьЧто показывает
Галереяexamples/gallery/gallery.tscn · F6Все виджеты, переключатель всех установленных пресетов и полный набор иконок
Средневековьеexamples/medieval/medieval.tscn · F6Лист персонажа, сумка и журнал заданий; кнопки переключают железо и пергамент и открывают описание предмета
Демо-приложениеcd examples/demo && godotДомашний экран, открывающий галерею, обучающий тур из 15 глав, витрину и средневековый образ, с живыми виджетами и отдельной карточкой на каждый класс
 
cd examples/demo && godot                             # домашний экран; при первом запуске создаёт ссылку и импортирует
bash examples/demo/run.sh                               # то же приложение, из корня аддона
bash examples/demo/run.sh -- --open=gallery             # пропустить домашний экран
bash examples/demo/run.sh -- --explore=surfaces         # открыть сразу на одной главе тура
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # запись тура в 1080p / 60 кадров в секунду

Демо-приложению не нужна никакая подготовка: если ссылки на аддон или кэша импорта нет, оно сообщает об этом, чинит папку и открывается заново. Его домашний экран открывает каждый пример в том же окне — нажмите 1–4 или щёлкните по строке, а полоса сверху вернёт вас назад.

В туре C включает режим «кино», F11 — полный экран, Space ставит на паузу (или проигрывает текущий виджет в режиме просмотра), стрелки меняют главы, а Escape возвращает на стартовый экран.

Запуск из вашего ИИ-агента

В комплекте с gohud идёт плагин для Claude Code со слэш-командами. Введите одну — и галерея или демо откроется в собственном окне Godot: ни редактор запускать, ни сцену искать не нужно.

Установите команды один раз

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud
# затем перезапустите Claude Code

Другие агенты, например Codex, могут пользоваться тем же навыком: скопируйте skills/gohud из этого репозитория в папку навыков агента.

/gohud:preview — галерея виджетов

Открывает галерею: все виджеты, переключатель всех шести пресетов и полный набор иконок. Наберите команду внутри своего проекта Godot — и она возьмёт ваш addons/gohud; если его нет, используется копия из плагина или свежий клон. Запуск идёт в одноразовом песочном проекте, поэтому ваши автозагрузки и кэш импорта остаются нетронутыми, а окно держится открытым, пока вы его не закроете.

/gohud:preview demo — обучающий тур из 15 глав

Открывает демо на стартовом экране. Start demo проигрывает тур с настоящим вводом; Explore widgets даёт попробовать виджет руками. Клавиши, перечисленные в разделе Примеры, работают и здесь.

Читаемость измеряют, а не прикидывают на глаз

«Красиво» — дело вкуса; «читаемо» можно измерить. Бледно-серый текст отлично смотрится на хорошем мониторе и исчезает на телефоне при дневном свете — выбор на глаз рано или поздно приводит именно к этому. 

python3 addons/gohud/tools/check_contrast.py

Каждая пара цветов и подпись каждого состояния кнопки поверх панели, на которой она лежит, измеряется по WCAG во всех шести темах. Полупрозрачные цвета сначала накладываются на настоящий фон — если измерять их напрямую, коэффициент получается лучше, чем на экране.

Поэтому цвета текста выводятся, а не выбираются: сборщик берёт значение из палитры как отправную точку и поднимает его светлоту, пока оно не пройдёт порог на всех поверхностях, где может оказаться. Измените палитру — и контраст пойдёт следом. Правила и ловушки за ними →

Проверки, релизы и этот сайт

Одна точка входа запускает все проверки; каждая часть видит то, чего не видят остальные.

bash addons/gohud/tools/check_all.sh
ПроверкаЧто ловит
run_tests.sh на четырёх размерах экранаПоведение и раскладку виджетов, позиции в RTL, фокус с клавиатуры, контраст скина во время работы, все пресеты
new_project_check.shСкрытые зависимости от проекта-хозяина; с --zip — релиз в том виде, в каком он поставляется, с --export — сборку для Web
check_contrast.pyКонтраст по WCAG в каждом файле темы, включая состояния кнопок и полупрозрачные панели
check_generated.py · check_scaffold.shСгенерированные темы совпадают со своими палитрами; одноразовая тема собирается и проходит проверку контраста
check_package.pyПовышение версии, перенос записей в журнале изменений и содержимое ZIP — во временных копиях
check_site.pyСсылки этого сайта, якоря, язык страницы, глоссарий и таблицы регуляторов
Последний записанный прогон — 2026-09-13, Godot 4.7.2, macOS, рендерер Compatibility. 438 из 438 проверок на 390×844, 844×390, 768×1024 и 1280×800 в пустом проекте; снова 438 из 438 с автозагрузкой GoRuntime; экспорт для Web; ноль провалов по контрасту в шести темах. Godot 4.6 и физические устройства на Android или iOS в этот прогон не входили.

Версии релизов

bash addons/gohud/tools/package.sh                           # 1.0.1 → 1.0.2 · builds/1.0.2/gohud-1.0.2.zip
bash addons/gohud/tools/package.sh --increase-minor-version  # 1.0.1 → 1.1.0

Успешный прогон обновляет plugin.cfg, GoUi.VERSION и CHANGELOG.md вместе, перенося заметки из раздела Unreleased в датированную запись. Неудачный прогон не меняет ничего, а уже существующий ZIP никогда не перезаписывается. В ZIP не попадают этот сайт, тесты и инструменты.

Этот сайт

python3 addons/gohud/tools/make_site.py            # глоссарий и таблицы регуляторов скина, порождённые из исходников
python3 addons/gohud/tools/check_site.py           # ссылки, якоря, язык, глоссарий, порождённые таблицы
bash addons/gohud/tools/site_shots.sh /tmp/shots   # снимки каждой страницы для настольного экрана и телефона

Страницы — это обычный HTML в www/: английский в корне, корейский в ko/. Рабочий процесс GitHub Actions публикует эту папку как корень сайта.

gohud распространяется по MIT — и код, и графика, включая 84 иконки по умолчанию и 16 средневековых. Встроенный шрифт Cinzel — под SIL Open Font License 1.1.
