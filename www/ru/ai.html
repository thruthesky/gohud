Go HUD Skill

В gohud входит ИИ-навык: весь API, готовые шаблоны и запуск предпросмотра. Вставьте один блок в своего агента — он установит gohud и будет знать, как им пользоваться.

Скопировать промпт установки Установка

Вставьте это в свой ИИ-агент

Откройте проект Godot в агенте, вставьте блок и отправьте. Он установит навык и дополнение, а потом расскажет, что умеет gohud.

  1. Откройте терминал в папке проекта Godot и запустите там свой ИИ-агент — например, claude.
  2. Нажмите Копировать на блоке ниже, вставьте его в агент и отправьте.
  3. Когда он закончит, перезапустите агент, если он попросит, и спросите: Что умеет gohud?
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
Блок намеренно написан по-английски — так его точнее всего читает любой агент. Свои вопросы задавайте на любом языке: навык отвечает на том языке, на котором вы пишете.

Или две команды — Claude Code

Так навык ставится как плагин Claude Code. В терминале:

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

Уже внутри Claude Code? Тогда введите это:

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

Затем перезапустите Claude Code и введите /gohud:features — если появился список возможностей gohud, навык установлен. Само дополнение по-прежнему должно лежать в addons/gohud: Установка →

Где каждый агент хранит навыки

Хотите поставить вручную? Положите папку skills/gohud туда, откуда читает ваш агент. Побеждает первая существующая.

Команды, которые вы получите

/gohud:preview — галерея виджетов

Открывает галерею: все виджеты, переключатель всех шести пресетов и полный набор иконок. Наберите команду внутри своего проекта Godot — и она возьмёт ваш addons/gohud; если его нет, используется копия из плагина или свежий клон. Запуск идёт в одноразовом песочном проекте, поэтому ваши автозагрузки и кэш импорта остаются нетронутыми, а окно держится открытым, пока вы его не закроете.

/gohud:preview demo — обучающий тур из 15 глав

Открывает демо на стартовом экране. Start demo проигрывает тур с настоящим вводом; Explore widgets даёт попробовать виджет руками. Клавиши, перечисленные в разделе Примеры, работают и здесь.

Для команд предпросмотра нужен Godot 4.6 или новее в PATH.

Или просто попросите

Или просто попросите. Навык обучает агента всему API gohud, поэтому работают и обычные просьбы — «Собери меню паузы на gohud». Если он установлен как обычный навык в ~/.claude/skills/gohud, команды пишутся через пробел: /gohud preview demo, /gohud features. Для предпросмотра нужен Godot 4.6 или новее в PATH, либо передайте --godot /path/to/godot.

gohud распространяется по MIT — и код, и графика, включая стандартные (84), средневековые (16), игровые (187) и библиотечные (1 000) иконки; контуры из Tabler Icons среди них тоже под MIT. Встроенный шрифт Cinzel — под SIL Open Font License 1.1.
