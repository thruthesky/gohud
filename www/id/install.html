Memasang gohud

Dua jalan. Serahkan pada agen AI, atau letakkan foldernya di proyekmu — tidak ada lagi yang perlu diatur.

Jalan tercepat — biarkan agen AI yang memasang

Satu blok teks, ditempel ke Claude Code, Codex, Cursor, atau Gemini CLI, memasang skill sekaligus add-on lalu menjelaskan gohud padamu. Lewat jalan itu, tak satu pun di bawah kartu ini diperlukan.

Instalasi

Letakkan folder add-on ke dalam proyek Anda. Tidak ada lagi yang perlu disiapkan.

Dari Asset Store atau ZIP rilis

Ekstrak ke akar proyek sehingga terbentuk res://addons/gohud/. Itu saja. Bila mau, aktifkan Project → Project Settings → Plugins → gohud.

Sebagai submodule git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # opsional: kunci ke satu tag atau commit

Akar repositori adalah folder add-on itu sendiri, jadi ia mendarat persis di tempat yang diharapkan Godot. Sunting langsung di tempat, commit dan push di dalam addons/gohud, lalu commit penunjuk submodule di game Anda.

Godot 4.6 atau yang lebih baru wajib. gohud memakai API yang diperkenalkan di 4.5 (DPITexture, FoldableContainer, properti aksesibilitas), jadi pada versi yang lebih lama ia gagal saat parsing. 4.6 adalah batas bawah yang didukung, tercatat di GoUi.MIN_ENGINE.

Mulai cepat

Setiap widget cukup .new() dan add_child() — tanpa file scene, tanpa autoload.

Pilih tampilan sebelum membangun UI (opsional)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # default_dark dipakai kalau baris ini dilewati

Konfirmasi yang bisa Anda await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Hapus simpanan", "Tindakan ini tidak bisa dibatalkan."):
    delete_save()

Berikan destructive = true (argumen terakhir) dan tombol konfirmasi digambar sebagai tombol bahaya berisi penuh.

Lembar bawah dengan kolom pencarian dan footer yang menempel

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventaris")
sheet.toolbar().add_child(GoStyle.line_edit("Cari…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Tutup", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Kenapa baris yang menempel dipisahkan dari body yang bergulir. Taruh tombol konfirmasi dan batal di body dan daftar yang panjang akan mendorongnya keluar layar. footer() selalu terlihat.

Satu sudut HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Konten yang menjauh dari HUD

form.avoid_hud = true                  # menjauh dari setiap GoHudAnchor yang terlihat
joystick_anchor.reserve_space = false  # …kecuali yang hanya muncul di bawah jari
notice_anchor.avoid_peers = true       # toast turun ke bawah HUD tetap alih-alih menutupinya

Setiap persegi dihindari ke arah yang paling sedikit memakan luas — ke bawah pada ponsel potret, ke samping pada lanskap. Bagaimana HUD menghindari dirinya sendiri →

Contoh yang bisa Anda jalankan

Tiga cara melihat gohud sebelum menulis satu baris pun — tidak satu pun butuh server atau autoload.

ContohCara membukaApa yang ditampilkan
Galeriexamples/gallery/gallery.tscn · F6Setiap widget, pemilih untuk setiap preset yang terpasang, dan set ikon lengkap
Abad pertengahanexamples/medieval/medieval.tscn · F6Lembar karakter, tas, dan jurnal misi; tombol-tombolnya menukar besi dan perkamen serta membuka rincian benda
Aplikasi democd examples/demo && godotLayar beranda yang membuka galeri, tur berpemandu 15 bab, layar etalase, dan tampilan abad pertengahan, lengkap dengan widget yang hidup dan satu kartu untuk tiap kelas
 
cd examples/demo && godot                             # layar beranda; menautkan dan mengimpor saat pertama dijalankan
bash examples/demo/run.sh                               # aplikasi yang sama, dari akar add-on
bash examples/demo/run.sh -- --open=gallery             # lewati layar berandanya
bash examples/demo/run.sh -- --explore=surfaces         # langsung membuka satu bab tur
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # rekaman tur 1080p / 60 fps

Aplikasi demo tidak butuh penyiapan: bila tautan add-on atau cache impornya tidak ada ia akan memberi tahu, memperbaiki foldernya, lalu membuka dirinya kembali. Layar berandanya membuka tiap contoh di dalam jendela yang sama — tekan 1–4 atau klik salah satu barisnya, dan bilah di sepanjang bagian atas membawa Anda kembali.

Di dalam turnya, C mengalihkan mode Sinema, F11 layar penuh, Spasi menjeda (atau memainkan widget yang sedang dilihat saat menjelajah), tombol panah mengganti bab, dan Escape kembali ke layar Mulai.
