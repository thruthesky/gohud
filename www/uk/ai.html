AI SKILL

gohud має ШІ-навичку: увесь API, готові до запуску шаблони та запуск попереднього перегляду. Вставте один блок у свого агента — він встановить gohud і знатиме, як ним користуватися.

До блоку для вставки Встановлення

Вставте це у свій ШІ-агент

Відкрийте проєкт Godot в агенті, вставте блок і надішліть. Він встановить навичку та доповнення, а тоді розповість, що вміє gohud.

Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, if addons/gohud/plugin.cfg is missing here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import

3. Restart yourself so the skill loads, then tell me what gohud can do
   and how to preview it.

Docs: https://thruthesky.github.io/gohud/
Блок навмисно написано англійською — саме її кожен агент читає найточніше. Свої запитання ставте будь-якою мовою: навичка відповідає тією, якою ви пишете.

Команди, які ви отримаєте

/gohud:preview — галерея віджетів

Відкриває галерею: кожен віджет, вибір із усіх шести пресетів і повний набір іконок. Наберіть її всередині свого проєкту Godot — і використається ваш addons/gohud; без нього береться копія, вкладена в плагін, або свіжий клон. Вона працює в одноразовому пісочничному проєкті, тож ваші автозавантаження та кеш імпорту лишаються недоторканими, а вікно стоїть відкритим, доки ви його не закриєте.

/gohud:preview demo — екскурсія з 15 розділів

Відкриває демо на початковому екрані. Запустити демо програє екскурсію справжнім вводом; Дослідити віджети дає спробувати один віджет вручну. Клавіші, перелічені в розділі Приклади, працюють і тут.

Команди попереднього перегляду потребують Godot 4.6 або новішого у PATH.

Або просто попросіть

Або просто попросіть. Уміння навчає агента всього API gohud, тож звичайні прохання теж працюють — «Зроби меню паузи на gohud». Якщо встановити його як звичайне вміння в ~/.claude/skills/gohud, команди пишуться через пробіл: /gohud preview demo, /gohud features. Для попереднього перегляду потрібен Godot 4.6 або новіший у PATH, або передайте --godot /path/to/godot.
