安装 gohud

两条路：让 AI 代理替你装，或把文件夹放进项目 —— 此外无需任何配置。

最快的路 —— 让 AI 代理替你安装

把一段文字粘贴到 Claude Code、Codex、Cursor 或 Gemini CLI，它会同时装好技能和插件，再为你讲解 gohud。走这条路，这张卡片以下的内容一样都不需要。

打开 AI SKILL 页 →

安装

把插件文件夹放进项目即可，没有别的要配置。

从资源商店或发布 ZIP 安装

解压到项目根目录，得到 res://addons/gohud/，这就完成了。也可以顺手启用 项目 → 项目设置 → 插件 → gohud。

作为 git 子模块安装

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # 可选：固定到某个标签或提交

仓库根目录本身就是插件文件夹，所以它会正好落在 Godot 期望的位置。直接在 addons/gohud 里改、提交、推送，然后在游戏项目里提交子模块指针。

必须是 Godot 4.6 或更高版本。 gohud 用到了 4.5 引入的 API（DPITexture、 FoldableContainer、无障碍属性），所以在更旧的版本上会在解析阶段就失败。 4.6 是受支持的下限，记录在 GoUi.MIN_ENGINE 里。

快速上手

每个控件都是 .new() 加 add_child() —— 不用场景文件，也不用自动加载。

先选一套外观，再开始搭 UI（可选）

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # 不写这一行时用的是 default_dark

可以 await 的确认框

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("删除存档", "此操作无法撤销。"):
    delete_save()

传入 destructive = true（最后一个参数），确认按钮就会画成实心的危险按钮。

带常驻搜索框和底栏的底部面板

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("背包")
sheet.toolbar().add_child(GoStyle.line_edit("搜索…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("关闭", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
常驻行为什么要和滚动主体分开。 把确认和取消放进 body，列表一长就会把它们顶出屏幕。 footer() 则始终可见。

一个 HUD 角落

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

让内容避开 HUD

form.avoid_hud = true                  # 避开每一个可见的 GoHudAnchor
joystick_anchor.reserve_space = false  # …只在手指按下时才出现的那些除外
notice_anchor.avoid_peers = true       # 提示条落到固定 HUD 下方，而不是盖住它

每个矩形都朝着损失面积最小的方向避让 —— 竖屏手机上往下，横屏时往侧边。 HUD 之间如何互相避让 →

能直接跑起来的示例

不写一行代码就能看到 gohud 的三种方式 —— 都不需要服务器，也不需要自动加载。

示例怎么打开能看到什么
控件画廊examples/gallery/gallery.tscn · F6每一个控件、一个可切换全部已安装预设的选择器，以及完整图标集
中世纪examples/medieval/medieval.tscn · F6角色面板、行囊和任务日志；按钮可在铁与羊皮纸之间切换，并打开物品详情
演示程序cd examples/demo && godot一个主页，从这里可以打开控件画廊、15 章导览、展示界面和中世纪外观，里面都是能实际操作的控件，每个类各占一张卡片
 
cd examples/demo && godot                             # 主页；首次运行会建好链接并导入资源
bash examples/demo/run.sh                               # 同一个程序，从插件根目录启动
bash examples/demo/run.sh -- --open=gallery             # 跳过主页
bash examples/demo/run.sh -- --explore=surfaces         # 直接打开导览的某一章
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # 以 1080p / 60 fps 录制整段导览

演示程序不需要任何准备工作：插件链接或导入缓存缺失时它会告诉你，自动把文件夹修好并重新打开自己。 它的主页会在同一个窗口里打开每一个示例 —— 按 1–4 或点击某一行即可，顶部那条横栏能把你带回来。

在导览里，C 切换影院模式，F11 全屏，Space 暂停（在探索模式下则是播放当前控件）， 方向键切换章节，Esc 回到开始界面。
