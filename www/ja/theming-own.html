自分のプリセットを、ファイル1枚で

← テーマ

テーマ 3つの層 トークン 不透明度 — パネルの向こうのゲーム スキン — テーマが届かない場所 自分のプリセットを、ファイル1枚で 読みやすさは測って決める

テーマを1つ足すのに、かつては4か所を手で編集する必要があった — ビルダーのパレット、形、スキン、 プリセットのリソース。いまは1つのコマンドがすべてを置いてくれる。 

python3 addons/gohud/tools/new_theme.py neon --from scifi_dark --title "Neon"
python3 addons/gohud/tools/make_theme.py neon      # テーマの .tres + コントロールの絵
godot --headless --path . --import                  # 新しい絵を一度だけインポートする
GoUi.use_preset(&"neon")                             # 完了 — 選択リストにも出てくる

最初の行が themes/palettes/neon.json と themes/presets/neon.tres を書く。 この JSON には継承元テーマのすべての値が省略なしで書き出されるので、そのまま「変えられるものの一覧」 にもなる。キーを消せば親の値のまま、書けば上書きだ。プリセットは themes/presets/ を 走査して見つけるので、登録コードの変更はいらない — プロジェクト設定のドロップダウンにも同じように載る。

変えられるもの — 1ページで

場所何をどう書くか
from継承元のテーマdark · light · scifi_dark · medieval_dark · … あるいは別の JSON テーマ。書かなかったキーはその値を継承し、循環すると失敗する
palette背景 · 3つのサーフェス · 枠 · 3段階の文字色 · アクセント · 4つの状態色 · 幕 · 影 · バーの溝"#RRGGBB"、アルファ付きは "#RRGGBB@0.35"
塗り専用の鮮やかな色 *_vivid文字色が暗くならざるを得ないときでもバーは鮮やかに保つ — 書き忘れるとビルダーが教えてくれる
読みやすさ手で調整しない。 文字・枠・アクセント・その上のラベルは、しきい値を超えるまでビルダーが押し上げる — アクセントだけを変えても検査は通ったままだ
shapekindflat（丸み） · cut（面取りした角） · medieval（鍛造の枠）
寸法radius · radius_small · radius_large · gap · gap_small · gap_large · padding · button_height · button_padding[4] — トークンも一緒に動くので、パネルとウィジェットの計算が食い違わない
cut 専用cut_ratio · cut_max · corners(diagonal|all) · glow · edge
medieval 専用material（0 鉄 · 1 革 · 2 羊皮紙） · grain_alpha · ornament_scale · bevel_strength · fonts — title、subtitle、caption、body、button をアドオン内の res:// フォントファイルへ割り当てる
skinbase — コードが自分で描く場所（スティック、スロット、バッジ、コーチマークのリング、チップ、区切り線）の系統default · scifi · medieval
dials — それらの場所の数値。スロットの枠の太さと色味、バッジの余白、チップとアラートの不透明度、スティックのリングの太さと不透明度、SF の面取り寸法、発光とブラケット親の値はすべて JSON に書き出される。ビルダーがそれを themes/skins/gohud_skin_<id>.tres へ書き込む — スキンのコードには触れない。描画そのものを変えたいときだけ --new-skin を付け、GoSkin のサブクラスの雛形を作らせる
iconsアイコンセットGoIconSet リソースへの res:// パス — 省略すると JSON の親から引き継ぐ
dark · title選択リストでの見せ方真偽値 · 文字列

スキンを継承する（任意）

スキンにあるのは、テーマと形では届かないものだけだ — スティックの六角形、スロットのバッジ、 コーチマークの照準ブラケット。GoSkin を継承してそれらのメソッドだけを上書きし、JSON の skin をそのリソースへ向ける。色だけのテーマなら、この手順はいらない。

約束を守らせるのは検査だ。 tools/check_scaffold.sh は実行のたびに使い捨てのテーマを作り — アクセントを変え、半径を 4 にして — 生成・トークンの伝播・コントラスト検査の通過までを確かめてから消す。 最初の実行では、アクセントだけを変えたテーマが8組で不足していた。ビルダーが文字色は押し上げるのに、 アクセントは書かれたまま使っていたのだ。いまはアクセントと、その上のラベルも押し上げる。
