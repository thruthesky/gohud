すべてのウィジェット

gohud のすべてのウィジェットとレイアウトを、名前と貼り付けて使える例で一覧にしました。どれも選んだプリセットの見た目になります。 ← ウィジェット

ウィジェット すべてのウィジェット ポップアップとダイアログ 浮かぶウィンドウ プレイヤーに何かを伝える HUD 待たせる、伝える、数える フォームとリスト ゲームで実際に使う形 画面の上に重ねる GoStyle — 作る場所を1つにする

レイアウト (15)

GoScaffold

アプリ画面を一度に組み立てる — バー、スクロールするページ、下部バー、FAB、ドロワー。

継承 Control

var page := GoStyle.column()
var screen := GoScaffold.make("Inbox", page, true)
screen.set_fab(GoFab.make(GoIconSet.EDIT))
add_child(screen)

GoTopBar

上端に沿って 1～3 個の枠。中央の枠は常に中央。

継承 GoEdgeBar

var bar := GoTopBar.make(3)
bar.add_start(GoStyle.icon_button(GoIconSet.BACK, go_back, -1, &"back"))
bar.add_center(GoStyle.label("Stage 3"))
bar.add_end(GoStyle.chip("1,250"))

GoBottomBar

下端に沿って配置。ジェスチャーバーを避ける。

継承 GoEdgeBar

var actions := GoBottomBar.make(1, GoBottomBar.Justify.SPACE_BETWEEN)
for name in ["Attack", "Guard", "Run"]: actions.add_start(GoStyle.button(name))
screen.add_child(actions)

GoLeftSideBar

左端に沿って最大 3 段。

継承 GoSideBar

var tools := GoLeftSideBar.make(3)
tools.add_start(GoStyle.icon_button(GoIconSet.MENU, open_menu, -1, &"menu"))
tools.add_end(GoStyle.icon_button(GoIconSet.USER, open_profile, -1, &"profile"))
screen.add_child(tools)

GoRightSideBar

右端に沿って最大 3 段。

継承 GoSideBar

var tools := GoRightSideBar.make(3)
tools.add_start(GoStyle.icon_button(GoIconSet.SETTINGS, open_settings, -1, &"settings"))
tools.add_center(GoStyle.icon_button(GoIconSet.SEARCH, find, -1, &"search"))
screen.add_child(tools)

GoSideBar

継承 GoEdgeBar

var rail := GoRightSideBar.make(1, GoSideBar.Justify.CENTER)
rail.add_start(GoStyle.icon_button(GoIconSet.MAP, open_map, -1, &"map"))

GoEdgeBar

すべての端バーに共通の規則 — 枠、均等配置、端への固定、セーフエリア。

継承 Container

bar.justify = GoEdgeBar.Justify.SPACE_BETWEEN
bar.pin_to_edge = GoEdgeBar.Pin.ALWAYS
