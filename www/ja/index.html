ゲーム UI を、リソース1枚で動かす

gohud は Godot 4.7 以降で使う HUD・UI キットだ。浮かぶウィンドウ、ボトムシート、ダイアログ、フォーム、 スナックバー、コーチマーク、HUD バー、クイックスロット、バーチャルスティックがテーマ1枚と 差し替え可能なアイコンセット1枚で動き、セーフエリア・仮想キーボード・RTL・タッチターゲットを自分で面倒みる。 14のプリセット — デフォルト・SF・中世・Material 3・キッズ・コミック・アーケード、それぞれにダークとライト — が1行で色と形を同時に変える。

新登場：アーケード、コミック、Material 3、キッズ向けの見た目

デフォルト・SF・中世に新しい系統が4つ加わった — 組み込みの見た目は14種類になり、それぞれにダークとライトがある。 どのウィジェット・ポップアップ・HUD 部品も、コードを一切変えずにそのまま受け取る：プリセットを切り替えれば、画面全体がついてくる。

Material 3 — アプリ画面向け

公式の M3 トークンと照らし合わせた Material 3 Expressive だ：48dp のタッチターゲットに 40dp の下地を収めた ピル型ボタン、28dp のダイアログとシート、塗りのカード、アウトラインの入力欄、Expressive のスライダー。アプリ部品 — ナビゲーションバー、アプリバー、FAB、検索バー、チップ、進捗、日付選択 — は M3 のコンポーネントトークンに従い、 タイトルには同梱の Roboto を使う。ショップ、設定、受信箱など、アプリらしく見せたいあらゆる画面に。

キッズ — おもちゃ箱

子どものために作った：キーも行もパネルも、太い縁取りと押すと沈むしっかりした段を持つゼリーキャンディで、 部品の種類ごとに自分のクレヨンの色をまとう。クイックスロットはキャンディのブロック、バッジはステッカー、 スティックは虹色だ。ウィンドウにはお日さま色のタイトルリボンと丸いキャンディの閉じるボタンが付き、押すとぷにっとつぶれる。 サイズとプロジェクトのフォントはまったく変わらない。

コミック — 太いインク

どの面もマンガのコマだ：太いインクの輪郭の中に表面の色を塗り、後ろにくっきりした影を落とし、 面を押すとその影が消える。設定1つですべての影をオン・オフし、さらに2つで輪郭の太さと影の大きさを決め、 呼び出し1つで同じことをウィジェット1つにだけ行える。ウィンドウには黄色のタイトルキャプションが付く。

アーケード — 塗られたキー

どのキーも塗られている — グラデーション、白い光沢、押すと沈む段を紺色のインクの輪郭に収め — ラベルはインクで縁取った白い文字だ：プレイは緑、ほかは青、削除は赤。ボードは厚く、淡い内側を 色の枠が囲む。ウィンドウには金色のタイトルバナーと丸い赤の閉じるキーが付く。

GoUi.use_preset(GoThemePresets.MATERIAL_LIGHT)   # または MATERIAL_DARK
GoUi.use_preset(&"kids_light")                   # または &"kids_dark"
GoUi.use_preset(&"comic_light")                  # または &"comic_dark"
GoUi.use_preset(&"arcade_light")                 # または &"arcade_dark"

アーケード：塗られたキーと厚いボード

いちばん新しい見た目は、どの画面もアーケード筐体のように仕立てる。どのキーも塗られている — 上が明るく下へいくほど 深くなるグラデーション、白い光沢のひと筋、押すと沈む段を、すべて紺色のインクの輪郭に収め — ラベルはインクで縁取った白い文字だ。 どのボードも厚い：自分の光沢を持つ色の枠が、淡い内側を囲む。 arcade_light は空色のページに白いボードを、arcade_dark は夜のページに紺色のボードを置く。 下の画像はすべて本物の gohud の画面だ — 同じコードで、違うのはプリセットの1行だけ。 

GoUi.use_preset(&"arcade_light")   # または &"arcade_dark"

夜は arcade_dark

暗いページでは、インクがずっと深くなってページそのものになり、塗りの色は変わらず鮮やかなままだ。

アーケードの見た目のしくみ

面

どのキーもボードも GoStyleBoxArcade だ：インクの輪郭、グラデーションの本体、段、光沢を、 コントロール自身の矩形の中に描く — キーは状態が変わっても大きさが変わらず、押すと沈むだけだ。

読めるラベル

インクで縁取った白いラベルは、その縁取りが引き離すどんな塗りの上でも読める — WCAG は縁取りを文字の一部として数える。 どの塗りも、グラデーションのどの高さでもラベルが 4.6:1 を超えるまで調整される。

ウィンドウ

ウィンドウのタイトルは、インクで縁取った白い文字で金色のバナーに載り、隣に丸い赤の閉じるキーが付く。ダイアログ、 シート、ドロワー、ポップオーバーは厚い枠付きのボードだ。

キー1つに自分だけの色を塗れる — ポーズメニューのオレンジのショップキーのように：

menu.add_child(GoStyle.arcade_paint(GoStyle.button("Shop", _shop), Color("#FF8A1E")))

コミック：太いインクとくっきりした影

コミックの見た目は、どの面もマンガのコマのように描く — 太いインクの輪郭の中に表面の色を塗り、 右下へくっきりとしたベタの影を落とす。comic_light は紙のようなクリーム色のページに黒のインクで描き、 プライマリはコバルト。comic_dark は夜のページにクリーム色のインクで描き、プライマリは黄色だ。下の画像はすべて 本物の gohud の画面だ — 同じコードで、違うのはプリセットの1行だけ。 

GoUi.use_preset(&"comic_light")   # または &"comic_dark"

どのウィジェットもインクで

ボタン、トグル、タブ、スライダー、カード、フォーム、テーブル、ピッカー、チップがみなインクをまとう — 1つずつ スタイルを付ける必要はない。キーを押すと影が消え、面がスタンプのようにその位置へ沈む。 無効な面は影を失って薄くなるので、押せるものと押せないものがひと目で分かる。

夜は comic_dark

暗いページでは黒い輪郭が消えてしまうので、comic_dark は輪郭をクリーム色で描き、同じインクの色をおびた 淡い影を落とす。HUD の部品 — クイックスロット、バー、スティック、報酬カレンダー — も同じルールに従う。

コミックの見た目のしくみ

すべての面に1つの StyleBox

どの面も GoStyleBoxComic だ：塗り、輪郭、影を、コントロール自身の矩形の内側に描く。描くたびに GoConfig から輪郭と影の大きさを読むので、設定1つで画面全体が一度に変わる。

押すと平らになる

押したキーは影を落とすのをやめ、その位置へ移る。ホバーでは影が残り、フォーカスでは輪郭を決して覆わない内側のインクの輪が加わり、無効な面は影を失って薄くなる。

残りはスキンが描く

GoSkinComic は、コードが描くものにインクを入れる：クイックスロット、チップ、バッジ、アバター、通知、ナビゲーションバー、FAB、日付のセル、そしてノブが影を落とすスティック。

ウィンドウにはキャプション

ウィンドウのタイトルは、マンガのナレーションの枠のような黄色のキャプションに載り、隣にはインクで描いた丸い閉じるボタンが付く。ダイアログ、シート、ドロワー、ポップオーバーは不透明なインクのパネルだ。

昼も夜も読みやすい

どちらのパレットも、ほかのすべてのプリセットと同じ WCAG のコントラスト検査に通る。押したキーや無効なキーも含めてだ。キャプションの色がページに近すぎるときは、その輪郭がページの色に切り替わる。

レイアウトは変わらない

輪郭と影は各コントロールの内側に収まり、内側余白はテーマが与えたままなので、別の見た目でレイアウトした画面はそのままのレイアウトを保つ — プロジェクトのフォントもだ。

設定3つと呼び出し1つ

GoConfig の3つの設定が、すべてのコミックの面を一度に変える。作り直すものは何もない — 値を入れたそばから画面が描き直される。

GoUi.config.comic_border_width = 2.0   # 輪郭 (dp) — 既定は 3
GoUi.config.comic_shadow_size = 6.0    # 影 (dp) — 既定は 4
GoUi.config.comic_shadow = false       # どこにも影を出さない

ウィジェット1つだけなら、設定に関係なく独自の道を行ける。最後の引数に true を渡すと、その中のすべても対象になる。

GoStyle.comic_shadow(skip_button, false)     # このボタンは平らに
GoStyle.comic_shadow(card, true, true)       # このカードとその中身すべては影を保つ
GoStyle.comic_border(title, 5.0)             # これだけ輪郭を太く
自分だけのコミックを作る。 tools/new_theme.py inked --from comic_light がパレットをコピーする。紙、 インク、プライマリの色を変えて tools/make_theme.py inked を実行すればいい。インクも影もスキンも一緒についてくる。

肩代わりしてくれるもの

ゲーム UI で時間を食うのはボタンの形ではなく、端末ごとにずれていくすべてだ。 gohud はそのずれを1か所で引き受ける。

寸法はすべてトークン

余白・角・文字サイズは数値で書かず名前で呼ぶ。テーマを差し替えれば画面全体がまとめて動く。

見える大きさ ≠ 押せる大きさ

閉じるボタンは 36dp に見えてタッチターゲットは 48dp。スロットが密集して重なる場所は、中心が近いほうが押下を取る。

ノッチとキーボード

HUD はセーフエリアの内側に収まり、仮想キーボードが出れば入力欄がその上へ持ち上がる。

戻るは1枚だけ閉じる

Escape と Android の戻るは最前面の1枚だけを閉じる。重ねたウィンドウがまとめて消えない。

通知は入力を奪わない

スナックバーの上を押しても、その下のボタンが反応する。フォーカスも奪わない。

アイコンは名前で頼む

ウィジェットが知っているのは GoIconSet.CLOSE だけ。セットを差し替えればコードに触れずに絵が変わる。 アイコン →

14の見た目、1行

GoUi.use_preset() がテーマ・スキン・アイコンをまとめて入れ替える — 丸み、面取りの SF、鍛造した中世の枠、Material 3 のアプリ部品、キッズのゼリーキャンディ、コミックのインク、アーケードの塗り。

読めるかどうかは測る

どのテーマも WCAG で測ってある。ボタンの状態ごとのラベルも、純白・純黒の上に載る半透明 HUD パネルも含めて。

プラグインを有効にしなくても全部動く。 有効にすると GoRuntime オートロードが付いてウィンドウサイズ・ dp 倍率・キーボード高さを追い、設定リソースとプリセットを選ぶプロジェクト設定が増える — 便利なだけで必須ではない。

クイックスタート

見た目を変える — 色だけでなく形も

Theme が作り替えられるのはエンジンが描くものだけだ。StyleBoxFlat が持つ角は丸だけで、 スティック・クイックスロット・コーチマークはコードが直接描くため、テーマをいくら替えても形は変わらない。 そこで gohud は、テーマ・スキン・アイコンをひとまとまりで選ぶプリセットを用意している。

中世コレクション

同じ画面を、スマートフォンでもデスクトップでも

ギャラリーの4枚は縦持ちのスマートフォンだ。下は同じコードを 1280×800 で開いたもので、本文は読みやすい幅 (480dp) で止まって中央に立ち、HUD は隅に残る。フォームは浮かぶ HUD をよけて回り込むが、 もともと重なっていなければ動かない — 広い画面で無理に押しやると、本文が中心からずれてしまう。

同じシート、違う見た目

エディタからは プロジェクト設定 → gohud → Theme → Preset で選び、設定リソースからは GoConfig.preset で指定する。theme・skin・icons を明示的に 埋めると、そちらがプリセットより優先される — プリセットを選んだうえで1つだけ差し替えられる。

新しいテーマは JSON ファイル1枚だ。 new_theme.py kingdom --from medieval_dark が、 継承した値をすべて書き出したパレットを作る。make_theme.py kingdom がテーマ・コントロールの絵・ スキンのダイヤルまで生成し、プリセットは選択リストに自動で現れる。設定とダイヤルのすべて →

スキン — テーマが届かない場所

スキンが受け持つのは、スティック、クイックスロットの面、コーチマークのリング、チップ、スケルトン、 アラート、区切り線、セクション見出しだ。継承して、変えたいものだけを上書きすればよい。 

class_name MySkin extends GoSkin

func slot_box(accent: Color, lit: bool) -> StyleBox:
    var box := GoStyleBoxCut.new()
    box.bg_color = accent
    box.cut = 6.0
    box.edge_color = accent
    return box
クラス作れる形
GoStyleBoxCut角を斜めに切り落とした面取り、1辺だけ太いアクセント縁、外へにじむ発光
GoStyleBoxBracket中身を囲わず、四隅の印だけを引く
GoStyleBoxMedievalリベット・角の彫刻・ベベルのハイライト・素材の質感を持つ鍛造の枠
GoStyleBoxJellyゼリーキャンディ — 太い縁取り、押すと沈むしっかりした段、上が明るい本体と白いつや
GoStyleBoxComicマンガのコマ — 太いインクの輪郭とくっきりしたドロップシャドウ。どちらもゲーム実行中に GoConfig で大きさが決まる
GoStyleBoxArcadeアーケードのキーやボード — グラデーションの本体、白い光沢、押すと沈む段、インクの輪郭。ボードは淡い内側を厚い色の枠で囲む

6つとも Theme リソースへそのまま保存できる — だからこそテーマが色だけでなく形まで変えられる。 GoSkinSciFi、GoSkinMedieval、GoSkinMaterial、GoSkinKids、GoSkinComic、GoSkinArcade が同梱のサブクラスだ。

GoStyle.box() は必ず StyleBoxFlat を返す。 呼び出し側が受け取って bg_color や corner_radius を調整するからだ。独自の形を保ったままにしたいときは GoStyle.surface() を使う。

gohud には AI スキルが入っている — API のすべて、すぐ動くテンプレート、プレビュー起動器。下の文をまるごとコーディングエージェントに貼れば、gohud を入れて使い方まで覚える。

Go HUD Skill

読みやすさは目分量ではなく実測で決める

「きれい」は好みだが、「読める」は測れる。 薄い灰色の文字は良いモニタでは平気に見えて、 日中の屋外ではスマートフォンから消える — 目で選んでいれば、いつか必ずそうなる。 

python3 addons/gohud/tools/check_contrast.py

すべての色の組み合わせと、ボタンの状態ごとのラベルとその下のパネルを、14のテーマすべてで WCAG に 照らして測る。半透明の色は実際の背景に合成してから測る — そのまま測ると、画面に出ている見え方より 良い比率が出てしまう。

だから文字色は選ぶのではなく導き出す。ビルダーはパレットの値を出発点にして、その文字が載りうる すべての面でしきい値を超えるまで明度を押し上げる。パレットを変えればコントラストも追従する。 その規則と、背後にある落とし穴 →

検査・リリース・このサイト

入口1つですべての検査が走る。それぞれが、ほかからは見えないものを見ている。

bash addons/gohud/tools/check_all.sh
検査捕まえるもの
4つの画面サイズでの run_tests.shウィジェットの挙動とレイアウト、RTL での位置、キーボードフォーカス、実行時のスキンのコントラスト、全プリセット
new_project_check.shホストプロジェクトへの隠れた依存。--zip なら配布物そのまま、--export なら Web ビルドまで
check_contrast.py全テーマファイルの WCAG コントラスト — ボタンの状態も半透明パネルも含めて
check_generated.py · check_scaffold.sh生成されたテーマがパレットと一致するか、使い捨てのテーマが生成できてコントラストを通るか
check_package.pypackage.json のバージョンの反映、変更履歴の移動、ZIP の中身を一時コピー上で
check_site.pyこのサイトのリンク・アンカー・文書言語・用語集・ダイヤル表
直近の記録 — 2026-09-13、Godot 4.7.2、macOS、Compatibility レンダラー。 空のプロジェクトで 390×844・844×390・768×1024・1280×800 の4サイズとも 438/438、GoRuntime オートロードを有効にしても再び 438/438、 Web エクスポート成功、6テーマでコントラスト不足は 0。この実行に Android・iOS の実機は含まれていない。

リリース版を作る

cat addons/gohud/package.json       # { "version": "1.1.0" }
bash addons/gohud/tools/release.sh  # 検査すべて → ZIP → 空プロジェクトで検証
bash addons/gohud/tools/package.sh  # 1.1.0 → builds/1.1.0/gohud-1.1.0.zip

バージョンは package.json に書かれた値で、パッケージングがそれを上げることはない。 新しいバージョンを出すときは、先にその数字を書き換える。 成功すると plugin.cfg・GoUi.VERSION をその値に合わせ、そのバージョンを初めてパッケージングしたときだけ CHANGELOG.md の Unreleased の記述を日付付きの項目へ移す。 同じバージョンでもう一度実行すると ZIP を作り直して前のものと置き換える。失敗すれば何も変わらない。 ZIP にはこのサイトもテストもツールも package.json も入らない。

このサイト

python3 addons/gohud/tools/make_site.py            # 用語集とスキンのダイヤル表をソースから生成する
python3 addons/gohud/tools/check_site.py           # リンク・アンカー・言語・用語集・生成された表を検査する
bash addons/gohud/tools/site_shots.sh /tmp/shots   # 各ページのデスクトップ幅とスマートフォン幅を撮る
