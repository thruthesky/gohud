Game UI, driven by one resource

gohud is a HUD and UI kit for Godot 4.7 and newer. Floating windows, bottom sheets, dialogs, forms, snackbars, coach marks, HUD bars, quick slots and a virtual joystick run off one theme and one swappable icon set, and handle the safe area, the virtual keyboard, RTL and touch targets for you. Twelve presets — default, sci-fi, medieval, Material 3, kids and comic, each dark and light — change colours and shapes in one line.

New: comic, Material 3 and a look for kids

Three new families join default, sci-fi and medieval — twelve built-in looks now, each in dark and light. Every widget, popup and HUD piece takes them with no change to your code: switch the preset and the whole screen follows.

Material 3 — for app screens

Material 3 Expressive, measured against the official M3 tokens: pill buttons with a 40dp plate inside the 48dp touch target, 28dp dialogs and sheets, filled cards, outlined fields and the Expressive slider. The app components — navigation bar, app bar, FAB, search bar, chips, progress and the date picker — follow the M3 component tokens, and titles are set in the bundled Roboto. For shops, settings, inboxes and every screen that should feel like an app.

Kids — the toy box

Made for children: every key, row and panel is a jelly candy with a chunky outline and a solid lip that sinks when pressed, each kind of control in its own crayon colour. Quick slots are candy blocks, badges are stickers, the joystick is a rainbow, windows get a sunny title ribbon and a round candy close button, and a press squishes. Sizes and your project's font stay exactly as they were.

Comic — bold ink

Every face is a comic-book panel: the surface colour inside a bold ink outline, with a hard shadow behind it that goes when the face is pressed. One setting turns every shadow on or off, two more set the outline width and the shadow size, and one call does the same for a single widget. Windows get a yellow title caption.

GoUi.use_preset(GoThemePresets.MATERIAL_LIGHT)   # or MATERIAL_DARK
GoUi.use_preset(&"kids_light")                   # or &"kids_dark"
GoUi.use_preset(&"comic_light")                  # or &"comic_dark"

Comic: bold ink and a hard shadow

The newest look draws every face like a panel in a comic book — the surface colour inside a bold ink outline, with a hard, solid shadow dropped down and to the right. comic_light inks black on a paper-cream page with a cobalt primary; comic_dark inks cream on a night page with a yellow primary. Every picture below is a real gohud screen — the same code, one preset line. 

GoUi.use_preset(&"comic_light")   # or &"comic_dark"

Every widget, inked

Buttons, toggles, tabs, sliders, cards, forms, tables, pickers and chips all wear the ink — you do not style them one by one. Press a key and its shadow goes: the face sinks into its place, like a stamp. Disabled faces lose their shadow and fade, so what can be pressed stands out from what cannot.

At night: comic_dark

On a dark page a black outline would vanish, so comic_dark draws it in cream and drops a faint shadow tinted with the same ink. The HUD pieces — quick slots, bars, the joystick and the reward calendar — follow the same rules.

How the comic look works

One StyleBox for every face

Every face is a GoStyleBoxComic: a fill, an outline and a shadow, drawn inside the control’s own rectangle. It reads the outline and shadow sizes from GoConfig each time it draws, so one setting changes the whole screen at once.

Pressed means flat

A pressed key drops its shadow and moves into its place. Hover keeps the shadow; focus adds an inner ink ring that never covers the outline; disabled faces lose the shadow and fade.

The skin inks the rest

GoSkinComic inks what code draws: quick slots, chips, badges, avatars, notices, the navigation bar, the FAB, the date cells and the joystick, whose knob casts a shadow.

Windows get a caption

A window’s title sits on a yellow caption, like the narration box of a comic, next to an inked round close button. Dialogs, sheets, drawers and popovers are opaque inked panels.

Readable day and night

Both palettes pass the same WCAG contrast checks as every other preset, including pressed and disabled keys. When a caption colour would sit too close to the page, its outline falls back to the page colour.

No layout changes

The outline and shadow fit inside each control and the padding stays as the theme gave it, so a screen laid out in another look keeps its layout — and your project’s font.

Three settings and one call

Three GoConfig settings change every comic face at once. Nothing is rebuilt — the screen redraws as you set them.

GoUi.config.comic_border_width = 2.0   # the outline (dp) — 3 by default
GoUi.config.comic_shadow_size = 6.0    # the shadow (dp) — 4 by default
GoUi.config.comic_shadow = false       # no shadows anywhere

One widget can go its own way, whatever the settings say. Pass true as the last argument to include everything inside it.

GoStyle.comic_shadow(skip_button, false)     # this button sits flat
GoStyle.comic_shadow(card, true, true)       # this card and everything in it keep their shadow
GoStyle.comic_border(title, 5.0)             # a thicker outline on this one
Make a comic of your own. tools/new_theme.py inked --from comic_light copies the palette; change the paper, ink and primary colours and run tools/make_theme.py inked. The ink, the shadow and the skin come along.

What it takes off your hands

What costs the most time in game UI is not the shape of a button — it is everything that drifts apart between devices. gohud handles that drift in one place.

Every measurement is a token

Spacing, corners and text sizes are called by name, not written as numbers. Swap the theme and the whole screen moves with it.

Visible size ≠ pressable size

A close button looks 36dp but its touch target is 48dp. Where crowded slots overlap, the one whose centre is nearer takes the press.

Notches and keyboards

HUD pieces sit inside the safe area, and an input rises above the virtual keyboard when it appears.

Back closes one thing

Escape and Android Back close only the topmost surface. Stacked windows do not vanish together.

Notices never steal input

Press through a snackbar and the button underneath receives it. Focus is not taken either.

Icons are asked for by name

Widgets only know GoIconSet.CLOSE. Swap the set and every drawing changes without touching a line of code. Icons →

Twelve looks, one line

GoUi.use_preset() swaps theme, skin and icons together — rounded, chamfered sci-fi, forged medieval frames, Material 3 app components, kids' jelly candies or comic ink.

Legible by measurement

Every theme is checked against WCAG, including button states and translucent HUD panels over pure white and pure black.

Everything works without enabling the plugin. Enabling it adds a GoRuntime autoload that tracks window size, dp scale and keyboard height, plus project settings for the config resource and the preset — conveniences, not requirements.

Change the look — colours and shape

A Theme can only restyle what the engine draws. Rounded corners are the only corners StyleBoxFlat has, and the joystick, quick slots and coach mark are drawn by code — so a theme alone can never change their shape. gohud therefore ships presets: a theme, a skin and an icon set picked as one unit.

The same sheet, a different look

Pick one from Project Settings → gohud → Theme → Preset, or set GoConfig.preset. Filling in theme, skin or icons explicitly wins over the preset, so you can take a preset and override just one of them.

A new theme is one JSON file. new_theme.py kingdom --from medieval_dark writes a palette that spells out every inherited value; make_theme.py kingdom builds the theme, its control artwork and its skin dials, and the preset appears in the picker. Every setting and dial →

Skins — where a Theme cannot reach

A skin owns the joystick, quick-slot faces, the coach-mark ring, chips, skeletons, alerts, dividers and section headings. Subclass it and override only what you want changed. 

class_name MySkin extends GoSkin

func slot_box(accent: Color, lit: bool) -> StyleBox:
    var box := GoStyleBoxCut.new()
    box.bg_color = accent
    box.cut = 6.0
    box.edge_color = accent
    return box
ClassShapes it can make
GoStyleBoxCutDiagonally cut corners (chamfer), one thickened accent edge, an outer glow
GoStyleBoxBracketCorner marks only, without enclosing the content
GoStyleBoxMedievalA forged frame with rivets, corner engraving, a bevel highlight and material grain
GoStyleBoxJellyA jelly candy — a chunky outline, a solid lip that sinks when pressed, a body lighter on top and a white shine
GoStyleBoxComicA comic-book panel — a bold ink outline and a hard drop shadow, both sized by GoConfig while the game runs

All five serialise into a Theme resource — which is what lets a theme change shape, not just colour. GoSkinSciFi, GoSkinMedieval, GoSkinMaterial, GoSkinKids and GoSkinComic are the shipped subclasses.

GoStyle.box() always returns a StyleBoxFlat, because calling code receives it and adjusts bg_color or corner_radius. Use GoStyle.surface() when a custom shape has to survive.

Readability is measured, not eyeballed

"Pretty" is taste; "legible" can be measured. Faint grey text looks fine on a good monitor and disappears on a phone in daylight — picking by eye guarantees it eventually. 

python3 addons/gohud/tools/check_contrast.py

Every colour pair and every button state's label over the panel it sits on is measured against WCAG, in all twelve themes. Translucent colours are composited over their real backdrop first — measuring them directly reports a better ratio than the screen shows.

Text colours are therefore derived, not chosen: the builder takes the palette entry as a starting point and pushes its lightness until it clears the threshold on every surface it can land on. Change the palette and the contrast follows. The rules and the traps behind them →

Release versions

cat addons/gohud/package.json       # { "version": "1.1.0" }
bash addons/gohud/tools/release.sh  # every check → ZIP → that ZIP in an empty project
bash addons/gohud/tools/package.sh  # 1.1.0 → builds/1.1.0/gohud-1.1.0.zip

The version is the one written in package.json — packaging never raises it. To release a new version, change that number first. A successful run sets plugin.cfg and GoUi.VERSION to it and, the first time that version is packaged, moves the Unreleased notes of CHANGELOG.md into a dated entry. Packaging the same version again rebuilds its ZIP and replaces the old one. A failed run changes nothing. The ZIP leaves out this website, the tests, the tools and package.json.
