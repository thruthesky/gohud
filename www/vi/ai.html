Go HUD Skill

gohud có sẵn một AI skill: toàn bộ API, mẫu chạy được ngay và trình mở xem trước. Dán một khối dưới đây vào tác nhân lập trình của bạn, nó sẽ cài gohud và biết cách dùng.

Chép lời nhắc cài đặt Cài đặt

Dán khối này vào tác nhân lập trình của bạn

Mở dự án Godot trong tác nhân, dán khối bên dưới rồi gửi. Nó cài skill và add-on, sau đó kể cho bạn nghe gohud làm được những gì.

  1. Mở terminal trong thư mục dự án Godot và khởi động tác nhân lập trình ở đó — ví dụ claude.
  2. Bấm Chép trên khối bên dưới, dán vào tác nhân rồi gửi.
  3. Khi xong, khởi động lại tác nhân nếu nó yêu cầu, rồi hỏi: gohud làm được gì?
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
Khối này cố ý viết bằng tiếng Anh — đó là thứ mọi tác nhân đọc chính xác nhất. Bạn cứ hỏi bằng ngôn ngữ nào cũng được; skill trả lời bằng đúng ngôn ngữ bạn viết.

Hoặc gõ hai lệnh — Claude Code

Cách này cài skill dưới dạng plugin của Claude Code. Trong terminal:

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

Đang ở trong Claude Code rồi? Hãy gõ những lệnh này:

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

Sau đó khởi động lại Claude Code và gõ /gohud:features — nếu hiện danh sách tính năng của gohud thì skill đã được cài. Bản thân add-on vẫn phải nằm trong addons/gohud: Cài đặt →

Mỗi tác nhân giữ skill ở đâu

Muốn tự cài? Đặt thư mục skills/gohud vào nơi tác nhân của bạn đọc. Nơi nào có trước thì thắng.

Những lệnh bạn có được

/gohud:preview — gallery widget

Mở gallery: mọi widget, một danh sách chọn cho cả sáu preset và trọn bộ biểu tượng. Gõ lệnh này bên trong dự án Godot của bạn thì nó dùng addons/gohud của bạn; không có thì nó dùng bản kèm theo plugin, hoặc clone mới một bản. Nó chạy trong một dự án sandbox dùng xong bỏ, nên autoload và bộ nhớ đệm import của bạn không bị đụng tới, còn cửa sổ thì mở cho đến khi bạn đóng.

/gohud:preview demo — chuyến tham quan 15 chương

Mở bản demo ở màn hình đầu. Bắt đầu demo chạy chuyến tham quan bằng thao tác thật; Khám phá widget cho bạn tự thử từng widget. Các phím liệt kê ở mục Ví dụ cũng dùng được ở đây.

Lệnh xem trước cần Godot 4.6 trở lên trong PATH.

Hoặc cứ hỏi thẳng

Hoặc cứ hỏi thẳng. Skill này dạy cho agent toàn bộ API của gohud, nên yêu cầu bằng lời bình thường cũng chạy — "Dựng giúp tôi một menu tạm dừng bằng gohud". Nếu cài như một skill thường ở ~/.claude/skills/gohud, các lệnh viết cách ra một khoảng trắng: /gohud preview demo, /gohud features. Xem trước cần Godot 4.6 trở lên nằm trong PATH, hoặc truyền --godot /path/to/godot.
