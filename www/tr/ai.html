gohud bir yapay zekâ becerisiyle gelir: API'nin tamamı, çalışmaya hazır şablonlar ve önizleme başlatıcı. Tek bloğu ajanınıza yapıştırın; gohud'u kurar ve nasıl kullanacağını bilir.

Bloğu gör Kurulum

Bunu kodlama ajanınıza yapıştırın

Godot projenizi ajanda açın, bloğu yapıştırıp gönderin. Beceriyi ve eklentiyi kurar, sonra gohud'un neler yapabildiğini anlatır.

Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, if addons/gohud/plugin.cfg is missing here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import

3. Restart yourself so the skill loads, then tell me what gohud can do
   and how to preview it.

Docs: https://thruthesky.github.io/gohud/

Kazandığınız komutlar

/gohud:preview — widget galerisi

Galeriyi açar: her widget, altı ön ayarın tamamı için bir seçici ve simge setinin tamamı. Komutu kendi Godot projenizin içinde yazarsanız sizin addons/gohud klasörünüzü kullanır; proje yoksa eklentiyle gelen kopyayı ya da taze bir klonu kullanır. Kullan-at bir sandbox projesinde çalışır, böylece autoload'larınıza ve içe aktarma önbelleğinize dokunulmaz; pencere siz kapatana kadar açık kalır.

/gohud:preview demo — 15 bölümlük rehberli tur

Demoyu başlangıç ekranında açar. Demoyu başlat turu gerçek girdiyle oynatır; Widget'ları keşfet tek bir widget'ı elle denemenizi sağlar. Örnekler altında listelenen tuşlar burada da çalışır.

Ya da sadece isteyin

Ya da sadece sorun. Beceri, ajana gohud'un bütün API'sini öğretir; dolayısıyla düz istekler de işe yarar — "gohud ile bir duraklatma menüsü kur". ~/.claude/skills/gohud içinde düz bir beceri olarak kurulduğunda komutlar boşlukla yazılır: /gohud preview demo, /gohud features. Önizlemeler için PATH üzerinde Godot 4.6 veya daha yenisi gerekir; ya da --godot /path/to/godot geçirin.
