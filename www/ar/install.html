التثبيت

ضع مجلد الإضافة في مشروعك. لا شيء آخر يحتاج إعدادًا.

من متجر الأصول أو من ملف ZIP للإصدار

فُكّ الضغط في جذر مشروعك بحيث تحصل على res://addons/gohud/. هذا كل شيء. واختياريًا فعّل Project → Project Settings → Plugins → gohud.

كوحدة فرعية في git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # اختياري: ثبّت وسمًا أو كوميت بعينه

جذر المستودع هو مجلد الإضافة نفسه، فيحطّ تمامًا حيث يتوقعه Godot. عدّل في مكانه، ثم أودِع وادفع داخل addons/gohud، ثم أودِع مؤشّر الوحدة الفرعية في لعبتك.

يلزم Godot 4.6 أو أحدث. يستعمل gohud واجهات برمجية ظهرت في 4.5 (DPITexture و FoldableContainer وخصائص الوصولية)، فعلى أي إصدار أقدم يفشل أثناء التحليل. الإصدار 4.6 هو الحد الأدنى المدعوم، ومسجَّل في GoUi.MIN_ENGINE.

بداية سريعة

كل ودجت هو .new() ثم add_child() — لا ملفات مشاهد ولا autoload.

اختر المظهر قبل بناء الواجهة (اختياري)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # يُستعمل default_dark إن تخطيت هذا السطر

تأكيد تنتظره بـ await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("حذف الحفظ", "لا يمكن التراجع عن هذا."):
    delete_save()

مرّر destructive = true (المعامل الأخير) فيُرسم زر التأكيد زرًّا مصمتًا بلون الخطر.

ورقة سفلية بحقل بحث وتذييل ثابتين

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("الحقيبة")
sheet.toolbar().add_child(GoStyle.line_edit("بحث…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("إغلاق", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
لماذا تنفصل الصفوف الثابتة عن الجسم المتمرر. ضع التأكيد والإلغاء في body فتدفعهما قائمة طويلة خارج الشاشة. أما footer() فيبقى ظاهرًا دائمًا.

ركن من HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

محتوى يتنحّى عن HUD

form.avoid_hud = true                  # ابتعد عن كل GoHudAnchor ظاهر
joystick_anchor.reserve_space = false  # …إلا ما لا يظهر إلا تحت الإصبع
notice_anchor.avoid_peers = true       # يستقر الإشعار تحت HUD الثابت بدل أن يغطيه

كل مستطيل يُتفادى في الاتجاه الأقل كلفة من حيث المساحة — نزولًا على هاتف بالوضع الطولي، وجانبًا في الوضع العرضي. كيف يتفادى HUD نفسه ←

أمثلة تستطيع تشغيلها

ثلاث طرق ترى بها gohud قبل أن تكتب سطرًا — ولا واحدة منها تحتاج خادمًا ولا autoload.

المثالكيف تفتحهما الذي يعرضه
المعرضexamples/gallery/gallery.tscn · F6كل ودجت، وقائمة اختيار لكل نمط جاهز مثبّت، ومجموعة الأيقونات كاملة
العصور الوسطىexamples/medieval/medieval.tscn · F6صفحة شخصية وحقيبة وسجل مهام؛ والأزرار تبدّل بين الحديد والرقّ وتفتح تفاصيل الأغراض
تطبيق العرض التوضيحيcd examples/demo && godotشاشة رئيسية تفتح المعرض، والجولة الإرشادية ذات الـ 15 فصلًا، وشاشة الاستعراض، ومظهر العصور الوسطى، بودجات حيّة وبطاقة لكل صنف
 
cd examples/demo && godot                             # الشاشة الرئيسية؛ يربط ويستورد عند أول تشغيل
bash examples/demo/run.sh                               # التطبيق نفسه، من جذر الإضافة
bash examples/demo/run.sh -- --open=gallery             # تخطَّ الشاشة الرئيسية
bash examples/demo/run.sh -- --explore=surfaces         # افتح مباشرة على فصل واحد من الجولة
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # تسجيل الجولة بدقة 1080p و60 إطارًا/ثانية

تطبيق العرض التوضيحي لا يحتاج إعدادًا: فإن غاب رابط الإضافة أو ذاكرة الاستيراد نبّه إلى ذلك، ثم أصلح المجلد وأعاد فتح نفسه. وشاشته الرئيسية تفتح كل مثال داخل النافذة نفسها — اضغط 1–4 أو انقر صفًّا، والشريط الممتد في الأعلى يعيدك.

وفي الجولة، يبدّل C وضع السينما، وF11 ملء الشاشة، وSpace يوقف مؤقتًا (أو يشغّل الودجت الحالية أثناء الاستكشاف)، والأسهم تغيّر الفصول، وEscape يعود إلى البداية.
