Go HUD Skill

يأتي gohud بمهارة ذكاء اصطناعي: واجهة البرمجة كاملة، وقوالب جاهزة للتشغيل، ومشغّل معاينة. الصق الكتلة أدناه في وكيل البرمجة لديك فيثبّت gohud ويعرف كيف يستخدمه.

انسخ موجّه التثبيت التثبيت

الصق هذا في وكيل البرمجة لديك

افتح مشروع Godot في الوكيل، والصق الكتلة أدناه ثم أرسلها. سيثبّت المهارة والإضافة، ثم يخبرك بما يستطيع gohud فعله.

  1. افتح طرفية في مجلد مشروع Godot وشغّل وكيل البرمجة هناك — مثلًا claude.
  2. اضغط نسخ على الكتلة أدناه، والصقها في الوكيل ثم أرسلها.
  3. عند انتهائه، أعد تشغيل الوكيل إن طلب ذلك، ثم اسأله: ماذا يستطيع gohud أن يفعل؟
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
كُتبت الكتلة بالإنجليزية عن قصد — فهي اللغة التي يقرأها كل وكيل بأعلى دقة. أما أسئلتك فاطرحها بأي لغة؛ تجيبك المهارة باللغة التي تكتب بها.

أو اكتب أمرين — Claude Code

يثبّت هذا المهارة كإضافة لـ Claude Code. في الطرفية:

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

أنت داخل Claude Code بالفعل؟ اكتب هذه بدلًا من ذلك:

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

ثم أعد تشغيل Claude Code واكتب /gohud:features — إن ظهرت قائمة ميزات gohud فالمهارة مثبّتة. أما الإضافة نفسها فلا بد أن تكون في addons/gohud: التثبيت →

أين يحفظ كل وكيل المهارات

تفضّل التثبيت يدويًا؟ ضع مجلد skills/gohud في المكان الذي يقرأ منه وكيلك. الأسبق وجودًا هو المعتمد.

الأوامر التي تحصل عليها

/gohud:preview — معرض الودجات

يفتح المعرض: كل ودجت، وقائمة اختيار للأنماط الجاهزة الستة، ومجموعة الأيقونات كاملة. اكتبه داخل مشروع Godot خاصتك فيستعمل addons/gohud الخاص بك؛ وبدون ذلك يستعمل النسخة المرفقة مع الإضافة، أو نسخة جديدة يستنسخها. يعمل داخل مشروع رملي مؤقت، فتبقى قوائم autoload وذاكرة الاستيراد عندك على حالها، وتبقى النافذة مفتوحة حتى تغلقها أنت.

/gohud:preview demo — الجولة الإرشادية ذات الـ 15 فصلًا

يفتح العرض التوضيحي على شاشة البداية. ابدأ العرض يشغّل الجولة بلمس حقيقي، واستكشف الودجات يتيح لك تجربة ودجت واحدة بيدك. والمفاتيح المذكورة تحت الأمثلة تعمل هنا أيضًا.

أو اطلب ببساطة

أو اطلب ببساطة. المهارة تعلّم الوكيل واجهة gohud البرمجية كاملة، فتنجح الطلبات العادية أيضًا — "ابنِ قائمة إيقاف مؤقت بـ gohud". وإن ثُبّتت مهارةً عادية في ~/.claude/skills/gohud، فالأوامر تأخذ مسافة: /gohud preview demo و/gohud features. وتحتاج المعاينات إلى Godot 4.6 أو أحدث على PATH، أو مرّر --godot /path/to/godot.
