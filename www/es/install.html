La vía más rápida: que lo instale tu agente de IA

Un bloque de texto, pegado en Claude Code, Codex, Cursor o Gemini CLI, instala la skill y el complemento y luego te explica gohud. Si tomas ese camino, nada de lo que hay debajo de esta tarjeta hace falta.

Instalación

Copia la carpeta del add-on dentro de tu proyecto. No hay nada más que configurar.

Desde la Asset Store o un ZIP de la versión

Descomprime en la raíz de tu proyecto para obtener res://addons/gohud/. Eso es todo. De forma opcional, activa Proyecto → Ajustes del proyecto → Plugins → gohud.

Como submódulo de git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # opcional: fija una etiqueta o un commit

La raíz del repositorio es la carpeta del add-on, así que queda exactamente donde Godot la espera. Edita ahí mismo, haz commit y push dentro de addons/gohud y luego registra el puntero del submódulo en tu juego.

Se requiere Godot 4.6 o posterior. gohud usa APIs introducidas en 4.5 (DPITexture, FoldableContainer, propiedades de accesibilidad), así que en versiones anteriores falla al analizar el código. 4.6 es la versión mínima admitida, registrada en GoUi.MIN_ENGINE.

Inicio rápido

Todo widget es .new() y add_child() — sin archivos de escena, sin autoload.

Elige un aspecto antes de construir la interfaz (opcional)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # si lo omites se usa default_dark

Una confirmación con await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Borrar partida", "Esto no se puede deshacer."):
    delete_save()

Pasa destructive = true (el último argumento) y el botón de confirmar se dibuja como un botón de peligro relleno.

Una hoja inferior con campo de búsqueda y pie fijos

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventario")
sheet.toolbar().add_child(GoStyle.line_edit("Buscar…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Cerrar", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Por qué las filas fijas están separadas del cuerpo desplazable. Si pones confirmar y cancelar en body, una lista larga los empuja fuera de la pantalla. footer() siempre está visible.

Una esquina del HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Contenido que se mantiene fuera del HUD

form.avoid_hud = true                  # se aparta de todo GoHudAnchor visible
joystick_anchor.reserve_space = false  # …salvo los que solo aparecen bajo un dedo
notice_anchor.avoid_peers = true       # el aviso se coloca bajo el HUD fijo en vez de taparlo

Cada rectángulo se esquiva en la dirección que menos área cuesta — hacia abajo en un teléfono vertical, hacia los lados en horizontal. Cómo el HUD se esquiva a sí mismo →

Ejemplos que puedes ejecutar

Tres formas de ver gohud antes de escribir una línea — ninguna necesita servidor ni autoload.

EjemploCómo abrirloQué muestra
Galeríaexamples/gallery/gallery.tscn · F6Todos los widgets, un selector para cada preajuste instalado y el juego de iconos completo
Medievalexamples/medieval/medieval.tscn · F6Una hoja de personaje, un zurrón y un diario de misiones; los botones alternan entre hierro y pergamino y abren el detalle de los objetos
App de democd examples/demo && godotUna pantalla de inicio que abre la galería, el recorrido guiado de 15 capítulos, la pantalla de muestra y el aspecto medieval, con widgets en vivo y una tarjeta por clase
 
cd examples/demo && godot                             # pantalla de inicio; enlaza e importa en la primera ejecución
bash examples/demo/run.sh                               # la misma app, desde la raíz del add-on
bash examples/demo/run.sh -- --open=gallery             # omite la pantalla de inicio
bash examples/demo/run.sh -- --explore=surfaces         # abre directamente en un capítulo del recorrido
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # grabación del recorrido a 1080p / 60 fps

La app de demo no necesita ninguna preparación: si falta el enlace al add-on o la caché de importación, lo indica, repara la carpeta y se vuelve a abrir sola. Su pantalla de inicio abre cada ejemplo dentro de la misma ventana — pulsa 1–4 o haz clic en una fila, y la barra superior te trae de vuelta.

En el recorrido, C alterna el modo cine, F11 la pantalla completa, Espacio pausa (o reproduce el widget actual mientras exploras), las flechas cambian de capítulo y Escape vuelve al inicio.
