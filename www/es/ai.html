AI SKILL

gohud trae una skill de IA: toda la API, plantillas listas para ejecutar y un lanzador de vista previa. Pega un bloque en tu agente y él instala gohud y sabe usarlo.

Ver el bloque Instalación

Pega esto en tu agente de código

Abre tu proyecto de Godot en el agente, pega el bloque y envíalo. Instala la skill y el complemento, y luego te cuenta qué puede hacer gohud.

Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, if addons/gohud/plugin.cfg is missing here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import

3. Restart yourself so the skill loads, then tell me what gohud can do
   and how to preview it.

Docs: https://thruthesky.github.io/gohud/
El bloque está en inglés a propósito: es lo que todo agente lee con más fiabilidad. Tus preguntas pueden ir en cualquier idioma; la skill responde en el idioma en que escribes.

Los comandos que obtienes

/gohud:preview — la galería de widgets

Abre la galería: todos los widgets, un selector para los seis preajustes y el juego de iconos completo. Escríbelo dentro de tu proyecto de Godot y usará tu addons/gohud; sin proyecto usa la copia incluida con el plugin, o un clon nuevo. Se ejecuta en un proyecto de prueba desechable, así que tus autoloads y tu caché de importación quedan intactos, y la ventana permanece abierta hasta que la cierras.

/gohud:preview demo — el recorrido guiado de 15 capítulos

Abre la demo en su pantalla de inicio. Start demo reproduce el recorrido con entrada real; Explore widgets te deja probar un widget a mano. Las teclas listadas en Ejemplos también funcionan aquí.

O simplemente pídelo

O simplemente pídelo. La skill le enseña al agente toda la API de gohud, así que también funcionan las peticiones en lenguaje natural — "Crea un menú de pausa con gohud". Instalada como skill normal en ~/.claude/skills/gohud, los comandos llevan un espacio: /gohud preview demo, /gohud features. Las vistas previas necesitan Godot 4.6 o posterior en tu PATH, o pasar --godot /path/to/godot.
