Go HUD Skill

gohud embarque une compétence IA : toute l'API, des modèles exécutables et un lanceur d'aperçu. Collez un bloc dans votre agent : il installe gohud et sait s'en servir.

Copier le prompt d'installation Installation

Collez ceci dans votre agent de code

Ouvrez votre projet Godot dans l'agent, collez le bloc et envoyez. Il installe la compétence et l'extension, puis vous dit ce que gohud sait faire.

  1. Ouvrez un terminal dans le dossier de votre projet Godot et lancez-y votre agent de code — par exemple claude.
  2. Appuyez sur Copier sur le bloc ci-dessous, collez-le dans l'agent et envoyez.
  3. Quand il a fini, redémarrez l'agent s'il vous le demande, puis demandez-lui : Que sait faire gohud ?
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
Le bloc est en anglais à dessein : c'est ce que tout agent lit le plus fidèlement. Posez vos questions dans la langue que vous voulez ; la compétence répond dans la vôtre.

Ou tapez deux commandes — Claude Code

Cela installe la compétence comme plugin Claude Code. Dans un terminal :

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

Déjà dans Claude Code ? Tapez plutôt ceci :

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

Redémarrez ensuite Claude Code et tapez /gohud:features — si la liste des fonctionnalités de gohud s'affiche, la compétence est installée. L'extension elle-même doit toujours se trouver dans addons/gohud : Installation →

Les commandes que vous obtenez

/gohud:preview — la galerie des widgets

Ouvre la galerie : tous les widgets, un sélecteur pour les six préréglages et le jeu d'icônes complet. Tapez-la à l'intérieur de votre projet Godot et elle utilise votre addons/gohud ; en dehors, elle utilise la copie fournie avec le plugin, ou un clone tout neuf. Elle s'exécute dans un projet bac à sable jetable : vos autoloads et votre cache d'import restent intacts, et la fenêtre reste ouverte jusqu'à ce que vous la fermiez.

/gohud:preview demo — la visite guidée en 15 chapitres

Ouvre la démo sur son écran de départ. Démarrer la démo joue la visite avec de vraies entrées ; Explorer les widgets vous laisse essayer un widget à la main. Les touches listées dans Exemples fonctionnent ici aussi.

Les commandes d'aperçu demandent Godot 4.6 ou plus récent dans votre PATH.

Ou demandez simplement

Ou demandez simplement. La skill enseigne à l'agent toute l'API de gohud : une demande en langage courant marche aussi — « Construis un menu de pause avec gohud ». Installées comme simple skill dans ~/.claude/skills/gohud, les commandes prennent une espace : /gohud preview demo, /gohud features. Les aperçus ont besoin de Godot 4.6 ou plus récent dans votre PATH, ou passez --godot /path/to/godot.
