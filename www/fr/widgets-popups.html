Choisir le bon pop-up

Un pop-up interrompt. Avant d'en choisir un, répondez à une seule question : le joueur doit-il répondre avant que le jeu continue ? Si oui, bloquez. Si non, ne bloquez jamais — une carte qui arrête le jeu pour une nouvelle que le joueur n'a pas demandée est le moyen le plus rapide de lui faire fermer votre jeu.

  1. Une question qui attend une réponse — acheter, supprimer, quitter, écraser → GoDialogs.confirm(). Une information à prendre en compte → alert(). Une option parmi quelques-unes → choose().
  2. Un écran à part entière — les réglages, une fiche de personnage, un article de boutique → GoSurface au milieu de l'écran.
  3. Une longue liste ou une page de gestion — la besace, le courrier, les amis → GoSheet depuis le bas sur un téléphone, GoDrawer depuis le côté sur un grand écran.
  4. Quelque chose sur ce qu'on vient d'appuyer — les statistiques d'un objet, ses actions → GoPopover ou GoContextMenu juste à côté.
  5. Une nouvelle pendant laquelle le jeu peut continuer — sauvegardé, lâché, invité → GoSnackbar, GoNotice ou GoPromptCard. Ceux-là ne prennent jamais l'écran.
  6. Apprendre les commandes → GoCoachMark. Des triches pendant le développement → GoConsole.

Anatomie d'un pop-up

Presque tous les pop-ups bloquants de gohud — boîtes de dialogue, feuilles, cartes épinglées, la liste du combobox et vos propres fenêtres — reposent sur un seul nœud, GoSurface. Apprenez ses parties une fois et vous les connaissez toutes.

PartieCe que c'estComment y accéder
CalqueLe CanvasLayer sur lequel vit le pop-up. Son numéro décide de ce qu'il recouvre.À vous pour un GoSurface ; intégré pour les autres (tableau)
VoileLe voile posé sur tout ce qui se trouve derrière. Il attrape les appuis qui manquent la carte.scrim_transparent, dismiss_on_scrim, la couleur scrim du thème
CarteLa fenêtre elle-même — la face de panneau du thème, arrondie, coupée, forgée ou en gelée selon l'apparence.card, alpha
En-têteUn bouton retour facultatif, le titre (deux lignes au plus, puis « … »), le bouton de fermeture.set_title() · set_title_key() · set_back() · close_enabled · show_header
Barre d'outilsUne rangée fixe sous l'en-tête — un champ de recherche, des puces de filtre. Masquée tant que vous ne l'utilisez pas.toolbar
CorpsLa partie qui défile. Mettez-y le contenu.body · scroll_body · clear()
Ligne d'étatUne ligne fixe entre le corps et le pied — « Échec de la vérification du nom », « Enregistrement… ».set_status_text() · set_status_key() · clear_status()

Ce qui doit rester visible va dans les rangées fixes. Un champ de recherche, une erreur ou un bouton Enregistrer placés dans le corps défilent avec une longue liste — le joueur tape un mauvais nom, l'erreur est hors de vue, et rien ne semble se passer. Utilisez toolbar, la ligne d'état et footer ; ils restent en place pendant que le corps défile.

Des boîtes de dialogue que vous await

GoDialogs pose la question et attend. Un nœud, trois questions — et la réponse revient sur la même ligne, si bien que le code se lit dans l'ordre où le joueur le vit.

var dialogs := GoDialogs.new()
add_child(dialogs)

if await dialogs.confirm("Buy the starter pack?", "300 gems for a sword, a shield and 10 potions.",
        "Buy", "Not now"):
    buy_starter_pack()

Les trois questions

confirm(title, body, ok_text := "", cancel_text := "", extra := "",
        args := {}, destructive := false) -> bool
alert(title, body, ok_text := "", extra := "", args := {})      # await pour attendre
choose(title, options: Array, cancel_text := "", translate := false) -> int
confirm_key(…) · alert_key(…)                                 # clés de traduction
AppelRenvoieSert à
confirm()true ou falseOui ou non — acheter, supprimer, quitter, écraser.
alert()rien — faites await dessus pour attendreCe que le joueur doit voir : une récompense, une connexion perdue.
choose()l'indice de l'option, ou -1Une option parmi quelques-unes. Une option est un String ou {text, icon, danger, subtitle}.
confirm_key() · alert_key()comme ci-dessusLa même chose avec des clés de traduction — les mots suivent un changement de langue pendant que la boîte de dialogue est ouverte.

Des libellés de bouton vides retombent sur les mots du kit (confirm, cancel dans GoConfig.text_keys). extra s'ajoute au corps sur une nouvelle ligne. args remplit les {placeholders} du titre et du corps : confirm("Buy {item}?", "It costs {price} gold.", "Buy", "", "", {"item": name, "price": 300}).

Le code qui suit await s'exécute donc toujours — aucune réponse ne reste en suspens, même quand la scène change sous la boîte de dialogue.

Actions destructives

Passez destructive = true pour ce qui ne peut pas être annulé. Le bouton OK devient le bouton plein Tone.DANGER_SOLID — blanc sur rouge dans chaque apparence, là où un libellé de danger teinté devrait s'assombrir presque jusqu'au noir sur un thème clair pour rester lisible. La tonalité est réinitialisée à chaque appel, car la fenêtre est réutilisée.

if await dialogs.confirm("Delete this save?", "Slot 2 — Aria, level 12. This cannot be undone.",
        "Delete", "Keep it", "", {}, true):
    delete_save(2)
OK a le focus clavier. Chaque confirmation s'ouvre avec le focus sur son bouton OK : Entrée ou Espace confirme — y compris une confirmation destructive. Formulez les boutons pour que le choix sûr soit évident (« Le garder »), et placez les actions irréversibles derrière une seconde étape quand une erreur de doigt coûte au joueur une vraie progression.

Disposition des boutons

action_layoutCe qu'il fait
VERTICAL (par défaut)Boutons empilés, pleine largeur. Sûr dans toutes les langues — un long libellé allemand ou russe n'est jamais comprimé.
HORIZONTALUne seule rangée, la moitié de la largeur chacun.
AUTOUne seule rangée quand les deux libellés tiennent sur une ligne dans la moitié de la carte ; empilés sinon. Décidé de nouveau à chaque changement de langue ou de taille.

action_gap est l'espace entre les boutons, body_gap l'espace au-dessus d'eux — faites-le plus large que l'écart entre boutons pour que la question et le choix se lisent comme deux parties. Pour une seule boîte de dialogue, appelez set_next_action_layout() avant de l'ouvrir. Le bouton unique d'une alerte prend toujours toute la largeur.

Une à la fois

Un second confirm() pendant qu'une boîte de dialogue est ouverte renvoie false immédiatement — une boîte de dialogue ne s'empile jamais par accident sur une autre. Activez queue_when_busy et elle attend son tour à la place ; alert() attend toujours. queue_limit (8) plafonne la file, et en cas de débordement la demande la plus ancienne reçoit false. pending() compte les demandes en attente et clear_pending() leur répond à toutes false. choose() ne se met jamais en file : il renvoie -1 quand une boîte de dialogue est déjà ouverte.

Téléphone et ordinateur

choose() s'ouvre en feuille depuis le bas sur Android et iOS — là où se trouve le pouce — et en carte au milieu sur un ordinateur. Une confirmation est plafonnée à max_width (420dp) et centrée. Réglez layer_index, max_width et les autres exports avant add_child ; ils sont appliqués quand le nœud entre dans l'arbre.

var picked := await dialogs.choose("Sort the bag by", [
    {"text": "Newest first", "icon": GoIconSet.CLOCK},
    {"text": "Rarity", "icon": GoIconSet.STAR},
    {"text": "Drop everything", "icon": GoIconSet.TRASH, "danger": true}])
if picked >= 0:
    sort_bag(picked)

GoSurface — une fenêtre à vous

Quand un pop-up est plus qu'une question — des réglages, une fiche de personnage, un objet à acheter —, construisez-le sur GoSurface. La zone sûre, le clavier, les rangées fixes, le défilement, Retour, le focus et le redimensionnement sont déjà réglés.

var layer := CanvasLayer.new()
layer.layer = 50
add_child(layer)

var window := GoSurface.new()
window.set_title("Settings")
window.close_requested.connect(layer.queue_free)
window.body.add_child(GoStyle.toggle("Music", false))
window.body.add_child(GoStyle.slider(0.0, 1.0, 0.05))
var row := GoStyle.row()
row.add_child(GoStyle.button("Cancel", window.request_close))
row.add_child(GoStyle.button("Save", save_and_close, GoStyle.Tone.PRIMARY))
window.footer.add_child(row)
window.footer.visible = true
layer.add_child(window)
Elle ne se ferme jamais d'elle-même. ×, Échap, Retour et un appui sur le voile ne font qu'émettre close_requested. Masquer ou libérer la fenêtre revient à l'écran propriétaire — lui seul sait si « fermer » veut dire enregistrer, abandonner ou demander d'abord.

Trois placements

ANCHOR a besoin de anchor_control. La carte se place à sa droite si anchor_min_width y tient, sinon du côté le plus large, sinon à l'intérieur de l'écran, et s'ouvre vers le haut quand il y a plus de place au-dessus. Elle suit une ancre mobile à chaque image. anchor_width (320) et anchor_max_height (520) la dimensionnent.

Le clavier pousse la carte vers le haut et fait défiler le champ qui a le focus jusqu'à le rendre visible ; la zone sûre la tient à l'écart de l'encoche et de la barre de gestes sur Android et iOS.

Feuilles et tiroirs

Une liste qui a besoin de place monte depuis le bas sur un téléphone tenu à la verticale — là où se trouve le pouce — et arrive par le côté sur une tablette ou un ordinateur, où une feuille recouvrirait le jeu.

GoSheet — des pages venues du bas

var sheet := GoSheet.new()
add_child(sheet)

func show_bag(items: Array) -> void:
    sheet.open("Bag")
    var search := GoStyle.line_edit("Search the bag…")
    search.text_changed.connect(filter_bag)
    sheet.toolbar().add_child(search)
    sheet.toolbar().visible = true
    for item in items:
        sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, show_item.bind(item),
            Color.TRANSPARENT, item.description, false, GoIconSet.CHEVRON_RIGHT))
    sheet.add_footer(GoStyle.button("Close", sheet.close, GoStyle.Tone.PRIMARY))
  • C'est un CanvasLayer (calque 10) qui contient un GoSurface BOTTOM redimensionnable — il se place donc au-dessus du HUD, et le joueur peut l'agrandir en le faisant glisser.
  • open(title) commence une nouvelle page : il vide le corps, la barre d'outils et le bouton retour, et libère ce que add_footer() a ajouté. Rappelez-le pour afficher une autre page dans la même feuille ; set_back() affiche un bouton retour pour revenir à la page d'accueil. open_key() prend une clé de traduction.
  • close() la masque — elle n'est pas libérée, si bien que le open() suivant est instantané. closed et page_changed vous préviennent.
  • height_ratio (0.6) est la hauteur d'ouverture ; max_height_ratio relève le plafond ; dismissable (true) la ferme sur un appui sur le voile.
Échap et Retour ferment toute la feuille, même sur une sous-page avec set_back() — seul le bouton retour à l'écran revient d'une page. Si Retour doit revenir d'une page, gérez vous-même close_requested sur sheet.surface.

GoDrawer — depuis le côté

var drawer := GoDrawer.new()
drawer.side = GoDrawer.Side.LEFT
drawer.follow_text_direction = true      # le côté du début : la gauche, ou la droite en arabe
add_child(drawer)
drawer.body.add_child(GoNavBar.drawer_list([{"icon": GoIconSet.HOME, "text": "Town"},
    {"icon": GoIconSet.MAP, "text": "World map"}], 0, go_to))
drawer.open("Menu")
  • Calque 80. 42 % de la largeur de l'écran (width_ratio), entre min_width (320dp) et max_width (420dp) — sur un téléphone, il couvre la plus grande partie de l'écran, c'est pourquoi une feuille y est le meilleur choix.
  • Le panneau va jusqu'au bord de l'écran ; seul son contenu se retire de la zone sûre, pour qu'un coin arrondi ne rogne jamais la première rangée.
  • LEFT veut dire la gauche de l'écran, même en arabe. Activez follow_text_direction quand c'est « le côté du début » qui compte ; effective_side() vous dit de quel côté il s'est placé.
  • open(title) garde le corps — remplissez-le une fois. set_title("") masque l'en-tête. motion_seconds (0.2) le fait glisser ; reduce_motion le rend instantané.
Le Retour Android ferme un tiroir ; Échap, non. Le tiroir n'écoute que le Retour du système. Sur un ordinateur, appelez drawer.close() depuis votre propre raccourci clavier — et notez que GoSurface.is_any_open() ne compte pas les tiroirs ; demandez à drawer.is_open().

Cartes et menus à côté d'une commande

Ce sur quoi le joueur vient d'appuyer mérite une réponse juste à côté du doigt, pas au milieu de l'écran.

GoPopover — une carte sur ce qu'on a appuyé

slot.pressed.connect(func() -> void:
    var card := GoStyle.item_card({"icon": GoIconSet.POTION, "title": "Health potion",
        "subtitle": "Heals 50 HP · 12 left"}, false)
    GoPopover.open(slot, card, {"width": 280}))

Une surface ANCHOR dont le calque, l'ancre et la libération sont déjà câblés — les dix lignes que chaque jeu réécrit encore et encore. Une seule à la fois : en ouvrir une seconde ferme la première, parce que des cartes empilées enterrent l'écran et plus personne ne sait laquelle appartient à quel emplacement. Le voile est transparent — une carte ouverte pour comparer un équipement ne doit pas assombrir cet équipement — mais il attrape quand même le premier appui extérieur, qui ferme la carte et ne va pas plus loin.

OptionPar défautCe qu'elle fait
title""Un en-tête avec ×. Vide : pas d'en-tête.
width · max_height320 · 520La taille de la carte.
dismissabletrueUn appui extérieur la ferme.
compact · alpha · translatefalse · -1 · falseEspacement dense, opacité de la face, titre comme clé de traduction.

GoPopover.close() et GoPopover.is_open() sont statiques. open() renvoie la surface — ou null quand l'ancre n'est pas dans l'arbre : vérifiez avant de faire await shown.close_requested.

Ce n'est pas une infobulle au survol. Le tactile n'a pas de survol ; tout ce que seule une souris peut révéler est invisible pour la moitié de vos joueurs. Et avec dismissable = false et sans titre, rien à l'écran ne la ferme — seulement Échap, Retour ou votre propre appel.

GoContextMenu — appui long et clic droit

var menu := [
    {"text": "Use", "icon": GoIconSet.POTION, "action": use},
    {"separator": true},
    {"text": "Drop", "icon": GoIconSet.TRASH, "action": drop, "danger": true}]
GoContextMenu.attach(slot, menu)

var more := GoStyle.icon_button(GoIconSet.MORE, Callable(), -1, &"more")
more.pressed.connect(func() -> void: GoContextMenu.open_at(more, menu))
  • Un clic droit l'ouvre aussitôt. Un doigt maintenu une demi-seconde (HOLD_SECONDS) l'ouvre ; bouger de plus de 12dp annule — faire défiler une liste ne fait donc jamais surgir de menu.
  • Une entrée est {text, action, icon, disabled, checked, separator, danger, translate}. Passez un Callable au lieu du tableau quand les entrées dépendent de ce sur quoi on a appuyé ; il est appelé à chaque ouverture du menu.
  • danger place « ⚠ » devant le texte — le menu du moteur ne sait colorer que toutes ses entrées à la fois.
  • C'est le PopupMenu du moteur, habillé par GoStyle.style_popup(). Il ne compte pas comme une surface ouverte.
Un appui long a besoin d'une seconde porte d'entrée. Personne ne découvre un geste caché. Accompagnez-le d'un bouton ⋯ visible (open_at(), comme ci-dessus), ou enseignez-le une fois avec un repère guidé.

Listes déroulantes, sélecteurs et bouton divisé

var sort := GoStyle.dropdown("Sort", ["Highest score", "Most wins", {"text": "Friends only", "disabled": true}],
    func(index: int) -> void: sort_board(index))
var quality := GoStyle.select(["Low", "Medium", "High", "Ultra"], "Quality")
quality.item_selected.connect(func(index: int) -> void: settings.quality = index)
var send := GoSplitButton.make("Send", send_now, ["Send later", "Save as draft"])

Les trois ouvrent le menu contextuel du moteur : dropdown() est un MenuButton qui lance une action, select() un OptionButton qui garde une valeur, GoSplitButton une action principale avec un menu sur sa flèche (chosen(index)). Les menus restent entièrement opaques exprès — un menu affiché dans sa propre fenêtre du système rend noirs les pixels translucides.

GoCombobox — une liste avec recherche

var friend := GoCombobox.make(friend_names, -1, "Find a friend")
friend.picked.connect(func(index: int) -> void: invite(friend_names[index]))

Une fois pressé, il ouvre une liste ancrée sur le calque 96 avec un voile transparent. À partir de search_threshold (8) entrées, un champ de recherche apparaît et prend le focus ; il trouve une correspondance n'importe où dans le texte ou l'indication, sans tenir compte de la casse, et un résultat vide le signale. list_width (0 = la largeur du bouton, au moins 180dp) dimensionne la liste.

Des pop-ups qui n'arrêtent jamais le jeu

Des nouvelles que le joueur peut lire en jouant. Aucun n'a de voile ; un appui n'importe où ailleurs que sur la carte elle-même va au jeu.

GoSnackbar — un message avec Annuler

var snack := GoSnackbar.new()
add_child(snack)

if await snack.post({"text": "Dropped {name}", "args": {"name": item.name}, "icon": GoIconSet.TRASH,
        "actions": ["Undo"], "seconds": 5.0}) == 0:
    restore(item)
Clé de post()Ce qu'elle fait
text · title · args · translateLe message, une ligne en gras facultative, des {placeholders}, des clés de traduction.
tone · iconLa couleur d'accent (GoTheme.SUCCESS, WARNING…) et une icône.
actions · closableDes boutons — des String ou {text, action} — et un ×.
secondsCombien de temps il reste affiché. Négatif : le notice_duration_ms du thème. 0 : jusqu'à ce qu'on le ferme — donnez-lui alors un bouton.

post() renvoie l'indice du bouton pressé, ou -1 quand le délai a expiré ou que le message a été fermé. Les messages se mettent en file (queue_limit 4, le plus ancien abandonné avec -1), et le même texte publié de nouveau pendant qu'il s'affiche ne fait que relancer son minuteur. Il se place en bas (ou en haut, placement), au-dessus de la zone sûre et du clavier, sur le calque 90 — lisible par-dessus un tiroir. Avec tap_to_dismiss (activé), un appui sur une carte sans boutons la ferme ; un appui hors de la carte atteint toujours le jeu. show_text() et show_key() sont les formes en une ligne.

Ne posez jamais de question dans un snackbar. Il disparaît tout seul ; un choix qui compte a sa place dans une boîte de dialogue.

GoNotice — une ligne sur le HUD

var notice := GoNotice.new()
hud_corner.add_child(notice)
notice.show_text("Game saved", GoTheme.SUCCESS)
notice.custom_minimum_size.x = notice.preferred_width(340)

Un simple panneau que vous placez vous-même — dans un GoHudAnchor, dans un coin, n'importe où. Il ne prend ni la saisie ni le focus : appuyer à travers lui atteint le bouton en dessous, et un nouveau message remplace l'ancien. Donnez-lui une largeur : preferred_width(limit) renvoie la largeur naturelle d'un texte court et fait passer à la ligne un texte long dans limit. set_content() affiche n'importe quelle commande à la place du texte.

GoBanner et infobulles

GoBanner.make("You're offline.", [{"text": "Retry", "action": reconnect}], GoIconSet.WARNING) se place dans la page elle-même, au-dessus du contenu, et n'expire jamais ; un bouton le ferme, sauf s'il a "keep": true. Calques, Retour et saisie

Trois règles décident de ce que le joueur peut toucher pendant que quelque chose est ouvert : ce qui est au-dessus, à qui appartient Retour, et qui reçoit un appui.

L'ordre est voulu : un snackbar rapporte ce qui vient de se passer, il se lit donc par-dessus un tiroir ; une carte épinglée appartient à ce qui vient d'être pressé, elle se place donc au-dessus ; une boîte de dialogue pose une question et couvre les deux ; la console couvre tout, parce que c'est ce que vous ouvrez quand tout le reste a mal tourné.

À qui appartient Retour

  • Seule la fenêtre du dessus répond. Parmi les surfaces ouvertes, celle du calque le plus haut (puis la dernière dans l'arbre) reçoit Échap, l'annulation de la manette (ui_cancel), le Retour Android et les appuis sur le voile. Des fenêtres empilées se ferment une à la fois, jamais ensemble.
  • Le Retour Android est traité une image plus tard, si bien qu'un seul appui ne peut jamais fermer deux fenêtres.
  • Tant qu'un élément qui possède Retour est ouvert, le Retour Android ne quitte pas l'application (GoBackPolicy compte les propriétaires et restaure quit_on_go_back après le dernier). Votre propre pop-up qui prend Retour doit appeler GoBackPolicy.acquire() et release() — dans _exit_tree aussi.
  • Un tiroir, une visite guidée et un formulaire s'effacent tant qu'une surface est ouverte — Retour va d'abord à la surface.
  • GoConfig.close_on_back (activé) est l'interrupteur des surfaces.

Qui reçoit un appui

  • Une surface couvre tout l'écran et arrête la saisie — un voile transparent aussi. Rien sur un calque inférieur ne peut être pressé tant qu'elle est ouverte ; les calques au-dessus (un snackbar) le peuvent toujours.
  • La molette de la souris et le pincement s'arrêtent aussi à la fenêtre : faire défiler au-delà de la fin d'une liste ne fait jamais défiler le jeu.
  • La saisie de jeu qui ne passe pas par des commandes — _unhandled_input pour le déplacement, un glissement de caméra — doit se mettre en pause : if GoSurface.is_any_open(): return. Cela couvre les boîtes de dialogue, les feuilles, les cartes épinglées et le combobox ; demandez is_open() séparément à un tiroir.
  • Le snackbar, l'avis, la carte d'invite et le repère guidé ne prennent la saisie que sur leur propre carte ; partout ailleurs, c'est le jeu qui la reçoit.

Focus

Une fenêtre ouverte par un pointeur ne donne le focus à rien — aucun anneau ne clignote pour un toucher. Ouverte depuis un clavier ou une manette, c'est le bouton de fermeture (ou initial_focus) qui prend le focus. Le focus reste dans la fenêtre tant qu'elle est ouverte et revient à la commande qui l'avait quand elle se ferme. Les boîtes de dialogue donnent le focus à OK à chaque fois.

Mettre le jeu en pause

Mettre l'arbre en pause met aussi les pop-ups en pause — seule la console continue de fonctionner. Pour un menu de pause, donnez à son calque process_mode = PROCESS_MODE_ALWAYS ; la fenêtre, ses boutons et Retour continuent alors de tourner pendant que le jeu est arrêté.

Quelle transparence

Chaque type de pop-up suit sa propre opacité, si bien qu'une carte du HUD peut rester légère pendant qu'une boîte de dialogue reste pleine : les fenêtres, les feuilles, les boîtes de dialogue, les cartes épinglées et le combobox suivent panel_alpha ; le tiroir et la carte de visite guidée card_alpha ; les cartes d'invite et la console hud_alpha ; les snackbars et les avis notice_alpha ; les menus popup_alpha. Material et enfants les rendent tous opaques ; la bande dessinée aussi, sauf les cartes d'invite et la console, à 92 %. Redéfinissez un type avec GoConfig.container_alpha_overrides, tous avec container_alpha (un ratio — 0.95), ou une seule fenêtre avec son alpha. Pièges

  • Un GoSurface ne se libère jamais lui-même. Connectez close_requested, sinon × ne fait rien.
  • Les options réglées après add_child — scrim_transparent, show_header, resizable, scroll_body, ainsi que layer_index et max_width de GoDialogs — ne sont pas appliquées.
  • Un second confirm() renvoie false immédiatement. Activez queue_when_busy si deux questions peuvent se croiser.
  • Entrée confirme. OK a le focus, y compris dans les boîtes de dialogue destructives.
  • Retour sur une feuille ferme la feuille, pas la sous-page.
  • Échap ne ferme pas un tiroir, et is_any_open() ne le voit pas.
  • Une carte épinglée ou une liste de combobox bloque le jeu jusqu'à sa fermeture, même avec un voile transparent — et une carte épinglée avec dismissable = false et sans titre n'a rien à l'écran qui la ferme.
  • Une carte d'invite démarre masquée et n'expire jamais.
  • Un snackbar avec seconds: 0 et sans bouton ne part jamais. Et par défaut, il attrape les appuis sur sa carte.
  • Un appui long que personne ne connaît est une fonction que personne n'utilise. Affichez aussi un ⋯.
  • Un arbre en pause met votre pop-up en pause. Utilisez PROCESS_MODE_ALWAYS sur son calque.
  • Un avis sans largeur se réduit à sa largeur minimale — utilisez preferred_width().
  • Ne demandez jamais dans un snackbar, n'informez jamais dans une boîte de dialogue. Une question ignorée disparaît ; une nouvelle ne doit pas arrêter le jeu.
