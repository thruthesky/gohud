Une UI de jeu pilotée par une seule ressource

gohud est un kit HUD et UI pour Godot 4.6 et versions ultérieures. Fenêtres flottantes, feuilles inférieures, boîtes de dialogue, formulaires, snackbars, repères guidés, barres de HUD, emplacements rapides et joystick virtuel fonctionnent à partir d'un seul thème et d'un seul jeu d'icônes interchangeable, et prennent en charge pour vous la zone sûre, le clavier virtuel, le sens RTL et les cibles tactiles. Six préréglages — par défaut, science-fiction et médiéval, chacun en sombre et en clair — changent les couleurs et les formes en une ligne.

Ce que ça donne dans un jeu

Les préréglages médiéval et science-fiction — fiches de personnage, inventaires et quêtes ; formulaires, grilles et cartes d'invite ; panneaux anguleux et commandes tactiles. Changer de préréglage tient en une ligne de code.

Ce qu'il vous enlève des mains

Ce qui coûte le plus de temps dans une UI de jeu, ce n'est pas la forme d'un bouton — c'est tout ce qui diverge d'un appareil à l'autre. gohud traite cette dérive en un seul endroit.

Chaque mesure est un token

Les espacements, les coins et les tailles de texte sont appelés par leur nom, pas écrits en chiffres. Changez de thème et tout l'écran suit.

Taille visible ≠ taille pressable

Un bouton de fermeture paraît faire 36 dp alors que sa cible tactile en fait 48. Là où des emplacements serrés se chevauchent, c'est celui dont le centre est le plus proche qui reçoit l'appui.

Encoches et claviers

Les éléments du HUD restent dans la zone sûre, et un champ de saisie remonte au-dessus du clavier virtuel quand celui-ci apparaît.

Retour ne ferme qu'une chose

Échap et le bouton Retour d'Android ne ferment que la surface la plus haute. Des fenêtres empilées ne disparaissent pas d'un seul coup.

Les snackbars ne captent jamais la saisie

Appuyez à travers un snackbar et c'est le bouton en dessous qui reçoit l'appui. Le focus n'est pas pris non plus.

Les icônes se demandent par leur nom

Les widgets ne connaissent que GoIconSet.CLOSE. Changez de jeu et tous les dessins changent sans toucher une ligne de code.

Six apparences, une ligne

GoUi.use_preset() change d'un coup le thème, le skin et les icônes — cadres arrondis, chanfreinés science-fiction ou forgés médiévaux.

Lisibilité mesurée

Chaque thème est vérifié au regard des WCAG, y compris les états des boutons et les panneaux de HUD translucides sur blanc pur et noir pur.

Tout fonctionne sans activer le plugin. L'activer ajoute un autoload GoRuntime qui suit la taille de la fenêtre, l'échelle dp et la hauteur du clavier, ainsi que des paramètres de projet pour la ressource de configuration et le préréglage — des commodités, pas des obligations.

Installation

Déposez le dossier de l'add-on dans votre projet. Il n'y a rien d'autre à configurer.

Depuis l'Asset Store ou un ZIP de version

Décompressez à la racine de votre projet pour obtenir res://addons/gohud/. C'est tout. Vous pouvez éventuellement activer Projet → Paramètres du projet → Extensions → gohud.

En sous-module git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # facultatif : fixer un tag ou un commit

La racine du dépôt est le dossier de l'add-on : il atterrit donc exactement là où Godot l'attend. Modifiez-le sur place, committez et poussez depuis addons/gohud, puis committez le pointeur de sous-module dans votre jeu.

Godot 4.6 ou plus récent est requis. gohud utilise des API introduites en 4.5 (DPITexture, FoldableContainer, propriétés d'accessibilité) : sur une version antérieure, l'analyse des scripts échoue. 4.6 est le plancher pris en charge, consigné dans GoUi.MIN_ENGINE.

Démarrage rapide

Chaque widget se crée avec .new() puis add_child() — aucun fichier de scène, aucun autoload.

Choisissez une apparence avant de construire l'UI (facultatif)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # default_dark est utilisé si vous sautez cette étape

Une confirmation que vous await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Supprimer la sauvegarde", "Cette action est irréversible."):
    delete_save()

Passez destructive = true (le dernier argument) et le bouton de confirmation est dessiné comme un bouton de danger plein.

Une feuille inférieure avec champ de recherche et pied de page fixes

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventaire")
sheet.toolbar().add_child(GoStyle.line_edit("Rechercher…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Fermer", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Pourquoi les rangées fixes sont séparées du corps défilant. Placez Confirmer et Annuler dans body et une longue liste les pousse hors de l'écran. footer() reste toujours visible.

Un coin de HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "PV"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Un contenu qui reste à l'écart du HUD

form.avoid_hud = true                  # reste à l'écart de chaque GoHudAnchor visible
joystick_anchor.reserve_space = false  # …sauf ceux qui n'apparaissent que sous un doigt
notice_anchor.avoid_peers = true       # un toast se pose sous le HUD fixe au lieu de le recouvrir

Chaque rectangle est contourné dans la direction qui coûte le moins de surface — vers le bas sur un téléphone en portrait, sur le côté en paysage. Comment le HUD s'évite lui-même →

Changer l'apparence — les couleurs et les formes

Un Theme ne peut restyler que ce que le moteur dessine. Les coins arrondis sont les seuls coins dont dispose StyleBoxFlat, et le joystick, les emplacements rapides et le repère guidé sont dessinés par du code — un thème seul ne peut donc jamais changer leur forme. gohud livre pour cela des préréglages : un thème, un skin et un jeu d'icônes choisis d'un seul tenant.

Collection médiévale

medieval_dark associe le fer et le cuir à l'or ancien ; medieval_light emploie le parchemin et l'encre. Les cadres de menu portent un rivet et un petit ornement d'angle tandis que le HUD, toujours visible, reste discret ; 16 icônes gravées redessinent les noms d'objets, et seuls les titres et sous-titres utilisent la police Cinzel fournie.

Le même écran sur téléphone et sur ordinateur

Les captures de la galerie sont prises sur un téléphone en portrait. Ci-dessous, le même code en 1280×800 — le contenu s'arrête à une largeur lisible (480 dp) et se centre, tandis que le HUD reste dans les coins. Le formulaire contourne les éléments de HUD flottants, mais ne bouge pas lorsqu'il en est déjà à l'écart : le décaler quand même décentrerait le contenu sur un écran large.

La même feuille, une autre apparence

Choisissez-en un dans Paramètres du projet → gohud → Theme → Preset, ou renseignez GoConfig.preset. Remplir explicitement theme, skin ou icons l'emporte sur le préréglage : vous pouvez donc partir d'un préréglage et n'en redéfinir qu'un seul.

Un nouveau thème tient dans un fichier JSON. new_theme.py kingdom --from medieval_dark écrit une palette qui détaille chaque valeur héritée ; make_theme.py kingdom construit le thème, ses illustrations de contrôles et les molettes de son skin, et le préréglage apparaît dans le sélecteur. Les skins — là où un Theme n'atteint pas

Un skin possède le joystick, la face des emplacements rapides, l'anneau du repère guidé, les puces, les squelettes de chargement, les alertes, les séparateurs et les en-têtes de section. Dérivez-le et ne redéfinissez que ce que vous voulez changer. 

class_name MySkin extends GoSkin

func slot_box(accent: Color, lit: bool) -> StyleBox:
    var box := GoStyleBoxCut.new()
    box.bg_color = accent
    box.cut = 6.0
    box.edge_color = accent
    return box
ClasseFormes qu'elle peut produire
GoStyleBoxCutCoins coupés en diagonale (chanfrein), une arête d'accent épaissie, un halo extérieur
GoStyleBoxBracketDes marques d'angle seules, sans enfermer le contenu
GoStyleBoxMedievalUn cadre forgé avec rivets, gravure d'angle, un reflet biseauté et le grain du matériau

Les trois se sérialisent dans une ressource Theme — c'est ce qui permet à un thème de changer la forme, et pas seulement la couleur. GoSkinSciFi et GoSkinMedieval sont les sous-classes fournies.

GoStyle.box() renvoie toujours un StyleBoxFlat, parce que le code appelant le reçoit et ajuste bg_color ou corner_radius. Utilisez GoStyle.surface() lorsqu'une forme personnalisée doit survivre.

Des exemples que vous pouvez exécuter

Trois façons de voir gohud avant d'écrire une ligne — aucune ne demande de serveur ni d'autoload.

Galerieexamples/gallery/gallery.tscn · F6Tous les widgets, un sélecteur pour chaque préréglage installé, et le jeu d'icônes complet

Application de démocd examples/demo && godotUn écran d'accueil qui ouvre la galerie, la visite guidée en 15 chapitres, l'écran de présentation et le style médiéval, avec des widgets vivants et une carte par classe

bash examples/demo/run.sh                               # la même application, depuis la racine de l'add-on
bash examples/demo/run.sh -- --open=gallery             # saute l'écran d'accueil

bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # enregistrement de la visite en 1080p / 60 ips

L'application de démo ne demande aucune configuration : si le lien vers l'add-on ou le cache d'import manque, elle le signale, répare le dossier et se rouvre. Son écran d'accueil ouvre chaque exemple dans la même fenêtre — appuyez sur 1–4 ou cliquez sur une rangée, et la barre du haut vous y ramène.

Dans la visite, C active le mode cinéma, F11 le plein écran, Espace met en pause (ou joue le widget courant en mode exploration), les flèches changent de chapitre et Échap ramène à l'écran de départ.

Ouvrez-le depuis votre agent de codage IA

gohud fournit un plugin Claude Code avec des commandes slash. Tapez-en une et la galerie ou la démo s'ouvre dans sa propre fenêtre Godot — aucun éditeur à lancer, aucune scène à chercher.

Installez les commandes une fois pour toutes

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud
# puis redémarrez Claude Code

D'autres agents comme Codex peuvent utiliser la même skill : copiez skills/gohud depuis ce dépôt dans le dossier de skills de l'agent.

/gohud:preview — la galerie des widgets

Ouvre la galerie : tous les widgets, un sélecteur pour les six préréglages et le jeu d'icônes complet. Tapez-la à l'intérieur de votre projet Godot et elle utilise votre addons/gohud ; en dehors, elle utilise la copie fournie avec le plugin, ou un clone tout neuf. Elle s'exécute dans un projet bac à sable jetable : vos autoloads et votre cache d'import restent intacts, et la fenêtre reste ouverte jusqu'à ce que vous la fermiez.

/gohud:preview demo — la visite guidée en 15 chapitres

Ouvre la démo sur son écran de départ. Démarrer la démo joue la visite avec de vraies entrées ; Explorer les widgets vous laisse essayer un widget à la main. Les touches listées dans Exemples fonctionnent ici aussi.

La lisibilité se mesure, elle ne s'estime pas à l'œil

« Joli » relève du goût ; « lisible » se mesure. Un gris pâle paraît très bien sur un bon écran et disparaît sur un téléphone en plein jour — choisir à l'œil finit toujours par y mener. 

python3 addons/gohud/tools/check_contrast.py

Chaque paire de couleurs et le libellé de chaque état de bouton sur le panneau qui le porte sont mesurés au regard des WCAG, dans les six thèmes. Les couleurs translucides sont d'abord composées sur leur fond réel — les mesurer directement annonce un meilleur rapport que ce que l'écran montre.

Les couleurs de texte sont donc dérivées, pas choisies : le générateur part de l'entrée de la palette et pousse sa clarté jusqu'à ce qu'elle franchisse le seuil sur chaque surface où elle peut se poser. Changez la palette et le contraste suit. Les règles et les pièges qui les motivent →

Vérifications, versions et ce site

Un seul point d'entrée lance toutes les vérifications ; chaque partie voit ce que les autres ne voient pas.

bash addons/gohud/tools/check_all.sh

new_project_check.shLes dépendances cachées envers un projet hôte ; avec --zip la version telle qu'elle est livrée, avec --export une build Web

check_site.pyLes liens, les ancres, la langue des pages, le glossaire et les tableaux de molettes de ce site
Dernière exécution consignée — 2026-09-13, Godot 4.7.2, macOS, moteur de rendu Compatibility. 438 vérifications sur 438 en 390×844, 844×390, 768×1024 et 1280×800 dans un projet vide ; 438 sur 438 à nouveau avec l'autoload GoRuntime ; un export Web ; zéro échec de contraste sur les six thèmes. Godot 4.6 et les appareils Android ou iOS physiques ne faisaient pas partie de cette exécution.

Publier des versions

bash addons/gohud/tools/package.sh                           # 1.0.1 → 1.0.2 · builds/1.0.2/gohud-1.0.2.zip
bash addons/gohud/tools/package.sh --increase-minor-version  # 1.0.1 → 1.1.0

Une exécution réussie met à jour plugin.cfg, GoUi.VERSION et CHANGELOG.md ensemble, en déplaçant les notes Unreleased dans une entrée datée. Une exécution qui échoue ne change rien, et un ZIP existant n'est jamais écrasé. Le ZIP laisse de côté ce site, les tests et les outils.
