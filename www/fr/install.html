Installer gohud

Deux chemins. Laissez votre agent IA le faire, ou déposez le dossier dans votre projet — il n'y a rien d'autre à configurer.

Le chemin le plus rapide : laissez votre agent IA installer

Un bloc de texte collé dans Claude Code, Codex, Cursor ou Gemini CLI installe la compétence et l'extension, puis vous explique gohud. Sur cette voie, rien de ce qui suit cette carte n'est nécessaire.

Installation

Déposez le dossier de l'add-on dans votre projet. Il n'y a rien d'autre à configurer.

Depuis l'Asset Store ou un ZIP de version

Décompressez à la racine de votre projet pour obtenir res://addons/gohud/. C'est tout. Vous pouvez éventuellement activer Projet → Paramètres du projet → Extensions → gohud.

En sous-module git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # facultatif : fixer un tag ou un commit

La racine du dépôt est le dossier de l'add-on : il atterrit donc exactement là où Godot l'attend. Modifiez-le sur place, committez et poussez depuis addons/gohud, puis committez le pointeur de sous-module dans votre jeu.

Godot 4.6 ou plus récent est requis. gohud utilise des API introduites en 4.5 (DPITexture, FoldableContainer, propriétés d'accessibilité) : sur une version antérieure, l'analyse des scripts échoue. 4.6 est le plancher pris en charge, consigné dans GoUi.MIN_ENGINE.

Démarrage rapide

Chaque widget se crée avec .new() puis add_child() — aucun fichier de scène, aucun autoload.

Choisissez une apparence avant de construire l'UI (facultatif)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # default_dark est utilisé si vous sautez cette étape

Une confirmation que vous await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Supprimer la sauvegarde", "Cette action est irréversible."):
    delete_save()

Passez destructive = true (le dernier argument) et le bouton de confirmation est dessiné comme un bouton de danger plein.

Une feuille inférieure avec champ de recherche et pied de page fixes

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventaire")
sheet.toolbar().add_child(GoStyle.line_edit("Rechercher…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Fermer", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Pourquoi les rangées fixes sont séparées du corps défilant. Placez Confirmer et Annuler dans body et une longue liste les pousse hors de l'écran. footer() reste toujours visible.

Un coin de HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "PV"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Un contenu qui reste à l'écart du HUD

form.avoid_hud = true                  # reste à l'écart de chaque GoHudAnchor visible
joystick_anchor.reserve_space = false  # …sauf ceux qui n'apparaissent que sous un doigt
notice_anchor.avoid_peers = true       # un toast se pose sous le HUD fixe au lieu de le recouvrir

Chaque rectangle est contourné dans la direction qui coûte le moins de surface — vers le bas sur un téléphone en portrait, sur le côté en paysage. Comment le HUD s'évite lui-même →

Des exemples que vous pouvez exécuter

Trois façons de voir gohud avant d'écrire une ligne — aucune ne demande de serveur ni d'autoload.

ExempleComment l'ouvrirCe qu'il montre
Galerieexamples/gallery/gallery.tscn · F6Tous les widgets, un sélecteur pour chaque préréglage installé, et le jeu d'icônes complet
Médiévalexamples/medieval/medieval.tscn · F6Une fiche de personnage, une besace et un journal de quêtes ; des boutons basculent entre fer et parchemin et ouvrent le détail des objets
Application de démocd examples/demo && godotUn écran d'accueil qui ouvre la galerie, la visite guidée en 15 chapitres, l'écran de présentation et le style médiéval, avec des widgets vivants et une carte par classe
 
cd examples/demo && godot                             # écran d'accueil ; liens et imports au premier lancement
bash examples/demo/run.sh                               # la même application, depuis la racine de l'add-on
bash examples/demo/run.sh -- --open=gallery             # saute l'écran d'accueil
bash examples/demo/run.sh -- --explore=surfaces         # ouvre directement sur un chapitre de la visite
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # enregistrement de la visite en 1080p / 60 ips

L'application de démo ne demande aucune configuration : si le lien vers l'add-on ou le cache d'import manque, elle le signale, répare le dossier et se rouvre. Son écran d'accueil ouvre chaque exemple dans la même fenêtre — appuyez sur 1–4 ou cliquez sur une rangée, et la barre du haut vous y ramène.

Dans la visite, C active le mode cinéma, F11 le plein écran, Espace met en pause (ou joue le widget courant en mode exploration), les flèches changent de chapitre et Échap ramène à l'écran de départ.
