La via più rapida: lascia installare al tuo agente IA

Installazione

Metti la cartella dell'add-on dentro il tuo progetto. Non c'è altro da configurare.

Dall'Asset Store o da uno ZIP di release

Estrai nella radice del progetto in modo da ottenere res://addons/gohud/. Tutto qui. Facoltativamente abilita Project → Project Settings → Plugins → gohud.

Come sottomodulo git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # facoltativo: fissa un tag o un commit

La radice del repository è la cartella dell'add-on, quindi finisce esattamente dove Godot se l'aspetta. Modifica sul posto, fai commit e push dentro addons/gohud, poi committa il puntatore del sottomodulo nel tuo gioco.

Serve Godot 4.6 o più recente. gohud usa API introdotte nella 4.5 (DPITexture, FoldableContainer, proprietà di accessibilità), quindi su qualsiasi versione precedente fallisce già in fase di parsing. La 4.6 è la soglia supportata, registrata in GoUi.MIN_ENGINE.

Avvio rapido

Ogni widget è .new() e add_child() — niente file di scena, niente autoload.

Scegli un aspetto prima di costruire la UI (facoltativo)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # se salti questo passo si usa default_dark

Una conferma che puoi mettere in await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Elimina salvataggio", "L'operazione non è reversibile."):
    delete_save()

Passa destructive = true (l'ultimo argomento) e il pulsante di conferma viene disegnato come pulsante di pericolo pieno.

Un foglio inferiore con campo di ricerca e piè di pagina fissi

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventario")
sheet.toolbar().add_child(GoStyle.line_edit("Cerca…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Chiudi", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Perché le righe fisse sono separate dal corpo scorrevole. Metti conferma e annulla dentro body e una lista lunga li spinge fuori dallo schermo. footer() è sempre visibile.

Un angolo di HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Contenuto che si tiene alla larga dall'HUD

form.avoid_hud = true                  # sta lontano da ogni GoHudAnchor visibile
joystick_anchor.reserve_space = false  # …tranne quelli che compaiono solo sotto un dito
notice_anchor.avoid_peers = true       # un avviso si posa sotto l'HUD fisso invece di coprirlo

Ogni rettangolo viene evitato nella direzione che costa meno area — verso il basso su un telefono in verticale, di lato in orizzontale. Come l'HUD evita sé stesso →

Esempi che puoi eseguire

Tre modi per vedere gohud prima di scrivere una riga — nessuno richiede un server o un autoload.

EsempioCome aprirloChe cosa mostra
Galleriaexamples/gallery/gallery.tscn · F6Ogni widget, un selettore per ogni preset installato e il set completo di icone
Medievaleexamples/medieval/medieval.tscn · F6Una scheda personaggio, una bisaccia e un diario delle missioni; i pulsanti alternano ferro e pergamena e aprono il dettaglio degli oggetti
App democd examples/demo && godotUna schermata iniziale che apre la galleria, il tour guidato di 15 capitoli, la schermata vetrina e l'aspetto medievale, con widget dal vivo e una scheda per ogni classe
 
cd examples/demo && godot                             # schermata iniziale; collegamenti e importazioni al primo avvio
bash examples/demo/run.sh                               # la stessa app, dalla radice dell'add-on
bash examples/demo/run.sh -- --open=gallery             # salta la schermata iniziale
bash examples/demo/run.sh -- --explore=surfaces         # apri direttamente su un capitolo del tour
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # registrazione del tour a 1080p / 60 fps

L'app demo non richiede alcuna configurazione: se manca il collegamento all'add-on o la cache di importazione lo segnala, ripara la cartella e si riapre da sola. La sua schermata iniziale apre ogni esempio dentro la stessa finestra — premi 1–4 oppure fai clic su una riga, e la barra in alto ti riporta indietro.

Nel tour, C attiva la modalità Cinema, F11 lo schermo intero, Spazio mette in pausa (o riproduce il widget corrente mentre esplori), le frecce cambiano capitolo e Esc torna alla schermata iniziale.
