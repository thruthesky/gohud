Najszybsza droga — niech zainstaluje to agent AI

Jeden blok tekstu wklejony do Claude Code, Codex, Cursora lub Gemini CLI instaluje i umiejętność, i dodatek, a potem objaśnia ci gohud. Na tej drodze nic poniżej tej karty nie jest potrzebne.

Instalacja

Wrzuć folder dodatku do swojego projektu. Nie ma nic więcej do ustawienia.

Z Asset Store albo z ZIP-a wydania

Rozpakuj do katalogu głównego projektu, tak aby powstało res://addons/gohud/. To wszystko. Opcjonalnie włącz Projekt → Ustawienia projektu → Wtyczki → gohud.

Jako submoduł git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # opcjonalnie: przypnij tag albo commit

Katalog główny repozytorium jest folderem dodatku, więc ląduje dokładnie tam, gdzie Godot się go spodziewa. Edytuj na miejscu, commituj i wypychaj wewnątrz addons/gohud, a potem zacommituj wskaźnik submodułu w swojej grze.

Wymagany jest Godot 4.6 lub nowszy. gohud korzysta z API wprowadzonych w 4.5 (DPITexture, FoldableContainer, właściwości dostępności), więc na czymkolwiek starszym nie przechodzi nawet parsowania. 4.6 to wspierane minimum, zapisane w GoUi.MIN_ENGINE.

Szybki start

Każdy widżet to .new() i add_child() — bez plików scen, bez autoloadu.

Wybierz wygląd, zanim zbudujesz UI (opcjonalnie)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # gdy to pominiesz, użyty zostanie default_dark

Potwierdzenie, na które czekasz przez await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Usuń zapis", "Tego nie da się cofnąć."):
    delete_save()

Przekaż destructive = true (ostatni argument), a przycisk potwierdzenia zostanie narysowany jako wypełniony przycisk niebezpieczeństwa.

Dolny arkusz z przyklejonym polem wyszukiwania i stopką

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Ekwipunek")
sheet.toolbar().add_child(GoStyle.line_edit("Szukaj…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Zamknij", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Dlaczego przyklejone wiersze są oddzielone od przewijanego ciała. Wsadź potwierdzenie i anulowanie do body, a długa lista wypchnie je poza ekran. footer() jest widoczna zawsze.

Narożnik HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Treść, która omija HUD

form.avoid_hud = true                  # omijaj każdy widoczny GoHudAnchor
joystick_anchor.reserve_space = false  # …poza tymi, które pojawiają się dopiero pod palcem
notice_anchor.avoid_peers = true       # powiadomienie osiada pod stałym HUD, zamiast go zasłaniać

Każdy prostokąt omijany jest w tym kierunku, który kosztuje najmniej powierzchni — w dół na telefonie w pionie, na bok w poziomie. Jak HUD omija sam siebie →

Przykłady, które możesz uruchomić

Trzy sposoby, by zobaczyć gohud przed napisaniem linijki — żaden nie potrzebuje serwera ani autoloadu.

PrzykładJak otworzyćCo pokazuje
Galeriaexamples/gallery/gallery.tscn · F6Każdy widżet, selektor każdego zainstalowanego presetu i pełny zestaw ikon
Średniowieczeexamples/medieval/medieval.tscn · F6Karta postaci, sakwa i dziennik zadań; przyciski przełączają żelazo i pergamin oraz otwierają szczegóły przedmiotu
Aplikacja democd examples/demo && godotEkran główny otwierający galerię, 15-rozdziałowy przewodnik, ekran pokazowy i wygląd średniowieczny, z żywymi widżetami i jedną kartą na klasę
 
cd examples/demo && godot                             # ekran główny; dowiązania i import przy pierwszym uruchomieniu
bash examples/demo/run.sh                               # ta sama aplikacja, z katalogu głównego dodatku
bash examples/demo/run.sh -- --open=gallery             # pomiń ekran główny
bash examples/demo/run.sh -- --explore=surfaces         # otwórz od razu na jednym rozdziale przewodnika
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # nagranie przewodnika w 1080p / 60 kl./s

Aplikacja demo nie potrzebuje żadnej konfiguracji: jeśli brakuje dowiązania do dodatku albo pamięci podręcznej importu, mówi o tym, naprawia folder i otwiera się ponownie. Jej ekran główny otwiera każdy przykład wewnątrz tego samego okna — naciśnij 1–4 albo kliknij wiersz, a pasek u góry zabierze cię z powrotem.

W przewodniku C przełącza tryb kinowy, F11 pełny ekran, Spacja pauzuje (albo odtwarza bieżący widżet w trybie eksploracji), strzałki zmieniają rozdziały, a Escape wraca na ekran startowy.
