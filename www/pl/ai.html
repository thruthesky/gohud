AI SKILL

gohud zawiera umiejętność AI: całe API, gotowe do uruchomienia szablony i podgląd. Wklej jeden blok do swojego agenta — zainstaluje gohud i będzie wiedział, jak go używać.

Zobacz blok Instalacja

Wklej to do swojego agenta kodu

Otwórz projekt Godota w agencie, wklej blok i wyślij. Zainstaluje umiejętność i dodatek, a potem opowie, co potrafi gohud.

Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, if addons/gohud/plugin.cfg is missing here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import

3. Restart yourself so the skill loads, then tell me what gohud can do
   and how to preview it.

Docs: https://thruthesky.github.io/gohud/
Blok jest po angielsku celowo — to język, który każdy agent czyta najpewniej. Własne pytania zadawaj w dowolnym języku; umiejętność odpowie w tym, w którym piszesz.

Polecenia, które dostajesz

/gohud:preview — galeria widżetów

Otwiera galerię: każdy widżet, selektor wszystkich sześciu presetów i pełny zestaw ikon. Wpisz to wewnątrz swojego projektu Godota, a użyje twojego addons/gohud; bez niego użyje kopii dołączonej do wtyczki albo świeżego klona. Działa w jednorazowym projekcie-piaskownicy, więc twoje autoloady i pamięć podręczna importu zostają nietknięte, a okno pozostaje otwarte, dopóki go nie zamkniesz.

/gohud:preview demo — 15-rozdziałowy przewodnik

Otwiera demo na ekranie startowym. Start demo odtwarza przewodnik z prawdziwym wejściem; Explore widgets pozwala wypróbować jeden widżet ręcznie. Klawisze wymienione w sekcji Przykłady działają też tutaj.

Albo po prostu poproś

Albo po prostu poproś. Umiejętność uczy agenta całego API gohud, więc zwykłe prośby też działają — „Zbuduj menu pauzy w gohud”. Gdy jest zainstalowana jako zwykła umiejętność w ~/.claude/skills/gohud, polecenia biorą spację: /gohud preview demo, /gohud features. Podglądy potrzebują Godota 4.6 lub nowszego w twoim PATH albo przekazania --godot /path/to/godot.
