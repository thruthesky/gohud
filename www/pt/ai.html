Go HUD Skill

O gohud traz uma skill de IA: toda a API, modelos prontos a correr e um lançador de pré-visualização. Cole um bloco no seu agente e ele instala o gohud e sabe usá-lo.

Copiar o prompt de instalação Instalação

Cole isto no seu agente de código

Abra o seu projeto Godot no agente, cole o bloco e envie. Ele instala a skill e o add-on, e depois diz-lhe o que o gohud consegue fazer.

  1. Abra um terminal na pasta do seu projeto Godot e inicie lá o seu agente de código — por exemplo, claude.
  2. Clique em Copiar no bloco abaixo, cole-o no agente e envie.
  3. Quando terminar, reinicie o agente se ele o pedir e pergunte-lhe: O que o gohud consegue fazer?
Install gohud for this Godot 4.6+ project, then use it for all game UI
(menus, HUD bars, quick slots, dialogs, bottom sheets, forms, themes).

1. Install the gohud AI skill.
   Claude Code - run these two commands in a shell:
     claude plugin marketplace add thruthesky/gohud
     claude plugin install gohud@gohud
   Any other agent (Codex, Cursor, Gemini CLI, ...):
     git clone --depth 1 https://github.com/thruthesky/gohud.git /tmp/gohud
     Copy /tmp/gohud/skills/gohud into whichever of these folders this agent reads:
     ~/.claude/skills/gohud, .claude/skills/gohud, .agents/skills/gohud.

2. Install the add-on itself, unless addons/gohud/plugin.cfg already exists here.
   In a git repository:
     git submodule add https://github.com/thruthesky/gohud.git addons/gohud
   Otherwise copy the clone to addons/gohud without its .git folder.
   Then run: godot --headless --path . --import
   (If godot is not on PATH, ask me where Godot 4.6+ is.)

3. Check the result: addons/gohud/plugin.cfg exists and the import printed
   no "SCRIPT ERROR" or "Parse Error" lines.

4. A new skill loads when the agent starts. Tell me if I have to restart you,
   then tell me what gohud can do and how to preview it.

Docs: https://thruthesky.github.io/gohud/
O bloco está em inglês de propósito — é o que todos os agentes leem com mais fiabilidade. As suas perguntas podem ser em qualquer língua; a skill responde na língua em que escreve.

Ou escreva dois comandos — Claude Code

Isto instala a skill como plugin do Claude Code. Num terminal:

claude plugin marketplace add thruthesky/gohud
claude plugin install gohud@gohud

Já está dentro do Claude Code? Escreva antes isto:

/plugin marketplace add thruthesky/gohud
/plugin install gohud@gohud

Depois reinicie o Claude Code e escreva /gohud:features — se aparecer a lista de funcionalidades do gohud, a skill está instalada. O add-on em si continua a ir para addons/gohud: Instalação →

Os comandos que ganha

/gohud:preview — a galeria de widgets

Abre a galeria: todo widget, um seletor para os seis presets e o conjunto completo de ícones. Digite dentro do seu projeto Godot e ele usa o seu addons/gohud; fora de um projeto, usa a cópia que vem com o plugin ou um clone novo. Roda em um projeto sandbox descartável, então seus autoloads e o cache de importação ficam intactos, e a janela continua aberta até você fechá-la.

/gohud:preview demo — o tour guiado de 15 capítulos

Abre a demo na tela inicial. Iniciar a demo toca o tour com entrada real; Explorar os widgets deixa você testar um widget na mão. As teclas listadas em Exemplos também valem aqui.

Os comandos de pré-visualização precisam do Godot 4.6 ou mais recente no seu PATH.

Ou simplesmente peça

Ou simplesmente peça. A skill ensina ao agente toda a API do gohud, então pedidos em linguagem comum também funcionam — "Monte um menu de pausa com o gohud". Instalada como skill simples em ~/.claude/skills/gohud, os comandos levam um espaço: /gohud preview demo, /gohud features. As pré-visualizações precisam do Godot 4.6 ou mais novo no seu PATH, ou passe --godot /caminho/para/godot.

O gohud é MIT — código e arte, incluindo 84 ícones padrão e 16 ícones medievais. A fonte Cinzel que acompanha o pacote está sob a SIL Open Font License 1.1.
