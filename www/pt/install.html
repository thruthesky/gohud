Instalar o gohud

Dois caminhos. Deixe o seu agente de IA fazer, ou solte a pasta no seu projeto — não há mais nada para configurar.

O caminho mais rápido: deixe o seu agente de IA instalar

Um bloco de texto, colado no Claude Code, Codex, Cursor ou Gemini CLI, instala a skill e o add-on e depois explica-lhe o gohud. Se seguir por aí, nada abaixo deste cartão é preciso.

Instalação

Coloque a pasta do add-on dentro do seu projeto. Não há mais nada para configurar.

Pela Asset Store ou por um ZIP de release

Extraia na raiz do seu projeto para obter res://addons/gohud/. É só isso. Opcionalmente, ative Projeto → Configurações do Projeto → Plugins → gohud.

Como submódulo do git

git submodule add https://github.com/thruthesky/gohud.git addons/gohud
git submodule update --init
git -C addons/gohud checkout v1.0.0   # opcional: fixa uma tag ou um commit

A raiz do repositório é a pasta do add-on, então ela cai exatamente onde o Godot espera. Edite ali mesmo, faça commit e push dentro de addons/gohud e depois registre o ponteiro do submódulo no seu jogo.

É preciso o Godot 4.6 ou mais novo. O gohud usa APIs introduzidas na 4.5 (DPITexture, FoldableContainer, propriedades de acessibilidade), então em qualquer versão anterior ele falha já na análise do script. A 4.6 é o piso suportado, registrado em GoUi.MIN_ENGINE.

Início rápido

Todo widget é .new() e add_child() — sem arquivos de cena, sem autoload.

Escolha um visual antes de montar a UI (opcional)

GoUi.use_preset(GoThemePresets.SCIFI_DARK)   # default_dark é usado quando você pula esta linha

Uma confirmação que você aguarda com await

var dialogs := GoDialogs.new()
add_child(dialogs)
if await dialogs.confirm("Apagar o save", "Isso não pode ser desfeito."):
    delete_save()

Passe destructive = true (o último argumento) e o botão de confirmação é desenhado como um botão de perigo preenchido.

Uma folha inferior com campo de busca e rodapé fixos

var sheet := GoSheet.new()
add_child(sheet)
sheet.open("Inventário")
sheet.toolbar().add_child(GoStyle.line_edit("Buscar…"))
sheet.toolbar().visible = true
for item in items:
    sheet.body.add_child(GoStyle.list_button(GoIconSet.BOX, item.name, _use.bind(item),
        Color.TRANSPARENT, item.description, false))
sheet.footer().add_child(GoStyle.button("Fechar", sheet.close, GoStyle.Tone.PRIMARY))
sheet.footer().visible = true
Por que as linhas fixas ficam separadas do corpo que rola. Coloque confirmar e cancelar no body e uma lista longa os empurra para fora da tela. O footer() está sempre visível.

Um canto de HUD

var corner := GoHudAnchor.new()
corner.spot = GoHudAnchor.Spot.TOP_LEFT
corner.landscape_spot = GoHudAnchor.Spot.TOP_RIGHT
add_child(corner)

var hp := GoBar.new()
hp.label_text = "HP"
hp.ink = GoUi.color(GoTheme.DANGER_FILL)
corner.add_child(hp)
hp.set_values(320, 500)

Conteúdo que se mantém longe do HUD

form.avoid_hud = true                  # se afasta de todo GoHudAnchor visível
joystick_anchor.reserve_space = false  # …menos os que só aparecem sob o dedo
notice_anchor.avoid_peers = true       # o aviso se acomoda abaixo do HUD fixo em vez de cobri-lo

Cada retângulo é contornado na direção que custa menos área — para baixo em um celular em retrato, para o lado em paisagem. Como o HUD se desvia de si mesmo →

Exemplos que você pode rodar

Três jeitos de ver o gohud antes de escrever uma linha — nenhum precisa de servidor nem de autoload.

ExemploComo abrirO que mostra
Galeriaexamples/gallery/gallery.tscn · F6Todo widget, um seletor para cada preset instalado e o conjunto completo de ícones
Medievalexamples/medieval/medieval.tscn · F6Uma ficha de personagem, uma bolsa e um diário de missões; os botões alternam entre ferro e pergaminho e abrem os detalhes dos itens
App de democd examples/demo && godotUma tela inicial que abre a galeria, o tour guiado de 15 capítulos, a tela de vitrine e o visual medieval, com widgets ao vivo e um cartão por classe
 
cd examples/demo && godot                             # tela inicial; cria os links e importa na primeira execução
bash examples/demo/run.sh                               # o mesmo app, a partir da raiz do add-on
bash examples/demo/run.sh -- --open=gallery             # pula a tela inicial
bash examples/demo/run.sh -- --explore=surfaces         # abre direto em um capítulo do tour
bash examples/demo/run.sh --record /tmp/gohud-demo.avi  # gravação do tour em 1080p / 60 fps

O app de demo não precisa de configuração: se o link do add-on ou o cache de importação estiver faltando, ele avisa, conserta a pasta e se reabre sozinho. A tela inicial dele abre cada exemplo dentro da mesma janela — pressione 1–4 ou clique em uma linha, e a barra do topo traz você de volta.

No tour, C alterna o modo Cinema, F11 a tela cheia, Espaço pausa (ou executa o widget atual durante a exploração), as setas mudam de capítulo e Escape volta ao início.
