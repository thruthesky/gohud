# arcade_light / leaderboard

Painted art for the podium leaderboard, at about 2x the reference size (reference = 1672x941 shot).
Nine-patch margins are left/right/top/bottom in px; the stretch band between them is flat.
Podium blocks are drawn stretched to their GoPodium rect; the "plate" is the empty cream name plate (x, y, w, h as shares of the block).
